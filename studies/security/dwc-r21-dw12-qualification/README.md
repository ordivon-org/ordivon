# DWC R2.1 DW12 — Qualification / Optimization R1

Status: **mechanical qualification study; independent acceptance remains mandatory**.

DW12 freezes a corpus of canonical DWC acceptance carriers and checks cross-module safety
invariants across six materially different cases:

1. Exchange historical replay;
2. benign authorized-validation + bounded-negative incident canary;
3. response-loss / exact replay;
4. stale consequence evidence;
5. synthetic confirmed-incident recovery;
6. live operator admission with independent security axes.

The study does not rank architectures or self-certify production readiness.

## Mechanical gates

R1 requires zero:

- false closure;
- authority-boundary violation;
- stale-evidence closure;
- duplicate effect apply under replay/response loss;
- historical-to-current evidence laundering;
- global-green collapse of independent security axes.

## Metrics that remain UNKNOWN

Current evidence does **not** establish production TTVP, time-to-eradication,
time-to-recovery, human/Agent decision latency, or unnecessary approval-prompt rate.

## Ablations

R1 records bounded ablations for DW03, DW04, DW10 and DW11.

The DW10 delta (20 selective vs 37 full, delta 17) is explicitly synthetic qualification
cost only. It is not production CPU/wall-clock/money evidence.

DW11 human-attention benefits are not claimed because independent timed re-entry trials remain
unavailable.

## R2 frozen evaluator packet

R2 strengthens the handoff from candidate-author mechanical qualification to genuinely
independent acceptance.

It freezes all DW01-DW11 module acceptance carriers plus six case evidence carriers directly
from the exact candidate Git object. Candidate bytes and evaluation-harness bytes are separate
identities: the subject is bound by candidateRevision + per-artifact SHA-256, while the
measurement harness is bound by exact implementation and runner SHA-256.

R2 therefore permits an independent evaluator to use the later harness to evaluate the exact
earlier candidate without mutating either identity.

The R2 packet also makes ablation scope explicit:

- DW10 has one executed matched synthetic full-recompute baseline;
- DW03, DW04 and DW11 currently have structural-removal ablations only;
- production outcome effects for those three remain UNDERDETERMINED;
- null timing/human-attention metrics mean UNKNOWN, never zero or PASS.

Final acceptance still requires a receipt from a different evaluator actor and a concrete
evaluator occurrence. No such receipt is generated by the candidate-building occurrence.
