# Browser Security Attribution Study

Status: retained experimental lineage / not production security authority.

This study preserves the neutral Browser Security R3/R4/R5/R7/R8/R9 attribution experiments,
their point-in-time evidence, and the focused tests that make the experiment mechanics replayable.
Production browser-security witness semantics and current operational fixtures belong to
`platform/security` and the current Harness/browser carrier owners; this study does not replace them.

The internal layout intentionally preserves the original experiment-relative contract:
`experiments/browser-security-r*` code resolves sibling experiment revisions and
`evidence/browser-security/*` observations from this study root. Historical evidence bytes are not
rewritten merely because the study moved out of `meta/next`.
