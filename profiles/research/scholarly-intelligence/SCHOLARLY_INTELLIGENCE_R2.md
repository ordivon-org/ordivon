# Scholarly Intelligence R2 — Thin Profile Admission

Date: 2026-09-23
Status: **ACCEPTED THIN PROFILE PROTOCOL / POLICY CIRCUITS NOT ADMITTED**

## Decision

Admit the machine-readable Scholarly Intelligence **profile protocol** as shared Research composition metadata.

Do **not** admit a universal scholarly ontology, a shared scientific state machine, or executable research-policy circuits.

The accepted shared surface is limited to:

- exact Study authority and revision binding;
- a nullable Standard-Native binding;
- five opaque coordination-role lists: requirements, claims, evidence, concerns, resolutions;
- nine independent owner-native state axes: requirements, evidence, inference, claims, argument, venue, review, publication, learning;
- explicit non-claims;
- exact digest-bound references when locations are projected.

Scientific payload meaning remains Study-owned.

## Cross-Study rule admitted

R2 admits one architecture rule:

> Closure or PASS on one scholarly axis does not authorize, imply, or overwrite closure on another axis; route next work through the unresolved owner-native axis.

This is a coordination/authority rule, not a scientific inference rule.

## Counterexample pressure

The profile survives only because it stays thin.

It explicitly does not attempt to encode:

1. statistical semantics such as estimands, dependence, uncertainty, robustness, or claim ceilings;
2. Paper2 eligibility/adjudication protocol semantics;
3. a global scientific-edge ontology duplicating CiTO/Nanopublication-style semantics;
4. the scholarly review/rebuttal cycle as an execution DAG.

The schema keeps role references opaque, owner-native state values unnormalized, role lists optionally empty, and scientific payload fields outside the shared object.

## External owner boundary

External owners continue to own their natural semantics:

- scientific/method requirements: Study-native standards and applicable domain standards;
- provenance: W3C PROV;
- operational/data lineage: OpenLineage;
- research-object packaging: RO-Crate;
- claim/citation interchange where useful: Nanopublications/CiTO;
- physical execution: Runtime;
- continuity: Host;
- routing: Gateway.

The thin profile coordinates references to these owners. It does not replace them.

## Explicitly not admitted

R2 does **not** admit:

- universal scientific ontology;
- universal statistical result schema;
- ClaimPermission as shared executable policy;
- Concern-to-gap routing as shared executable policy;
- experiment-admission policy;
- reviewer personality or acceptance-probability authority;
- shared scientific database;
- a mutable global paper.status = READY.

These remain candidates requiring separate cross-Study proof.

## Storage

No shared PostgreSQL materialization is authorized by this decision.

Storage may be reconsidered only after a repeated workload requires durable shared projections/analytics. Scientific datasets remain Study-owned.
