## New structural motifs

### m13 — Extraction makes ownership conditional on safe return

Value acquired inside a session can become dramatically more consequential when it is only banked after a voluntary, contestable exit decision.

**Seen in:** top-hunt-showdown

### m14 — Dangerous capability can create cooperation

Cooperation can be strengthened when powerful tools have friendly externalities/collateral risk, forcing players to coordinate intent and position rather than merely stack buffs.

**Seen in:** top-helldivers2

### m15 — Mundane actions can generate social evidence

A low-complexity task layer can support a richer social-deduction layer when routes, timing and visible behavior create evidence/alibis.

**Seen in:** top-among-us

### m16 — Asymmetric pursuit turns attention into a team resource

In one-versus-many designs, occupying the powerful role’s attention can be valuable even without direct objective progress because it frees teammates elsewhere.

**Seen in:** top-dbd

### m17 — Persistent groups are gameplay infrastructure

Guild/corporation structures become mechanics when they pool resources, assign responsibilities, create trust/reputation and persist beyond a single session.

**Seen in:** top-ffxiv, top-eve

### m18 — Player economy needs institutions, logistics and trust

A deep player economy is not merely trading UI: transport, territorial access, contracts, reputation and organizational authority determine who can create and capture value.

**Seen in:** top-eve

### m19 — Live-service breadth must expand possibility space

Long-lived progression is healthier when new content creates alternative builds/roles/scenarios rather than only a higher scalar power tier.

**Seen in:** top-warframe

### m20 — Tiny verb sets can support extreme physical mastery

Continuous physics plus immediate feedback can generate a high skill ceiling from very few inputs when repeated practice is cheap and outcomes are attributable.

**Seen in:** top-rocket-league, top-trackmania

### m21 — Asynchronous opponents can be compressed into benchmarks

Ghosts, times and leaderboards let other players function as persistent practice targets without requiring simultaneous matchmaking.

**Seen in:** top-trackmania

### m22 — Automation can move agency upward instead of deleting it

Automating low-level actions can create value when meaningful agency remains in positioning, routing, composition or architecture; it fails when automation removes the remaining consequential choices.

**Seen in:** top-vampire-survivors, top-factorio

### m23 — Creator loops can sit above player loops

UGC platforms add a higher-order loop—create/publish/discover/play/reinvest—where the player population also becomes the content-production system.

**Seen in:** top-roblox

## Synthesis

The second wave adds several mechanisms that the first wave underrepresented: **conditional ownership, attention as resource, dangerous cooperation, persistent institutions, asynchronous opponents, and creator-side production loops**. These are especially valuable because they change where the game boundary sits.

```text
Hunt:       acquire value → carry risk → choose when to bank it
Helldivers: powerful tool → collateral risk → communicate/position → coordinated payoff
Among Us:   ordinary action → observed behavior → claim/alibi → vote
DbD:        chase attention → frees teammates → distributed objective progress
EVE/FFXIV:  session play → persistent organization → pooled resources/trust/identity
Trackmania:  past/other run → ghost benchmark → micro-correction → new time
Vampire:    automate attacks → preserve movement/build choice → system snowball
Roblox:     create → publish → discovery → play → creator reward → more creation
```

The important design lesson is again not “copy extraction” or “add UGC”. It is to decide **what becomes scarce, persistent, social, bankable, attributable or producer-owned**, and then couple that property to a stable core grammar.
