# OSS Contribution Domain Glossary

**Campaign** — A long-running objective that coordinates repeated upstream-contribution waves and whose semantic frontier must survive interruptions.

**Wave** — A bounded batch of independent or mostly independent contribution lanes. A Wave is a coordination batch, not a durable Work by default.

**Contribution Case** — One upstream repository/Issue candidate that has become active enough to require its own bounded evidence and, only when justified, durable continuity.

**Repository Admission** — The decision that a repository is worth deeper contribution investigation based on current software/activity/openness/reachability evidence.

**Issue Admission** — The decision that an Issue is worth independent reproduction after current duplicate, assignment, existing-PR, policy, and value checks.

**Stage Marker** — A campaign/profile progress label describing where a Campaign or Contribution Case sits in the contribution process. It is not a Host Work lifecycle state.

**Reproduction Disposition** — The bounded result of testing an admitted Issue claim: REPRODUCED, FALSE, ALREADY_FIXED, NEEDS_INFO, or SECURITY_PRIVATE_ROUTE.

**Independent Falsifier** — An actor whose objective is to disprove the producer's reproduction, root-cause explanation, test, or repair using independent evidence.

**Owner-native Verification** — Verification defined and executed according to the target repository/domain's own build, test, lint, type, security, or other acceptance surface.

**Contribution Contract** — The repository/provider-specific rules that constrain a concrete upstream contribution, including CONTRIBUTING, SECURITY, CLA/DCO, templates, base-branch rules, test requirements, changelog/newsfragment requirements, and review conventions.

**Contribution Ledger** — A derived reporting view over natural-owner evidence and campaign semantic outcomes. It is not a second authoritative task or GitHub database.

**Handoff** — A durable collaboration message that states what another actor should recover, what remains unresolved, and the bounded next action or stop condition.

**Evidence Reference** — An exact reference to evidence retained by its natural owner. A reference enables navigation and recovery; it does not transfer authority.
