### Verification subtraction decision

- **Consolidated** duplicate digest status branching into the one pure
  `digest_verdict` function with PEP 316 contract; `catalog.py` consumes it.
  No second digest classifier remains in the Data package.
- **Kept** file-identity and hash read-back tests, malformed URI, out-of-scope,
  duplicate product version, schema rejection and real Capital consumption,
  because neither Lean abstract digest equality nor CrossHair bounded symbolic
  Python execution proves these I/O and cross-owner effects.
- **Kept** historical R1–R6 and source snapshots: they are consumed by native
  regression/replay/reference analysis, not merely old timestamps.
- **Removed only** generated test caches and temporary files in this
  candidate worktree with exact paths; no system or another Agent's
  worktree is a cleanup target.
- **Not claimed:** complete implementation refinement, SHA-256 collision
  freedom, provider truth, full RDF conformance, durable offsite backup,
  operational deployment, or production data product publication.
- **Formal negative oracle:** CrossHair rejected a deliberate mutation
  `digest_verdict(None,None) == VERIFIED` with a concrete
  `(None,None)` counterexample (tool exit 1); the normal implementation
  returned zero with no counterexamples found, which is a bounded result.
- **Real downstream witness:** Capital public-shadow consumer produced a
  product-version-bound receipt and OpenLineage START/COMPLETE event pair
  with `externalFinancialWriteAttempted = false`.
