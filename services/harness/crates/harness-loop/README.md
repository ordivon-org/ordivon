# Native Rust Harness Loop

Rust execution-decision kernel: bounded tool selection, progress, evidence,
provider/tool source inspection and owner-effect receipt classification.

Native PostgreSQL persistence is in harness-pg; canonical representation in
harness-core. Tool selection and progress are separate modules. Identity
validation is Rust-native.

Python differential tests are historical test inputs only, not a runtime
fallback, compatibility layer, dual writer or production adapter. The
native Agent Loop and Provider execution path remain unimplemented; this
crate is not installed as the production Harness.
