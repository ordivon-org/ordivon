# Policies

Policies cover responsibility and authority boundaries around Agent action.

Policy dimensions should be imported from mature risk/governance practice where possible and may include:

- read vs constrained-write vs write;
- external effects;
- reversibility;
- consequence/risk;
- environment trust;
- required human authorization;
- validator/acceptance requirements;
- retention and evidence requirements.

Policies must not become a duplicate implementation of domain standards or external identity/access-control systems.
