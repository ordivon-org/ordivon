# Archive Archipelago 001

A cartographic portrait of the current Ordivon Creative Library. The work deliberately uses a **conceptual Cartesian archive plane**: owner domains become islands, individual Works become stable points, and catalogued work relations become routes. Nothing in the coordinates claims physical or geographic location.

Editable/source-first chain:

`Creative Library catalog snapshot → generate.py → GeoJSON + SVG → GDAL/OGR GeoPackage → rsvg-convert PNG`

The GeoPackage is the reusable spatial artifact; the SVG is the editable visual composition; the PNG is the fast preview.
