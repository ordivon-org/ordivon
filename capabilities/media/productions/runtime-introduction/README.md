## Chosen proof

The first film will not enumerate every Runtime feature. It proves one complete trajectory:

```text
exact source
→ guarded Patch
→ durable Job
→ recover the same Job after uncertain delivery
→ read bounded evidence and review the diff
→ compare-and-close the exact reviewed Workspace state
```

The executable demonstration belongs in `ordivon-runtime`; Studio owns the story, motion, capture selection, edit and delivery variants.

## Verified now

The committed Runtime demo has run repeatedly against the installed service. It captures non-terminal three-step progress, recreates the MCP client, receives the same Job and Attempt on exact replay, recovers the Job through `task.list`, reads terminal evidence, confirms a one-file diff, and compare-and-closes the reviewed source state. No demo Workspace remains after a successful run.

Studio validates the resulting Receipt as a Production Source. Identity drift, absent non-terminal observation, incomplete proof events, and private-path leakage fail validation.

Three 1920×1080, 30 fps programmatic components now render:

- the Runtime execution flow;
- exact request replay to the same Job and Attempt;
- exact source-state compare-and-close.

All tested outputs pass H.264, `yuv420p`, limited-range, complete BT.709 signaling, and no-empty-audio-track QC.
