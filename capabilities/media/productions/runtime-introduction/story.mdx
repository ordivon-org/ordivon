# Reliable execution is a different problem

AI systems can propose code and commands. That does not make the resulting execution durable, observable, or safe to repeat after an uncertain response.

Ordivon Runtime addresses that physical execution boundary. It binds work to an exact Git Workspace, commits a durable Job identity, supervises the resulting process tree, preserves bounded evidence, and exposes explicit observation, cancellation, reconciliation, and recovery.

<RuntimeFlow activeStage="evidence" />

The production will pair this explanation with a real end-to-end demonstration:

```text
workspace.open
→ workspace.patch
→ workspace.exec
→ task.observe
→ artifact.read
→ workspace.diff
→ workspace.close
```

The film will also state the boundary directly: Runtime is operational for owner-trusted Linux environments. It does not decide semantic Task completion and is not a hostile multi-tenant sandbox.
