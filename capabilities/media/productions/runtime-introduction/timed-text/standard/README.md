# Standard timed-text authority

`narration.en.ttml` is the current timed-text source referenced by `production.json`.

It was generated by pinned `ttconv==1.2.3` using its IMSC-oriented TTML writer. R4 does not claim independent IMSC 1.3 conformance; the file is treated as a standard TTML/IMSC candidate until independently validated. `narration.en.vtt` and `narration.en.srt` are delivery derivatives.

Mechanical delivery is checked by `media-v2/bin/probe-timed-text.sh` using xmllint, ttconv, and FFprobe. Semantic caption completeness and accessibility outcomes remain separately reviewed.
