# 中文旁白草稿

Agent 会写代码，不代表它能够可靠地执行代码。

一次命令可能持续得比当前对话更久，也可能丢失响应、遗留子进程，或者留下无法立即判断的结果。

Ordivon Runtime 是面向 Agent 与自动化工作流的本地持久执行层。

它为操作建立稳定身份，在绑定具体版本的 Git Workspace 中工作，使用 systemd 与 cgroup 管理进程树，并保存有界的结果、Artifact 与终端证据。

这次演示会真实完成 Workspace 创建、文件修改、Job 执行、状态观察、Artifact 读取、Diff 检查和安全关闭。

响应丢失时，客户端重新连接同一个已记录的 Job，而不是盲目重复一项后果不明的操作。

Runtime 面向所有者信任的 Linux 环境。它不是敌对代码沙箱，也不负责判断用户的语义目标是否完成。
