# Creative Library extraction

This source slice was extracted from the historical workstation-lab repository after
the geospatial presentation-classification retirement at source revision
ee41e995d0bd98ac08de54d9d11c876345f4f182.

The slice is hosted by Media because its executable role is cross-domain discovery,
carrier presentation, exact-revision browsing, and derived-preview projection. Hosting
does not transfer work identity, source-byte authority, physical standing, publication
approval, artistic-quality standing, or Human-value standing to Media or Creative Library.

The catalog is a rebuildable projection. Exact carrier bytes remain bound to the
source repository and source revision recorded for each work. The PostgreSQL historical
Creative Archive remains the live archive authority when selected; the frozen JSON export
is the reproducible fallback.

Preservation semantics are excluded and now live behind the separate standard-native
Preservation profile.
