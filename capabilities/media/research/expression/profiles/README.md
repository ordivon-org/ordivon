# Expression profiles

Profiles translate the cross-medium creative core into faster-moving medium and encounter knowledge.

They are intentionally downstream from [`../creative-system.md`](../creative-system.md), [`../protocol.md`](../protocol.md), and [`../knowledge-model.md`](../knowledge-model.md).

`medium-baseline.json` is the provisional baseline extracted from the original monolithic `context.json`. It preserves useful existing hypotheses while making their lower authority explicit. C2 will pressure-test and split these profiles only where real production earns the distinction.

A profile may own medium craft, renderer/inspection expectations, common semantic failure modes, distribution assumptions, and current context. It may not redefine cross-medium truth binding or promote a local style into universal taste.
