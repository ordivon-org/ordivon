# Still Visual expression profile candidate

Status: provisional
Evidence state: M7-S supports distinct rendered-visual failure classes but ordinary-production deletion does not yet justify a large resident profile.

## Responsibility

Still Visual covers a persistent simultaneous visual field: composition, figure/ground, crop, scale, visual hierarchy, color/light/texture, symbol and viewing/reproduction conditions. It is narrower than generic `Visual`: when visual structure is authored over time, Motion/Video also applies; when observer actions change state, Interactive also applies.

## Current discriminating evidence

M7-S rendered one source-bounded recovery proposition as controlled SVG/PNG variants. A low-level rendered-pixel signature produced zero distance for the re-encode control and clear separation for outcome-color and qualifier-crop interventions. Registered target-specific failure coverage was:

```text
Still candidate  4 / 4
Core only        1 / 4
Motion swap      0 / 4
Sham             0 / 4
```

This is evidence that crop, viewing distance, reproduction and diagram geometry form a useful Still-specific diagnostic family.

## Counterevidence and ROI

`productions/site-social-card` is an important deletion counterexample: while Still remained only a provisional baseline, Core + exact rendered preview inspection already detected and fixed a real thumbnail-scale legibility defect. The profile therefore has **incremental information**, but current evidence does not show that a large always-resident Still profile is required for ordinary production.

Current disposition: keep a **compact retrievable provisional profile**, not an active foundational authority.

## Working priors

- inspect actual rendered pixels under relevant crop/scale/reproduction;
- treat position, scale, balance, color and negative space as possible implicit claims;
- diagram geometry can imply relation/causality even when labels are literally correct;
- crop can remove qualification without changing source truth;
- typography has visual-form consequences distinct from Writing semantics;
- viewing distance and reduced preview size can reorder practical hierarchy.

## Render / inspect boundary

```text
editable source
→ exact raster/vector delivery
→ relevant crop / scale / reproduction
→ visual + semantic audit
```

The current RGB-grid signature is controlled-sensitivity equipment only; it is not an object recognizer, salience oracle or beauty metric.

## Falsifier

Promote only if another materially different ordinary production shows that Core + real-render inspection repeatedly misses Still-specific defects that this compact profile predicts before revision. Merge/narrow if the same performance can be obtained from Core plus on-demand diagram/crop/reproduction checks at lower context/maintenance cost.
