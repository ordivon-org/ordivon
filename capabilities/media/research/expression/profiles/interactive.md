# Interactive expression profile candidate

Status: provisional
Evidence state: M7-I proves trajectory-specific failure, but generic-profile authority remains redundant with the mature Web consumer until non-Web reuse earns a separate owner.

## Responsibility

Interactive expression begins when an observer action can alter subsequent state, information, timing, path or consequence. The real artifact is therefore a state/action trajectory, not a screenshot collection.

## Current discriminating evidence

The M7-I real Chromium experiment held source proposition and final state constant across three variants:

```text
lawful
premature-success
silent-delay
```

For both defective variants, **initial and final static states were identical to the lawful encounter**, yet the trajectory exposed either a transient unsupported `Succeeded` claim or latency with no feedback. Encounter freezing to initial+final screenshots erased both registered defects.

Target-specific registered detector coverage was:

```text
Interactive candidate   2 / 2
Core only               1 / 2
static-publication swap 0 / 2
Sham                    0 / 2
```

This is direct evidence that action → state → feedback/recovery is not reducible to static presentation.

## Current boundary and ROI

Ordivon Web already owns mature browser interaction, navigation, state legibility, accessibility and recovery craft. The M7-I experiment was itself run through Web equipment. Studio therefore does **not** create a second active Interactive authority yet.

Current disposition: retain a compact provisional generic candidate; Web remains the active concrete consumer. Graduation requires materially different non-Web reuse such as Game or another interactive runtime where the same trajectory priors predict failures independently of browser/publication conventions.

## Working priors

- inspect action → state → feedback trajectories, including transient states;
- distinguish pending/checking/unknown/success rather than using polish as state proof;
- latency without feedback is semantically different from known failure;
- reversible/recoverable actions require legible identity and consequence;
- final-state correctness cannot erase misleading transient claims;
- interaction accessibility must preserve both control and state-change information.

## Falsifier

Merge into Web/other concrete consumers if non-Web work adds no reusable generic knowledge. Promote only when deletion of the generic candidate harms at least two materially different interactive consumers while a consumer-specific profile alone cannot explain the transfer.
