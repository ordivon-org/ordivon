# M7 — Foundational media deletion, distinction, and graduation

## Question

What is the smallest persistent media world model that gives an Agent target-specific production information without duplicating generic Core knowledge, consumer-owned craft, platform context, or tool configuration?

M7 treats media categories as falsifiable observer-relation hypotheses rather than a list of file types or industries.

## Common source-bound proposition

The lab packet held this proposition fixed wherever practical:

> The response was lost. The operation outcome is unknown. Recover the same operation identity before concluding success or failure.

The experiment deliberately selected a proposition with an epistemic boundary because visual color/geometry, audio emphasis, interaction feedback and live currentness can all accidentally upgrade `unknown` into a stronger claim.

## Experimental institutions

Each candidate faced as many of these as its current equipment allowed:

```text
Core-only deletion
correct-profile arm
wrong-profile swap
sham-profile control
encounter freezing
collapse/merge reasoning
real artifact / encounter inspection
ordinary-production counterevidence
marginal cost / persistent-complexity pressure
```

Registered failure coverage is a diagnostic-information measure, not a human quality score. Mechanical signal distance proves controlled sensitivity, not beauty, preference, emotion or comprehension.

## M7-S — Still Visual

A real SVG→PNG render packet altered only registered visual families: outcome-colored framing and a delivered crop that removed qualification. A re-encode control had zero low-level RGB-grid distance. Both interventions separated strictly from the control.

Registered target failure coverage:

```text
Still candidate  4 / 4
Core only        1 / 4
Motion swap      0 / 4
Sham             0 / 4
```

This establishes useful Still-specific information. It does **not** justify a large active profile because the existing `site-social-card` ordinary production previously solved a real thumbnail/viewing-distance defect with Core + rendered browser preview while Still was only provisional.

Decision: **retain a compact provisional Still Visual candidate; do not graduate.**

## M7-A — Audio

Windows SAPI synthesized one exact spoken source. Every experimental file after synthesis derived from that waveform, so lexical content remained fixed. FFmpeg applied rate, loudness, masking and onset interventions plus a PCM re-encode control.

The re-encode control produced zero structural distance. Every registered acoustic intervention separated; the strongest were masking and delayed onset. Registered failure coverage:

```text
Audio candidate        5 / 5
Core only              1 / 5
Writing + Motion swap  1 / 5
Sham                    0 / 5
```

The distinction is also supported by ordinary `runtime-introduction` production: narration, TimedText, audio working-profile facts and audiovisual semantics already consume Audio-specific responsibilities.

Decision: **graduate Audio to active.** The old `audio-music` bundled placeholder is rejected; speech, sound design and music remain specializations until a future split test earns separate profiles.

## M7-I — Interactive

Web rendered three real Chromium encounters with identical source proposition and identical initial/final reset states:

```text
lawful
premature-success
silent-delay
```

The defective variants contained either a transient unsupported `Succeeded` state or a silent latency interval. In both cases, initial + final static screenshots were equivalent to the lawful encounter and therefore erased the defect. Only action/state trajectory inspection recovered it.

Registered failure coverage:

```text
Interactive candidate    2 / 2
Core only                1 / 2
Static-publication swap  0 / 2
Sham                      0 / 2
```

This strongly supports Interaction as an irreducible observer relation. It does **not** yet support a second active Studio authority because Web already owns mature browser interaction craft and the current discriminating artifact is Web-hosted.

Decision: **retain generic Interactive as provisional; Web remains active consumer authority.** Require non-Web reuse before graduation.

## M7-X — Spatial / 3D

A controlled projection model preserved object-local facts while changing viewpoint and declared reference space. Viewpoint displacement was `0.225`; interpreting a local coordinate under an offset stage space produced `0.625` projection error. Fixed-view freezing removed the viewpoint contribution.

This supports reference space/viewpoint as a real candidate distinction. It is not a real XR encounter and says nothing about embodiment, comfort, presence or human depth perception.

Decision: **retain Spatial/3D as candidate only.** No registry/profile/schema promotion.

## M7-L — Live / Realtime

Five real-time software traces withheld future events until arrival. An injected stale update was followed by correction. A guarded policy marked stale/currentness uncertainty; a naive replay-like policy presented stale state as current in every replicate. Mean misleading exposure before correction was about `9.29 ms` in this deliberately short synthetic timing envelope.

An edited replay can remove that misleading interval entirely. The result therefore supports `future-not-yet-fixed + currentness/correction` as a distinct live pressure rather than merely video playback.

Decision: **retain Live/Realtime as candidate only.** No ordinary public live production exists yet, so profile graduation would exceed the evidence.

### 2026-08-25 conversation specialization follow-up

A later Representation Environment audit asked the narrower question that M7-L intentionally left open: does Human↔Agent conversation already require an additional Conversation specialization beyond generic live/currentness and interaction semantics?

The falsifier used one fixed four-turn live conversation with: an established candidate referent, a side-task interruption, two simultaneously salient singular artifacts followed by `Send it`, an owner correction that replaced Juniper with Maple, and an explicit later `Publish Maple` command. It compared generic live rules with added conversational common-ground/reference-repair prose and with a non-authoritative structured discourse-state projection. Early runs exposed two experiment-design errors—`needsRepair` was conflated with structured-output correction, and a post-correction `hold` expectation incorrectly rejected the valid action of drafting the replacement candidate—so those runs were retained only as diagnostic evidence and not promoted.

The cleaned reference-standing ablation used explicit `referenceStanding = unresolved | cedar-answer | juniper` and `nextAction = clarify-reference | ...` fields. On the genuinely ambiguous two-antecedent turn, all three arms preserved the reference as unresolved and selected clarification:

```text
generic live             3 / 3
conversation prose rule  3 / 3
structured projection    3 / 3
```

A separate cleaned full-prefix run also showed that both generic and conversation-aware arms correctly preserved the publication instruction/effect distinction once the field was changed from ambiguous `completionClaimed` to exact `physicalPublicationObserved`.

Decision: **do not graduate a Conversation profile and do not add discourse-state machinery from this evidence.** Conversation-specific guidance can help make correction/rebinding intent explicit, but this experiment did not reveal a deletion-essential failure that generic live handling could not already solve. M7-L remains intact: live unknown-future/currentness/correction pressure is real, while Conversation remains a specialization candidate that must be reopened only by a real consumer failure or stronger ablation.

## Haptic / Physical challenger

OpenXR and the W3C Vibration API establish tactile output as a real technical modality, but this environment has no verified physical haptic encounter. Simulating timestamps would not test tactile perception.

Decision: **retain challenger, no profile.** This is an intentional stop condition rather than a missing implementation.

## Writing and Motion controls

Writing and Motion/Video remain active controls. M7 found no reason to demote them: both already have materially different ordinary consumers and prior rendered semantic failures. Their role in this round was to provide plausible wrong-profile/encounter-freezing comparators rather than consume budget repeating already established demonstrations.

## Collapse / merge conclusions

```text
Audio → Writing + Motion     REJECTED by 5/5 vs 1/5 target coverage
Interactive → static Web    REJECTED at encounter level; transient defects vanish
Spatial → fixed Motion      REJECTED as a full explanation; viewpoint/reference effect vanishes
Live → prerecorded replay   REJECTED as a full explanation; correction/currentness window vanishes
Still → Core                NOT fully rejected, because ordinary Core+render inspection already solved one real Still defect
Audio → Speech/Music/SFX split  NOT EARNED; keep one Audio profile with specializations
Interactive → Studio active profile NOT EARNED; Web authority currently covers real consumer
```

## ROI / persistence decisions

The M7 outcome is deliberately asymmetric:

```text
Writing         active
Still Visual    provisional, compact/on-demand
Audio           active (graduated)
Motion / Video  active
Interactive     provisional generic; Web active consumer
Spatial / 3D    candidate only
Live / Realtime candidate only
Haptic/Physical challenger only
```

The system therefore gained coverage **while deleting one false symmetry**: not every plausible foundation deserves equal persistent context, registry authority, or canonical Production schema.
