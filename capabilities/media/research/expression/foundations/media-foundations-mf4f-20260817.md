# 1. Problem statement

MF4 has already established:

- whole composition is not plurality;
- parts are not pre-given atoms;
- relations are typed rather than generic edges;
- hierarchy is not one tree;
- temporal composition is not timestamp order.

MF4-F asks the analogous spatial question:

> **When do spatial relations merely locate components, and when do geometry, topology, enclosure, orientation, alignment, occlusion, layout or spatial hierarchy become constitutive of a whole's identity, function or content?**

Spatial composition appears in:

- physical scenes;
- pages;
- screens;
- maps;
- diagrams;
- interfaces;
- photographs;
- paintings;
- architecture;
- scientific figures;
- graphs/networks;
- continuous fields;
- spatial memory;
- visual perception.

Dangerous collapses:

`Position = Spatial Relation = Layout`;

`Coordinates = Geometry = Topology`;

`Proximity = Grouping = Composition`;

`Containment = Part-of = Ownership`;

`Overlap = Occlusion = Connection`;

`Image Geometry = Scene Geometry`;

`Viewer Frame = Object Frame = World Frame`;

`Visual Order = Logical Order = Reading Order`;

`Same Spatial Whole = Same Pixel Coordinates`.

MF4-F rejects all of them as universal identities.

---

# 2. Position is not spatial composition

A coordinate `x=(x,y,z)` locates one unit relative to a coordinate frame.

A set of coordinates does not yet specify which spatial relations are whole-relevant.

### Result

**CF-01 — Spatial coordinates provide location under a frame, not spatial composition by themselves.**

---

# 3. Location is reference-frame dependent

The same object can have:

- room/world coordinates;
- viewer-relative coordinates;
- object-relative coordinates;
- screen coordinates.

### Result

**CF-02 — Location requires a declared reference frame; coordinate values are not frame-free spatial facts.**

---

# 4. Coordinates ≠ Reference frame

A coordinate tuple only acquires spatial interpretation under axes/origin/units/orientation/projection conventions.

### Result

**CF-03 — Coordinates and their reference frame/coordinate system are distinct.**

---

# 5. Reference frame ≠ Spatial relation

`A is left of B` can be evaluated under several frames without storing either object's absolute coordinates.

### Result

**CF-04 — Spatial relations can be represented qualitatively/relationally without absolute coordinates.**

---

# 6. Viewer-centered, intrinsic and allocentric frames are distinct

Possible organizations include:

- egocentric/viewer-relative;
- intrinsic/object/configuration-relative;
- allocentric/environment/world-relative.

### Result

**CF-05 — Spatial reference frames form typed alternatives rather than one universal coordinate basis.**

---

# 7. Mou–McNamara provide a hard reference-frame falsifier

Their experiments showed spatial memories could be organized according to an intrinsic axis of a learned object configuration even when that axis differed from the participant's viewing perspective.

### Result

**CF-06 — Spatial organization need not be reducible to current viewer orientation; intrinsic configuration frames can organize memory.**

---

# 8. Reference-frame choice can alter relation content

`left-of(A,B)` under viewer frame can reverse after viewpoint change while an intrinsic relation remains constant.

### Result

**CF-07 — Relation content must include the relevant frame when frame changes can reverse/alter spatial predicates.**

---

# 9. Frame transformation ≠ Object change

Changing viewer position can alter image/screen coordinates while physical scene identity stays fixed.

### Result

**CF-08 — Coordinate/frame transformation and underlying object/scene transformation are distinct.**

---

# 10. Geometry is broader than coordinates

Geometry concerns relational structure such as:

- distance;
- angle;
- orientation;
- shape;
- size;
- geodesic relation;
- transformation invariants.

### Result

**CF-09 — Geometry is relational structure over space, not merely stored coordinate tuples.**

---

# 11. Metric geometry ≠ Topology

Metric structure concerns quantitative distance/angle/length.

Topology concerns continuity/connectivity/inside-boundary relations that can survive large metric deformation.

### Result

**CF-10 — Metric and topological spatial structure are distinct composition profiles.**

---

# 12. Egenhofer–Franzosa provide a formal topological falsifier

Their point-set framework characterizes spatial-region relations through intersections of interiors and boundaries, yielding relations corresponding to disjointness, equality, containment and other topological configurations without requiring one particular metric geometry.

### Result

**CF-11 — Topological relation identity can remain meaningful independently of exact coordinates/distances.**

---

# 13. Topological equivalence can survive geometric deformation

Stretching a region without tearing/merging can preserve connectivity/containment while changing distances, angles, area and curvature.

### Result

**CF-12 — Same topology does not imply same metric geometry.**

---

# 14. Same metric summaries do not imply same topology

Equal area/perimeter/distance summaries can belong to differently connected regions.

### Result

**CF-13 — Metric equality/similarity is insufficient for topological identity.**

# 157. Spatial composition failure taxonomy

## Mislocation

Correct unit at wrong position.

## Wrong reference frame

Correct coordinates interpreted under wrong axes/origin/perspective.

## Distance/spacing error

Metric relation outside intended range.

## Orientation error

Wrong direction/rotation/handedness.

## Alignment error

Wrong baseline/axis/grid alignment.

## Adjacency error

Wrong neighborhood/contact relation.

## Topological merge

Distinct regions incorrectly connected/overlapped.

## Topological split

One connected region incorrectly disconnected.

## Containment error

Inside/outside relation wrong.

## Ownership error

Correct boundary assigned to wrong region/figure.

## Depth-order/occlusion error

Front/behind/visibility relation wrong.

## Projection/view error

Image geometry mistaken for scene geometry or wrong viewpoint model used.

## Layout-role error

Correct component placed in wrong slot/region.

## Visual/logical-order conflict

Visual order contradicts intended logical/navigation order.

## Reflow failure

Responsive transform destroys required relation/affordance/readability.

## Spatial aliasing

Sampling/resolution collapses relevant geometry/topology.

## Scale mismatch

Spatial resolution/extent inappropriate for task.

## Constraint conflict

No realization satisfies required layout relations.

## Clutter/legibility failure

Valid geometry yields poor discriminability/traversal under consumer/task.

## Interaction-geometry mismatch

Visible and actionable regions diverge incorrectly.

**CF-151 — Spatial-composition error is a typed family, not one coordinate/RMSE/IoU scalar.**

# 159. Primary/original/official literature anchors

- Egenhofer, M. J. & Franzosa, R. D. (1991), `Point-Set Topological Spatial Relations`, *International Journal of Geographical Information Systems* 5(2), 161–174. DOI: 10.1080/02693799108927841. Formalizes region topology via boundary/interior intersections; provides a clean separation of topological relations from exact metric coordinates.
- Palmer, S. E. (1992), `Common Region: A New Principle of Perceptual Grouping`, *Cognitive Psychology* 24(3), 436–447. DOI: 10.1016/0010-0285(92)90014-S. Shows common-region enclosure strongly affects grouping, can overcome proximity/similarity in tested displays and depends on perceived depth organization.
- Palmer, S. E. & Rock, I. (1994), `Rethinking Perceptual Organization: The Role of Uniform Connectedness`, *Psychonomic Bulletin & Review* 1(1), 29–55. DOI: 10.3758/BF03200760. Unit formation/grouping framework relevant to connectedness, depth and spatial composition boundaries.
- Mou, W. & McNamara, T. P. (2002), `Intrinsic Frames of Reference in Spatial Memory`, *Journal of Experimental Psychology: Learning, Memory, and Cognition* 28(1), 162–170. DOI: 10.1037/0278-7393.28.1.162. Experiments support spatial-memory organization around intrinsic configuration axes that can differ from viewing perspective.
- Shepard, R. N. & Metzler, J. (1971), `Mental Rotation of Three-Dimensional Objects`, *Science* 171(3972), 701–703. DOI: 10.1126/science.171.3972.701. Recognition cost varies with angular disparity while object-shape identity can be preserved across rotation.
- Rock, I., Di Vita, J. & Barbeito, R. (1981), `The Effect on Form Perception of Change of Orientation in the Third Dimension`, *Journal of Experimental Psychology: Human Perception and Performance* 7(4), 719–732. DOI: 10.1037/0096-1523.7.4.719. Examines phenomenal form under changes of 3D orientation/view.
- Heiser, J. & Tversky, B. (2006), `Arrows in Comprehending and Producing Mechanical Diagrams`, *Cognitive Science* 30(3), 581–592. DOI: 10.1207/s15516709cog0000_70. Experiments show arrow marks alter/communicate functional-dynamic interpretation in mechanical diagrams, demonstrating relation-bearing diagrammatic spatial elements.
- Koenderink, J. J. & van Doorn, A. J. (2008), `The Structure of Visual Spaces`, *Journal of Mathematical Imaging and Vision* 31(2–3), 171–187. Discusses ambiguity/geometry of visual space and inference of depth from monocular cues rather than trivial recovery from image coordinates.
- W3C CSS Working Group, `CSS Flexible Box Layout Module Level 1` and `CSS Grid Layout Module Level 1`. Official specifications provide engineered cases where layout is constraint/rule based; flex visual order can differ from source/logical order and responsive arrangements can reflow while preserving selected document relations.
