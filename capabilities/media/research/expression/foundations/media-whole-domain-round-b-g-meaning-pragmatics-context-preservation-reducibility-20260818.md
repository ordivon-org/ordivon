# 0. Question

Round A left two tightly coupled residuals:

```text
Meaning / Semantics / Pragmatics
Context Integrity / Recontextualization
```

MF3 explicitly froze the boundary:

```text
Representation ≠ full linguistic/social Meaning
```

and already permits context/scope/frame/provenance to participate in fixing representational standing/content.

Round B-G therefore asks:

> **Is there a Media-specific Meaning/Pragmatics or Recontextualization primitive that remains after MF3 representation/content/context/provenance, MF4 composition, MF6 time, MF7 state/history, MF8 agency/action, and Human/Institution/World ownership are made explicit?**

The cheapest falsifier is:

```text
same exact bytes / vehicle
same work identity
same basic representation token/type
DIFFERENT speaker/source/authority/audience/placement/time/provenance/frame
→ different semantic/pragmatic/evidential standing
```

If the resulting differences cannot be represented by existing standing/profile machinery, a new foundation may exist.

# 1. Terminology correction — reserve `Contextual Integrity`

`Contextual Integrity` is already a technical term in Helen Nissenbaum's privacy framework, where privacy is evaluated through context-relative informational norms governing appropriate flows among actors/information types/transmission principles.

This Round is not primarily a privacy theory.

To avoid an ownership/name collision, the Media residual is renamed:

```text
Context Preservation / Recontextualization Standing
```

Meaning:

> which content, source, provenance, audience, authority, pragmatic and evidential relations remain preserved, are lost, or are newly constituted when a media token/expression is embedded into a new surrounding frame or use.

Nissenbaum-style Contextual Integrity remains a Human/Institution/Privacy cross-cutting domain.

# 4. First split — context can affect semantic content itself

Indexicals provide the cleanest case.

The same expression type:

```text
"I am here now"
```

has different token-level content depending on:

```text
speaker / agent
location
time
world/context
```

Therefore:

```text
same string type ≠ same token content across context
```

This is not yet pragmatics in the broad social-force sense; standard semantic theories of indexicals treat context as constitutive of reference/content.

MF3 already allows exactly this through context/reference-frame grounding.

### B-G result 1

Some `context-dependent meaning` is already **semantic RepresentationStanding**, not a missing post-MF3 layer.

---

# 5. Ambiguity/disambiguation can also be context-sensitive without new ontology

A token containing an ambiguous expression can support several candidate contents until context/practice constrains the relevant interpretation.

The important distinction is:

```text
standing ambiguity profile
≠ analyst's arbitrary decoder
≠ one actual context-grounded interpretation
```

MF3's contrastive-content discipline and context field already cover this.

No new Meaning primitive is required merely because bytes underdetermine content absent context.

---

# 6. Sentence/conventional meaning ≠ speaker meaning

Gricean pragmatics provides the canonical split.

A speaker can utter a sentence whose conventional/literal content is p while intending to communicate q beyond p.

For example, an utterance equivalent to:

```text
"I have to work"
```

can in context answer whether the speaker will attend an event by implicating non-attendance without literally stating it.

Thus:

```text
Conventional/Semantic Content
≠ SpeakerMeaning
≠ Implicature
```

This confirms MF3's deliberate boundary rather than falsifying it.

---

# 7. Speaker meaning is not universal to all Media meaning

Public signs, archived texts, anonymous artifacts, machine protocols and inherited conventions can retain content when the original producer's occurrent intention is absent, unknown or no longer recoverable.

Therefore:

```text
CurrentSpeakerIntention ≠ universal condition of Meaning
```

MF3 already rejected one universal intention-based representation theory.

Human speaker meaning remains one important pragmatic route, not the whole Media ontology.

---

# 8. Implicature is context/agent inference, not encoded sentence content

Conversational implicature depends on more than lexical/conventional content.

Relevant variables may include:

```text
what was said
speaker goals/intentions
shared background
conversation history
assumptions about rational/cooperative behavior
audience inference
```

Therefore:

```text
Implicature ≠ RepresentationContent by identity
```

But it decomposes into:

```text
uttered representation          → MF3
speaker/producer agency          → MF8 + Human
conversation/common-ground state → Human + MF7/MF3
inference                         → Human cognition / Agent reasoning
communication relation           → B-A derived profile
```

No Media-specific primitive appears.

---

# 9. Common ground ≠ identical private knowledge

Pragmatics distinguishes:

```text
each participant independently knows p
```

from stronger shared/common-ground standing about p.

Two recipients can separately receive the same proposition without each knowing that the other also received it; a joint public utterance can generate a different coordination state.

Therefore:

```text
SameInformationPerPerson ≠ SameCommonGround
```

But common ground belongs primarily to Human/social epistemic coordination and possibly Institution/Agent coordination, not Media foundation ontology.

Media can create evidence/events that update such states.

---

# 10. Presupposition/common-ground update is not Media-universal

Some linguistic acts interact with presupposed discourse state.

But:

```text
image file decoding
sensor protocol
machine telemetry
static diagram
```

need not instantiate human conversational presupposition structure.

Therefore human pragmatic common-ground machinery cannot be a universal Media constituent.

depending on form, intention, context, role and institution.

Thus:


This is real structure beyond MF3 content.

But the structure maps to Agency/Institution rather than a new Media atom.

# 12. Same words / different institutional force falsifier

Construct:

```text

```

Authorized office-holder, correct procedure, correct institutional setting.

Potential result:

```text

institutional status changes
```

## Case B

Actor repeats identical words in rehearsal, or unauthorized observer says them.

Potential result:


The difference decomposes into:


Therefore speech-act force is not a new Media primitive.

# 13. Performativity is not universal to meaning


Performativity remains a specialized Agency/Institution relation.

This reduces Round A's `Performativity / constitutive media acts` candidate without claiming all pragmatic meaning is institutional.

# 14. Perlocutionary effect ≠ illocutionary force

A warning can be successfully issued but ignored.

A false statement can persuade.

A joke can accidentally offend.

Therefore:

```text
SpeechActForce
≠ AudienceEffect
≠ BeliefChange
≠ ActionOutcome
```

Effects belong to Human/MF8/downstream causal owners.

This preserves B-A's communication failure ladder.

# 15. Quotation proves use/mention and source standing matter

Quotation creates recursive representational structure.

The embedded string:

```text
X
```

can appear as:

```text
a direct assertion of X
quotation of another person's assertion X
example of the sentence X
code/text mentioned as an object
sarcastic echo of X
```

The embedded bytes can remain identical while the surrounding composition changes its role.

MF3 already supports representations targeting other representations, and MF4 supports enclosing composition/role structure.

Thus:

```text
EmbeddedTokenContent/Role
```

must be indexed to its compositional frame.

No separate quotation primitive is necessary.

---

# 16. Quotation ≠ endorsement

A newspaper, paper or agent can quote:

```text
"X is guilty"
```

without itself asserting or endorsing `X is guilty`.

Therefore:

```text
TokenPresence ≠ CurrentPublisherAssertion
Quotation ≠ Endorsement
```

Source/attribution roles must be explicit.

This becomes critical for agent retrieval and generated summaries.

# 17. Exact same bytes can acquire a new composite meaning through placement

Consider one unchanged image `I`.

Place `I` under two different captions:

```text
C1: identifies the actual event/time/place
C2: falsely claims a different event/time/place
```

The image's underlying depictive standing may remain unchanged, while the composed artifact:

```text
<I,C1>
```

and:

```text
<I,C2>
```

have different represented claims/evidential implications.

Therefore:

```text
EmbeddedAssetIdentity ≠ CompositeRepresentationIdentity
```

MF4 composition + MF3 layered representation already handles this.

Recontextualization can create a **new higher-scope representation** without changing the embedded bytes.

# 18. Context change does not always change underlying semantic content

The reverse warning matters.

Moving a photograph from one website to another does not automatically change what scene the image depicts.

Moving a propositionally stable sentence into a quotation may preserve its quoted content while changing who asserts it.

Therefore:

```text
ContextChanged
↛ EveryContentDimensionChanged
```

A Context Preservation profile must specify **which relation** changed:

```text
reference
speaker
assertor
provenance
pragmatic force
audience
institutional status
evidential force
composite claim
```

This prevents overclaiming semantic mutation.

# 19. Interpretation ≠ standing content

A consumer may infer a false contextual story from a correctly represented artifact.

That consumer interpretation does not automatically rewrite the artifact's grounded standing.

MF3 already freezes this anti-arbitrariness discipline.

Therefore distinguish:

```text
GroundedContent
ConsumerInterpretation
ConsumerInference
ConsumerBelief
```

Recontextualization may change the evidence available for inference without making every inference part of the token's content.

MF3 already explicitly freezes content/provenance separation.

# 21. Provenance ≠ truth

W3C PROV models provenance through entities, activities and agents involved in producing/influencing/delivering an object.

C2PA similarly records signed assertions about creation, edits, ingredients, devices and related history.

But a valid provenance record does not by itself establish the truth, quality or goodness of the represented claim.

C2PA explicitly avoids treating validated provenance assertions as automatic value judgments about content.

Therefore:

```text
ValidProvenance
≠ Truth
≠ Reliability
≠ CorrectInterpretation
```

Provenance is evidence/standing input to later trust judgments.

---

# 22. Provenance itself is a representation

A provenance record is not magical access to history.

It represents claims about:

```text
entities
activities
agents
transformations
ingredients
times
responsibilities
```

with its own grounding, integrity and trust assumptions.

Thus provenance belongs within MF3/MF7 evidence architecture, not above it as an unquestionable oracle.

# 23. Context loss can reduce interpretability without changing token bytes

Examples:

This is a genuine preservation problem.

But it is expressible as loss of MF3 grounding/context/provenance links, not a new primitive.
