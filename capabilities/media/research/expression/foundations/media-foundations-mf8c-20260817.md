# 0. Purpose

MF8-A introduced `EvaluativeOrientationStanding`; MF8-B showed that action requires typed guidance but deliberately left that guidance unresolved. MF8-C reconstructs the overloaded family:

```text
Need / Drive / Want / Desire / Liking / Preference / Utility /
Reward / Value / Goal / Objective / Norm / Success / Failure
```

The central question is not `what scalar does the agent maximize?` but:

> **What makes some condition/action/outcome better or worse, needed or harmful, preferred or dispreferred, or to-be-pursued for a declared bearer—and through which provenance?**

MF8-C preserves the frozen boundaries:

```text
Goal ≠ Attractor

Goal ≠ Reward
Goal ≠ Utility
Goal ≠ Preference
Control ≠ Goal
Agency ≠ UtilityMaximization
```

# 1. EvaluativeStanding is deeper than Value-as-number

Provisional primitive:

```text
EvaluativeStanding(X, B, K | Σ)
```

where X is an object/state/action/outcome/possibility; B is the bearer or role; K is the criterion, norm, dependency, concern, objective or other grounding route.

X has EvaluativeStanding when it is non-arbitrarily differentiated as better/worse, favorable/unfavorable, acceptable/unacceptable, needed/harmful, preferred/dispreferred, permitted/forbidden or otherwise action/selection-relevant **for B under K**, rather than merely receiving an analyst's arbitrary score.

### C8-002
Evaluation is fundamentally relational and criterion-relative.

### C8-003
`EvaluativeStanding ≠ ScalarRepresentation`.

### C8-004
Partial, multidimensional, lexicographic, context-dependent and conflicting evaluation are admissible; one total scalar utility is not constitutive.

# 3. NeedStanding

A need is not fundamentally a feeling or desire.

```text
NeedStanding(R, B | D, H, Σ)
```

holds when resource/condition/relation R is required, within horizon/tolerance H, for preserving or enabling dependency D of bearer B.

Need routes include:

```text
Constitutive Need   — persistence/viability/organization
Functional Need     — capability/function
Instrumental Need   — higher-order goal
Role Need           — obligation/institutional function
Epistemic Need      — information required for a task/standard
```

### C8-008
Need ≠ Deficit; a need can be satisfied.

### C8-009
Need ≠ NeedSignal; the representation/detection of a need is another standing.

### C8-010
Need ≠ Want; a bearer can need what it does not want and want what it does not need.

### C8-011
Bare `B needs X` is incomplete without the relevant dependency/horizon unless constitutive viability is clearly intended.

Biological regulation further requires:

```text
NeedStanding
≠ NeedDeficitState
≠ NeedDetectionSignal
≠ Drive/MotivationalState
≠ Action
≠ Consumption
≠ NeedSatisfaction
```

Betley et al. (2015) show need-related neural populations with negative-valence teaching properties; sodium-depletion studies show that physiological state can rapidly reshape incentive valuation.

### C8-012
A physiological need can exist before conscious wanting.

### C8-013
Need state can alter evaluative/action guidance without requiring a new learned preference from scratch.

### C8-014
Homeostatic regulation therefore does not justify `Need = Setpoint = Goal`.

# 4. Want / DesireStanding and Liking

Provisional:

```text
WantStanding(X, B | Σ)
```

holds when X is motivationally attractive/pursuit-relevant for B through grounded motivational organization, increasing tendency to recruit search, attention, approach, persistence or related action.

Keep distinct:

```text
Incentive Wanting
Propositional / Reflective Desire
Craving
Appetite
Task/Goal Pursuit Motivation
```

### C8-015
Want ≠ Need.

### C8-016
Want ≠ Liking.

### C8-017
Want ≠ Preference by identity.

### C8-018
Want ≠ Goal; an urge need not become a committed action-guiding target, and goals can be pursued with weak current wanting.

Hedonic route:

```text
HedonicValenceStanding(X, B | Σ)
```

concerns positive/negative experiential/affective evaluation.

Berridge/Robinson and Smith, Berridge & Aldridge separate motivational `wanting`, hedonic `liking`, and learned prediction-related signals.

### C8-019
`Liking ≠ Wanting ≠ Learning/Prediction`.

### C8-020
Pleasure is one evaluative route, not the universal definition of value.

Tindell et al. (2009) provides a strong hard case: under novel sodium depletion, a cue for previously disliked intense salt acquired strong incentive salience before new positive tasting/learning in that state.

```text
LearnedAssociation + CurrentNeedState
→ dynamically recomputed IncentiveStanding
```

### C8-021
EvaluativeStanding can be dynamically state-dependent.

### C8-022
Current motivation is not merely a fixed stored reward magnitude replayed unchanged.

### C8-023
Need, learned association, wanting and liking are separate but interacting standings.

# 5. PreferenceStanding

```text
PreferenceStanding(x, y, B | C, Σ)
```

holds when bearer/decision role B orders or is grounded as ranking alternative x relative to y under context C.

Preference is comparative. It may be:

```text
strict / weak / indifferent
partial / incomplete
context-dependent
state-dependent
time-dependent
probabilistic at observation level
individual / collective / institutional
revealed / stated / inferred / modeled
```

### C8-024
Preference ≠ Value by identity.

### C8-025
Preference ≠ Choice. Choice is a selection occurrence under a menu/constraints; preference is a comparative standing or inferred relation.

### C8-026
Observed choice does not automatically reveal one stable target preference without a behavioral/modeling bridge.

Samuelson's revealed-preference program supplies one formal bridge from constrained choice to preference restrictions; it does not establish the ontology `choice = preference`.

Tversky & Kahneman (1981) demonstrate predictable preference shifts under framing, and Lichtenstein & Slovic (1971) demonstrate reversals between choice and pricing procedures.

### C8-027
Preference claims require context, elicitation route, time and uncertainty.

### C8-028
Choice may reflect conflict, habit, norm, coercion, satisficing, framing or limited information rather than maximizing one stable preference relation.

### C8-029
Global preference coherence is not constitutive to AgencyStanding.

### C8-033

# 7. RL reward, return and value

Reinforcement learning gives `reward` and `value` precise formal meanings.

```text
RewardSignalStanding(r_t, M | Σ)
```

holds when formal/operational model M constitutes a signal/event as evaluative feedback for a learning/control objective.

```text
RLValueStanding(V, M | Σ)
```

holds when V represents expected cumulative/discounted/average reward or another declared return quantity.

Therefore:

```text
Reward ≠ Goal
Reward ≠ Pleasure
Reward ≠ Need
Reward ≠ Preference
Reward ≠ ValueStanding by identity
RLValueFunction ≠ ValueStanding by identity
Return ≠ intrinsic worth
```

### C8-034
Designer-defined reward can provide genuine formal ActionGuidanceStanding without establishing constitutive/intrinsic value for the bearer.

### C8-035
An RL system can legitimately have a formal objective `maximize expected return` while objective provenance remains externally assigned.

### C8-036
Silver et al.'s `Reward is enough` hypothesis concerns possible generative sufficiency of reward maximization for intelligent abilities; even if successful, it would not establish semantic identity among reward, desire, need, value and goal.

Also:

```text
RewardSignal/Event ≠ ReinforcementEffect
```

### C8-037
Formal reward standing is constituted by the learning/control schema, not by pleasure.

### C8-038
Reinforcement is an effect on learning/behavior, not a synonym for the reward token.

# 9. GoalStanding

MF7 blocked `Goal = Attractor/Setpoint`; MF8-C can now define the positive role.

```text
GoalStanding(G, B | K, Σ)
```

holds when condition/outcome/relation/action-region G has grounded **to-be-attained, maintained, avoided, realized or protected** standing for bearer/role B under action-guiding criterion K, such that it organizes selection, persistence, suppression, planning or evaluation over a declared horizon.

Goal routes can include:

```text
Biological / Viability-Grounded
Learned
Intentional / Represented
Formal Task
Designed
Delegated
Institutional
Collective
```

### C8-042
GoalStanding does not universally require explicit symbolic representation.

Behavioral goal-directedness can be evidenced through sensitivity to outcome value and action-outcome contingency without requiring language-like goal symbols.

### C8-043
Goal ≠ mere future state.

### C8-044
Goal ≠ Attractor. Convergence under dynamics does not establish action-guiding target standing.

### C8-045
Goal ≠ Setpoint. A reference parameter in a controller does not automatically become a goal of the bearer.

### C8-046
Goal ≠ ObjectiveFunction. A goal may be set/constraint-like; an objective may score whole policies/trajectories without naming a single target condition.

Distinguish:

```text
GoalStanding
  = to-be-attained/maintained/avoided target-like action-guiding standing

ObjectiveStanding
  = criterion/function/rule under which alternatives/policies/trajectories
    are evaluated or optimized
```

### C8-047
One goal can admit multiple objectives; one objective can trade among multiple goals.

### C8-048
A formal objective may exist without psychologically represented goal content.

# 11. NormStanding

Norms are not goals.

```text
NormStanding(N, B | Σ)
```

holds when a rule/criterion/constraint has grounded standing as defining correct/incorrect, permitted/forbidden, required/optional, acceptable/unacceptable or better/worse performance for bearer/role B.

Routes include:

```text
Viability / Biological Norm
Functional Norm
Skill/Performance Norm
Designed/System Norm
Institutional Norm
Legal Norm
Social Norm
Moral Norm
Epistemic Norm
```

### C8-051
Norm ≠ statistical regularity.

### C8-052
Norm ≠ Goal; norms can constrain how goals are pursued without themselves being target outcomes.

### C8-053
Biological normativity ≠ moral normativity. `Good/bad` and `ought` claims require a route.

Di Paolo (2005), Barandiaran/Di Paolo/Rohde (2009), and Moreno/Mossio's biological-autonomy framework provide a strong candidate route for constitutive normativity:

```text
self-maintaining organization
→ viability / identity conditions
→ some variations matter for continued organization
→ adaptive regulation relative to those variations
→ constitutive evaluative/normative standing candidate
```

### C8-054
Self-maintenance is a powerful candidate grounding for one form of intrinsic normativity, but MF8-C does not claim it is the only possible route.

### C8-055
A thermostat does not gain constitutive normativity merely because an engineer calls temperature error `bad` for the thermostat.

### C8-056
Whether non-biological systems can generate comparable constitutive norms remains open for later falsification.

# 12. Observer-imputed teleology versus target-grounded evaluation

Surface trajectory shape cannot establish goal standing:

```text
system approaches X
≠ system wants X
≠ X is valuable for system
≠ X is system's goal
```

MF8-C uses an evidence battery.

## E1 — Criterion intervention
Change alleged goal/norm/objective while other structure is sufficiently controlled. Does action organization systematically reorganize?

## E2 — Outcome devaluation
Change outcome value while action mechanics stay available. Does action selection adapt?

## E3 — Need-state modulation
Change physiological/constitutive need state. Do action priorities or incentive standings change specifically?

## E4 — Goal substitution
Can a different target recruit flexible action routes while preserving higher-order guidance?

## E5 — Perturbation compensation
When the normal path is disturbed, does the system vary behavior to preserve the alleged goal/norm rather than merely replay the trajectory?

## E6 — Provenance tracing
Can the criterion be grounded as constitutive, learned, designed, delegated, institutional, etc., instead of being invented after observation?

## E7 — Representation firewall
Is utility/value merely an analyst's fitted latent variable, or is target evaluative standing independently evidenced?

### C8-057
No individual test is universally sufficient; convergence across tests strengthens target-grounded teleology claims.

Rosenblueth, Wiener & Bigelow (1943) remain historically important for behavioristic purpose/feedback analysis, but MF8-C preserves:

```text
negative feedback / error correction
≠ intrinsic bearer GoalStanding automatically
```

### C8-058
PurposefulBehaviorRoleStanding ≠ constitutive bearer GoalStanding.

# 13. There is no universal evaluative pipeline

A tempting chain is:

```text
Value → Utility → Preference → Choice
```

MF8-C rejects it as universal.

Real admissible routes include:

```text

Hedonic liking → Preference
Norm → choice against current Want
Institutional Goal → Delegated Objective → Policy
Preference Relation → Utility Representation
Reward Signal → Learned Policy / RL Value Estimate
Habit → Action with weak current outcome-value sensitivity
```

### C8-059
There is no universal one-dimensional evaluative pipeline.

# 23. Evidence anchors

Primary/authoritative anchors used in MF8-C:

1. **Xabier E. Barandiaran, Ezequiel Di Paolo & Marieke Rohde (2009), `Defining Agency: Individuality, Normativity, Asymmetry, and Spatio-temporality in Action`, Adaptive Behavior 17(5), DOI `10.1177/1059712309343819`.** Individuality, active-source asymmetry and normativity as a strong natural-agency route.
2. **Ezequiel A. Di Paolo (2005), `Autopoiesis, Adaptivity, Teleology, Agency`, Phenomenology and the Cognitive Sciences 4(4), DOI `10.1007/s11097-005-9002-y`.** Adaptivity relative to viability as a candidate grounding of intrinsic biological normativity.
3. **Alvaro Moreno & Matteo Mossio (2015), `Biological Autonomy`, Springer, DOI `10.1007/978-94-017-9837-2`.** Organizational autonomy and self-maintaining norms/goals; retained as one route rather than universal artificial-agent ontology.
4. **J. Nicholas Betley et al. (2015), `Neurons for hunger and thirst transmit a negative-valence teaching signal`, Nature 521, DOI `10.1038/nature14416`.** Physiological need-state mechanisms with motivational/negative-valence learning effects.
5. **Steven B. Tindell et al. (2009), `Dynamic computation of incentive salience: wanting what was never liked`, Journal of Neuroscience 29, DOI `10.1523/JNEUROSCI.2499-09.2009`.** Novel physiological state dynamically recomputes incentive wanting before new positive liking/learning experience.
6. **Kyle S. Smith, Kent C. Berridge & J. Wayne Aldridge (2011), `Disentangling pleasure from incentive salience and learning signals in brain reward circuitry`, PNAS 108, DOI `10.1073/pnas.1101920108`.** Empirical separation among liking, wanting and learned prediction-related signals.
7. **Kent C. Berridge et al. (1984), `Sodium depletion enhances salt palatability in rats`, Behavioral Neuroscience 98, DOI `10.1037/0735-7044.98.4.652`.** Physiological state alters palatability evaluation.
8. **Bernard W. Balleine & Anthony Dickinson (1998), `Goal-directed instrumental action: contingency and incentive learning and their cortical substrates`, Neuropharmacology 37, DOI `10.1016/S0028-3908(98)00033-1`.** Outcome-value/contingency sensitivity anchors goal-directed versus habitual control.
9. **P. A. Samuelson (1938), `A Note on the Pure Theory of Consumer's Behaviour`, Economica 5(17), 61–71.** Revealed-preference bridge from constrained observed choice to preference restrictions.
10. **Gerard Debreu (1954), `Representation of a Preference Ordering by a Numerical Function`, in Decision Processes.** Utility as numerical representation of preference ordering under conditions.
11. **Sarah Lichtenstein & Paul Slovic (1971), `Reversals of preference between bids and choices in gambling decisions`, Journal of Experimental Psychology 89, DOI `10.1037/h0031207`.** Elicitation-route preference reversals.
12. **Amos Tversky & Daniel Kahneman (1981), `The Framing of Decisions and the Psychology of Choice`, Science 211, DOI `10.1126/science.7455683`.** Framing-dependent preference/choice shifts.
13. **Richard S. Sutton & Andrew G. Barto, `Reinforcement Learning: An Introduction`, 2nd ed.** Formal RL reward/value/action framework.
14. **David Silver, Satinder Singh, Doina Precup & Richard S. Sutton (2021), `Reward is enough`, Artificial Intelligence 299, DOI `10.1016/j.artint.2021.103535`.** Reward-maximization sufficiency hypothesis treated as computational, not semantic identity across evaluative concepts.
15. **Arturo Rosenblueth, Norbert Wiener & Julian Bigelow (1943), `Behavior, Purpose and Teleology`, Philosophy of Science 10(1), DOI `10.1086/286788`.** Cybernetic purpose/feedback analysis used while preserving goal-provenance distinctions.

Competing theories remain preserved where evidence does not decide one universal source of normativity.

# 24. MF8-C verdict

```text
VALUE is not the primitive.

 = bearer/role
 + evaluand
 + criterion/norm/dependency
 + better/worse or action-relevant differentiation
 + provenance
 + context/time/scale
 + evidence
```

Then:

```text
Need
 = dependency standing

Want
 = motivational attraction/pursuit standing

Liking
 = hedonic/affective standing

Preference
 = comparative ordering standing

Utility
 = numerical/ordered representation or optimization standing

Reward
 = formal/operational evaluative-feedback standing

Goal
 = to-be-attained/maintained/avoided action-guiding target standing

Objective
 = optimization/evaluation criterion standing

Norm
 = correctness/permissibility/requirement standing

Value
 = typed evaluative significance under a declared criterion
```

The consequence is decisive:

> **A bearer need not be a coherent utility maximizer to be an agent. It may simultaneously carry biological needs, learned wants, hedonic likes, context-sensitive preferences, delegated goals, institutional norms and formal rewards that only partially align. Serious agency claims must preserve which evaluative relation is active and where it came from.**

This also blocks a common artificial-agent category error:

```text
user prompt / reward model / objective function / system instruction
```

may establish formal/delegated evaluative and goal standing, but do not automatically establish:

```text
machine desire / intrinsic value / self-generated goal / autonomous preference.
```
