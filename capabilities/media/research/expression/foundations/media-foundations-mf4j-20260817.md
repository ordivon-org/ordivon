# 1. Problem statement: MF4 is now broad enough to become dangerous

MF4-A→I has admitted:

- objects and fields;
- static and dynamic relations;
- standing specifications and active episodes;
- spatial/temporal compositions;
- multimodal wholes;
- narratives;
- software/modules;
- interactive/control/social systems.

This breadth creates a serious failure mode:

> If any selected set of entities plus any relation can be called a whole, `composition` becomes analytically empty.

MF4-J therefore does not primarily add another domain. It attacks the accumulated ontology itself.

Core question:

> **What distinguishes genuine whole-level organization from an analyst's arbitrary relation bundle, and what roles—if any—should global coherence, Gestalt organization, closure, constraint satisfaction, emergence, robustness and whole-level invariants play in the minimal definition of composition?**

Primary collapses to attack:

`Grouping = Coherence`;

`Closure = Composition`;

`Connectedness = Closure = Wholeness`;

`Local Consistency = Global Consistency = Coherence`;

`Constraint Satisfaction = Coherence`;

`All Constraints Satisfied = Whole`;

`Conflict = Incoherence`;

`Global Descriptor = Whole`;

`Order Parameter = Cause`;

`Global Effect = Emergence`;

`Emergence = Composition`;

`Robustness = Identity`;

`Graceful Degradation = Modularity`;

`Compression = Reality`;

`Predictive Utility = Ontology`;

`Many Relations = One Whole`.

# 2. Coherence must first be separated from composition existence

A broken machine can remain the same composed machine.
A contradictory document can remain one document.
A badly synchronized performance can remain one performance.
A malformed protocol run can remain one interaction episode.

### Result

**CJ-01 — Composition existence and composition quality/coherence are distinct.**

# 7. Gestalt effects matter as whole-to-part evidence, not universal ontology

**CJ-06 — Whole/configural organization can change access to component distinctions while component signal features remain locally unchanged.**

**CJ-07 — `More context` does not universally imply stronger whole processing or better part access.**

**CJ-08 — Global organization can influence local processing, but this is evidence for interaction among levels rather than a universal temporal law.**

**CJ-09 — Global precedence is condition/scale dependent; global processing is not constitutively prior to local processing.**

# 66. Provisional Composition Relevance Criterion (CRC)

For candidate whole `W`, components/roles `U`, organization `O`, scope `Σ`:

```text
CRC(W,O | Σ) holds when:
  1. Grounding: O is supported by physical/dynamic, perceptual, designed,
     conventional, representational, functional or historical evidence
     beyond analyst set-membership alone;
  2. Restriction: O restricts/structures admissible joint states,
     transitions, interpretations, roles or evaluations beyond independent coexistence;
  3. Counterfactual relevance: admissible removal/permutation/violation of O,
     while holding relevant constituents/confounds fixed, changes a declared
     whole-level profile;
  4. Scope stability: the relevance is not produced solely by one arbitrary
     coordinate/name choice and survives the transformations/contrast class
     claimed for W;
  5. Alternative comparison: where ambiguity matters, O distinguishes W from
     plausible alternative partitions/organizations on the claimed profile.
```

### Result

**CJ-65 — CRC is the strongest MF4-J anti-inflation candidate; no single clause alone is sufficient.**

# 162. Revised provisional minimal composition definition after MF4-J

> **A composition is a scope-relative organization in which a plurality of individuated units, regions, states, events or roles are linked by grounded typed relations/constraints whose joint organization nontrivially restricts or structures admissible states, transitions, interpretations, roles or evaluations and is counterfactually relevant to a whole-level identity, capability, content, persistence or evaluation profile.**

Important:

- `plurality` can include fields/regions/processes rather than object atoms;
- `grounded` rejects analyst-only arbitrary predicates;
- `typed` rejects generic edges;
- `nontrivially structures/restricts` rejects tautological relation inflation;
- `counterfactually relevant` rejects incidental relations;
- `whole-level profile` is scope/evaluation typed;
- high coherence/closure/emergence/robustness remain optional profiles.

### Result

**CJ-161 — MF4-J tightens MF4-A rather than replacing it with a new Gestalt/closure primitive.**

```text
CompDef(O, W | Σ)
```

# 167. Global-coherence failure taxonomy

## Arbitrary relation inflation

Analyst-selected relation counted as composition without grounding/relevance.

## Tautological organization

Relation is true of every candidate state and distinguishes nothing.

## Local-global mismatch

Local constraints satisfied while global whole impossible/incoherent.

## False closure

Perceptual/topological/operational/narrative closure types conflated.

## Over-closure

External dependencies/flows ignored to make system appear self-contained.

## Under-closure

Standing internal completion/constraint structure ignored because environment remains open.

## Conflict erasure

Frustrated/competitive/contradictory relations averaged away as `noise`.

## False harmony

Agreement mistaken for coherence.

## Descriptor reification

Centroid/order parameter/summary statistic treated as the whole or causal agent.

## Emergence inflation

Any macro effect labeled irreducible emergence.

## Compression reification

Compact description treated as unique natural ontology.

## Robustness inflation

Perturbation tolerance treated as wholeness/identity itself.

## Fragility denial

Fragile but genuine composition rejected.

## Partition cherry-picking

Candidate grouping evaluated without plausible alternatives.

## Scope laundering

A relation relevant in one task/scale asserted as universal whole identity.

## Grounding collapse

Designed/conventional/perceptual/causal evidence routes conflated or analyst assertion substituted for them.

## Counterfactual confound

Ablation changes multiple variables so relation relevance is not isolated.

## Invariance overreach

One preserved profile generalized to total identity.

## Global-precedence overreach

Specific perceptual timing result universalized into ontology.

## Gestalt-cue overreach

Perceptual grouping cue treated as universal composition criterion.

### Result

**CJ-166 — MF4-J identifies overbreadth/holism failures that were not visible in earlier positive-domain rounds.**

# 168. Primary/original literature anchors

- Pomerantz, J. R., Sager, L. C. & Stoever, R. J. (1977), `Perception of wholes and of their component parts: Some configural superiority effects`, *Journal of Experimental Psychology: Human Perception and Performance* 3(3), 422–435. DOI: 10.1037/0096-1523.3.3.422. Added contexts can improve, impair or leave unchanged component discriminability; strong evidence that relational configuration can alter part processing without supporting a universal `whole always wins` law.
- Navon, D. (1977), `Forest before trees: The precedence of global features in visual perception`, *Cognitive Psychology* 9(3), 353–383. DOI: 10.1016/0010-0285(77)90012-3. Demonstrates global-level precedence/interference in hierarchical visual stimuli under tested conditions; retained as global-to-local evidence, not universal ontology.
- Kinchla, R. A. & Wolfe, J. M. (1979), `The order of visual processing: Top-down, bottom-up, or middle-out`, *Perception & Psychophysics* 25(3), 225–231. DOI: 10.3758/BF03202991. Stimulus-size manipulation argues against invariant global-first/local-first sequence and provides a counterweight to overgeneralized global precedence.
- Kanizsa, G. (1976), `Subjective Contours`, *Scientific American* 234(4), 48–52. DOI: 10.1038/scientificamerican0476-48. Incomplete inducing figures can yield perceived contours absent in the physical luminance boundary; used to separate physical from perceptual completion.
- Elder, J. & Zucker, S. (1993), `The Effect of Contour Closure on the Rapid Discrimination of Two-Dimensional Shapes`, *Vision Research* 33(7), 981–991. DOI: 10.1016/0042-6989(93)90080-G. Shape-search performance varies smoothly with degree of closure in tested displays, supporting graded closure rather than binary universal closure.
- Mackworth, A. K. (1977), `Consistency in Networks of Relations`, *Artificial Intelligence* 8(1), 99–118. DOI: 10.1016/0004-3702(77)90007-8. Separates local node/arc/path consistency from global solution construction; key formal falsifier of `many locally consistent relations = coherent whole`.
- Edwards, S. F. & Anderson, P. W. (1975), `Theory of Spin Glasses`, *Journal of Physics F: Metal Physics* 5(5), 965–974. DOI: 10.1088/0305-4608/5/5/017. Sign-varying interactions generate collective disordered states; used with frustration analyses as a hard case against equating whole organization with simultaneous local harmony.
- Kirkpatrick, S. (1977), `Frustration and ground-state degeneracy in spin glasses`, *Physical Review B* 16, 4630. DOI: 10.1103/PhysRevB.16.4630. Makes unavoidable unsatisfied interactions/frustration explicit in spin-glass ground states; demonstrates structured wholes can contain conflicting local constraints.
- Hopfield, J. J. (1982), `Neural networks and physical systems with emergent collective computational abilities`, *PNAS* 79(8), 2554–2558. DOI: 10.1073/pnas.79.8.2554. Demonstrates content-addressable recovery, error correction and fail-soft collective properties from recurrent network dynamics; used for whole-level capability/robustness, not as universal neural or emergence ontology.
- Haken, H., Kelso, J. A. S. & Bunz, H. (1985), `A theoretical model of phase transitions in human hand movements`, *Biological Cybernetics* 51(5), 347–356. DOI: 10.1007/BF00336922. Relative-phase order parameter/model provides an example of a compact whole-level descriptor tracking coordination regimes, while MF4-J explicitly separates descriptor from ontology/cause.

```text
                  │
                  ▼
          Candidate composition W
                  │

          │                │
          │        coherence / closure /
          │        robustness / emergence /
          │        integration / completion
          │
          └─ can exist even when many quality dimensions fail
```

The central move is:

> **Composition existence is grounded typed whole relevance; coherence/closure/robustness/emergence are optional properties of an already identified organization.**
