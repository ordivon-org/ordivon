# 0. Question

Round C retained `Datafication / Legibility / Metricization` because B-L had already studied measurement/feedback performativity but had not directly audited the earlier transformation by which activity/world state becomes data, categories, metrics and institutionally actionable representations.

D-E asks:

> **Does rendering activity, persons, environments or media processes data-legible introduce a Media-specific primitive beyond observation/measurement, representation/schema, aggregation/composition, state/history, inference/evaluation and institutional use?**

Or is `datafication` a family of pipelines in which selected world/activity distinctions are instrumented, captured, encoded, categorized, aggregated and recruited as proxies/indicators for downstream decisions?

# 2. Datafication is broader than digitization but not one ontology atom

A useful media/organization sense of `datafication` concerns rendering previously unrecorded or weakly formalized activities into data traces suitable for storage, combination, analysis, evaluation or control.

Examples:

```text
clickstream logging
location traces
watch time
scroll depth
work completion events
conversation metadata
heart-rate streams
sensor telemetry
creator analytics
performance dashboards
content moderation labels
agent tool traces
```

These differ substantially in mechanism and target.

Therefore:

```text
Datafication
```

is initially an umbrella over a family of observation/representation pipelines, not evidence of one new primitive.

---

# 3. Digitization ≠ datafication

A paper photograph can be digitized into pixels without thereby making the social activity depicted in it a structured metric system.

A workflow can be datafied through event logs, categories and metrics even if much of the underlying activity remains physical.

Thus:

```text
Digitization
≠ Datafication
```

Digitization concerns representational/material format transformation; datafication concerns systematic capture and recruitment of selected distinctions as data about a target/process.

---

# 4. Target activity can exist without datafication

People can work, communicate, move, create and consume media without a platform logging those activities.

Therefore:

```text
TargetActivity
↛ DataTrace
```

No ontology should identify the activity with its recorded traces.

# 6. Same activity, different instrumentation → different data world

Hold target behavior fixed.

System A records:

```text
completion event only
```

System B records:

```text
completion + duration + retries + location + interaction path
```

Then:

```text
World/ActivityState(A)=World/ActivityState(B)
```

while:

```text
DataficationProfile(A) ≠ DataficationProfile(B)
```

The difference lies in observation/instrumentation selection, not target ontology.

A worker's invisible coordination, emotional labor, informal repair or offline action may be absent from platform traces while remaining causally important.

Organizational analytics research explicitly notes the paradox that organizations gain vast behavioral data while the meaning of those behaviors can become harder to discern; in platform work, organizations often see labor principally through data representing it.

Therefore:

```text
NotLogged
≠ DidNotOccur
```



# 10. Observation ≠ measurement universally

A raw event log may record a categorical occurrence without estimating a magnitude.

Measurement is one structured observation route with scale/calibration/evaluation semantics.

Therefore:

```text
DataCapture
↛ Measurement
```

while many metrics are computed from measurements/counts/traces.

# 11. Measurement ≠ metric

A sensor reading can be a measurement.

A KPI such as:

```text
average handling time
engagement rate
conversion rate
performance score
```

is a derived aggregation/evaluation relation over one or more observations.

Therefore:

```text
Measurement
≠ Metric
```

`42 completed tasks` is a count under some event definition.


# 20. Datafication can alter behavior without being identical to performativity

Instrumentation alone can produce awareness/chilling effects; public metrics can alter incentives; algorithmic management can instruct/monitor/evaluate workers.



# 21. Dataveillance is a surveillance/use specialization



# 97. Strongest legibility counterfactual

Hold target and raw data fixed.

Give observer A a schema/model/view answering query Q; observer B lacks the key/schema or receives an unusable representation.

```text
TargetState(A)=TargetState(B)
RawData(A)=RawData(B)
```

but:

```text
LegibilityForQ(A) ≠ LegibilityForQ(B)
```

The difference is consumer-relative representation/use capability, not a primitive target property.

# 98. Strongest metric counterfactual

Hold observations fixed.

Change aggregation/normalization/weighting.

Thus metric standing is derived from representation/composition/evaluation relations.

Deep result:

> **Datafication is real but is not a primitive transformation by which reality simply becomes data. It is a selective pipeline: target activity/world state is instrumented, some distinctions are captured as traces, traces receive schemas/categories, observations are transformed/aggregated into metrics/features, those representations become legible to particular consumers for particular queries, and only then may enter evaluation, institutional authority or algorithmic action. Every stage is defeasible. Unlogged does not mean nonexistent; logged does not mean understood; measurement is not metric; metric is not construct; score is not rank; legibility is not truth, transparency or governability. The same target can yield different data worlds under different instrumentation, the same data can yield different metrics, the same metric can have different institutional effects, and a powerful metric can be epistemically poor. The general ontology therefore reduces to MF1 observation/measurement + MF3 representation/schema/proxy + MF4 aggregation + MF6/MF7 temporal/state history + B-F selection/ranking + B-L feedback/performativity + Institution/Host authority/governance. No Datafication/Legibility/Metricization primitive survives.**
