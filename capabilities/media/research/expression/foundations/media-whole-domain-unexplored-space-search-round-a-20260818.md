Important pressure revealed by the comparison:

1. **Communication is not exhausted by signal transport.** Speech-act and pragmatic traditions distinguish propositional content from communicative force, contextual inference, speaker/hearer standing, commitments and social/institutional consequences.
2. **Reception is not exhausted by perception.** Encoded structure, actual exposure/encounter, interpretation and response can diverge.
3. **Archive is not merely persistence.** Archival science adds designated communities, preservation responsibility, access, migration and institutional commitments.
4. **Accessibility is not merely perceptual fidelity.** It concerns alternative routes to equivalent/usable functions across sensory, motor and cognitive conditions and often carries social/institutional obligations.
5. **Infrastructure is not merely Network.** Media-infrastructure studies add material maintenance, standards, industrial organization, geography and public dependence, although much generic substrate reality remains owned elsewhere.
6. **Art/work ontology is not identical to representation.** Scores, performances, recordings, editions, oral traditions and mutable/generative works create token/type/work/realization questions.
7. **Ritual/heritage traditions show that mediation can maintain or recreate shared worlds rather than simply transmit packets or propositions.** This is likely Human/Institution/Culture-heavy, but it is a coverage gap.

- XR embodiment and telepresence are rich compositions, not yet primitives.

This comparison already weakens any attempt to make `Computation`, `Platform`, `Recommendation`, `XR`, `Live`, or a traditional medium type the next universal Media foundation merely because it is currently important.

# 8. Unknown continents outside the closeout residual map

The closeout inventory was mostly noun-domain shaped. Round A therefore explicitly searched for **relation-, status-transition- and ecology-shaped** continents. The following were not prominent as standalone residuals in the closeout and should remain visible as `unknown` until destructive tests decide them.

## U1 — Encounter / Exposure Standing

Possible referent:

```text
Availability
→ Addressability / Eligibility
→ Selection / Delivery Opportunity
→ Exposure / Encounter
→ Uptake / Non-uptake
```

Why this matters:

- Network reachability does not imply a person/agent encountered a medium.
- Publication does not imply exposure.
- Exposure does not imply perception/interpretation.
- MF0 requires potential functional uptake, not a complete ontology of actual encounter.
- modern personalized systems make exposure an endogenous result of user action + platform/agent selection.

Current class: `unknown`, plausibly Media-specific cross-cutting residual.

Cheapest falsifier for a later round:

> Construct two cases identical under MF0–MF9 and Network transport standing but differing only in actual exposure/encounter; if no Media-relevant classification, prediction or causal consequence changes, `EncounterStanding` is reducible. If systematic differences survive, the residual is real.

## U2 — Convention / Protocol / Interoperability Standing

Possible referent:

```text
Convention formation
+ participant recognition
+ conformance / deviation
+ version / compatibility
+ interpretation/action interoperability
+ maintenance / institutionalization
```

Examples span natural language, scripts, musical notation, genres, file formats, MIME/media types, social protocols and Agent-to-Agent protocols.

Current class: `unknown / cross-cutting`.

Main ownership conflict: Human + Institution + Network + Runtime/Harness + MF3 representation.

Cheapest falsifier:

> If every case can be represented without loss as MF3 grounding-by-convention plus other-owner protocol/authority state, do not create a Media foundation.

## U3 — Inscription / Fixation / Materialization Standing

Possible referent:

> the transition by which an event, expression, performance, state or representation becomes a manipulable/persistent token with copy/version/derivation consequences.

Oral/live regimes show fixation is not constitutive of Media, but manuscript/print/recording/digital/archive regimes make it structurally powerful.

Current class: `unknown / partially-covered`.

Cheapest falsifier:

> Reduce all fixation cases to MF1 carrier + MF3 representation + MF7 persistence/identity. If no new standing remains, it is a composite profile.

## U4 — Publicness / Addressability / Visibility Standing

Potential distinctions:

```text
private ≠ public
available ≠ discoverable
addressed ≠ broadcast
reachable ≠ visible
visible ≠ encountered
encountered ≠ interpreted
```

This may unify portions of publication, audience formation, broadcast, feeds and agent routing without collapsing into Network transport.

Current class: `unknown / cross-cutting`.

## U5 — Operative / Executable Mediation

Pre-Agent antecedents include commands, scores, instructions, contracts and code. Agent-era systems intensify the phenomenon because symbolic inputs can be autonomously interpreted and converted into actions/tool calls/world changes.

Current class: `unknown / cross-cutting`, with execution itself owned by Runtime/Harness and status/authority effects often owned by Host/Law.

Cheapest falsifier:

> If operative media is fully captured by MF0 functional uptake + MF3 representation + MF8 agency/action + Runtime execution, reject a separate foundation.

## U6 — Context Integrity / Recontextualization Standing

The same preserved bytes can be copied into a different surrounding discourse, audience, authority frame, time, location or provenance chain and thereby change pragmatic force, evidential force or interpretation without changing signal content.

Current class: `unknown / cross-cutting`.

This is not yet obviously reducible to MF3 context fields because redistribution itself may transform the standing that downstream agents assign to the representation.

Cheapest falsifier:

> Show that all recontextualization consequences are fully represented by MF3 context/scope + MF7 provenance + communication/pragmatics specialization. If so, no new foundation.

## U7 — Reflexive Mediation Ecology

Media systems may observe their own audiences, creators and downstream reactions, then adapt selection/production/distribution; creators in turn adapt to the media system.

This existed before digital platforms through ratings, circulation data, editorial feedback and market research, but algorithmic platforms and agents increase loop speed and granularity.

Current class: `unknown / cross-cutting`.

Likely reducible to measurement + dynamics + agency + economics + encounter unless a specifically media-level emergent standing survives.

# 9. Agent-era perturbation

Agent-era systems create major **regime shifts**, but Round A finds no reason yet to posit an `Agentic Media` primitive.

Observed perturbations:

```text
human-readable → machine-readable + machine-actionable
pre-authored → dynamically generated
fixed artifact → mutable/persistent/generative work
one-way publication → negotiated interaction
human audience → human + agent + agent-collective audience
editorial pipeline → autonomous selection/generation/verification loops
static provenance → machine-verifiable provenance/credential chains
shared public object → audience-specific generated variants
separate producer/consumer → recursively coupled producer-consumer agents
```

These perturbations increase pressure on:

- communication standing without human sender/receiver assumptions;
- convention/protocol formation and interoperability;
- encounter/exposure standing;
- artifact/work identity under continuous generation;
- provenance/authenticity;
- authority/delegation and operative mediation;
- context integrity across generated/personalized variants.

But most are currently explainable as richer compositions of frozen MF0–MF9 plus other Ordivon owners. Therefore `Agentic Media` remains `cross-cutting / unknown`, not a selected foundation.

# 11. Cheapest-falsifier queue for Round B

Round B should **not pick a next foundation**. It should attack the residual set in the cheapest order:

1. **Communication reducibility:** can communicative force/common-ground/repair be reduced to MF3 representation + MF8 agency + Human/Institution relations?
2. **Encounter reducibility:** can actual exposure/encounter be reduced to MF0 potential uptake + Network delivery + MF2 perception occurrence?
3. **Artifact/work reducibility:** can token/type/work/edition/live/generative identity be reduced to MF3 + MF4 + MF7?
4. **Convention/protocol reducibility:** can format/language/protocol interoperability be reduced to MF3 convention grounding + Host/Network/Runtime standing?
5. **Meaning/pragmatics boundary:** does MF3 already contain sufficient typed context/grounding, leaving pragmatics wholly social/agency-specialized, or is a new standing missing?
6. **Publication/publicness test:** is publication merely institutionally recognized circulation status, while publicness/addressability/visibility are separate profiles?
7. **Agent-only falsifier:** construct machine-only communicating/curating/consuming agents with no human audience and ask which candidate structures survive.
8. **Oral/live falsifier:** remove persistent artifact, computation and formal institution and ask which candidates survive oral, ritual and improvised performance regimes.
9. **Copy-with-context-change falsifier:** keep exact bytes fixed while changing provenance, framing, audience and authority; determine which lower standing changes.
10. **Same-network/different-exposure falsifier:** hold topology/transport constant while changing curation/addressability/visibility; test whether Media residual is nontrivial.

Only after these destructive tests should the residual map be allowed to nominate any new foundation.
