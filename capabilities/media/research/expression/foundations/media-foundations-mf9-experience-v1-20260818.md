# 1. Canonical minimal standing

```text
ExperienceStanding_v1(E,B|Σ)
=
  ExperienceOccurrenceStanding(E,B|Σ)
+ PhenomenalBearerStanding(B,E|Σ)
+ ExperientialProfileStanding_v1(E|Σ)
+ Occurrence/TemporalStanding(E|MF6,Σ)
+ ExperienceEvidenceStanding_v1(E,B|Σ)
+ Bearer/SubjectPartitionReference(B|Σ)
+ TheoryStackReference(E,B|Σ)
+ GroundingStackReference(E,B|Σ)
+ Provenance
+ Uncertainty
```

`ExperienceOccurrenceStanding(E,B|Σ)` is the phenomenology-facing claim that an experiential / subjectively manifest occurrence is attributed to bearer `B` in scope `Σ`.

It does **not** by definition identify experience with report, access, attention, perception, representation, metacognition, wakefulness, arousal, self-model, agency, one neural marker, one cognitive architecture, one phenomenal-property metaphysics or one mind–matter grounding theory.

# 16. FoundationReopenConditions

## FRC-E1 — Bearerless Experience Counterexample
Reopen if a concrete genuine experience cannot be represented as bearer-/locus-relative under any defensible minimal bearer notion.

## FRC-E2 — Occurrence Ontology Failure
Reopen if a genuine experience cannot be represented under MF6-compatible occurrence/state-token semantics.

## FRC-E3 — Content Ontology Failure
Reopen if decisive evidence establishes a necessary content form excluded by v1 or a genuine case cannot fit rich/reduced/minimal/indeterminate/contentlessness statuses.

## FRC-E4 — Universal Subject-Individuation Criterion
Reopen if a theory-neutral invariant uniquely determines subject count/boundary across ordinary brains, split brains, distributed nervous systems, nested AI and collective systems.

## FRC-E5 — Subject/Bearer Partition Failure
Reopen if a genuine case requires a subject relation not expressible by distinct/nested/overlapping/fused/fissioned/derived/composite structures.

## FRC-E6 — Grounding-Neutrality Failure
Reopen if decisive evidence forces one grounding ontology in a way that changes the definition of ExperienceStanding rather than merely filling a theory field.

## FRC-E7 — Property-Realism Target Failure
Reopen if realism/illusionism resolution makes occurrence/property-status separation incoherent.

## FRC-E8 — Scalar Completeness
Reopen if one theory-neutral scalar proves sufficient and invariant across all major experiential regimes, materially falsifying the multidimensional/partial-order foundation.

## FRC-E9 — Evidence-Architecture Failure
Reopen if a validated evidence route demonstrates a missing necessary evidence class or systematically invalidates current positive/negative evidence asymmetry.

## FRC-E10 — Substrate-Transfer Failure
Reopen if evidence establishes universal substrate necessity or universal organization-only sufficiency that changes grounding-neutral bearer rules.

## FRC-E11 — Lower-Foundation Contradiction
Reopen MF9 and a lower foundation only when a concrete Experience counterexample directly contradicts frozen MF2–MF7 ontology rather than requiring a specialization.

## FRC-E12 — Agency Necessity / MF8 Coupling
If evidence establishes ExperienceStanding as necessary for every genuine AgencyStanding route, trigger MF8 FRC-A10.
