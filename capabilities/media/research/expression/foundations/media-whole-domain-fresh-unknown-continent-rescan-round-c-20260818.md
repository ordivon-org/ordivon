# 7. C-U2 — Interface / Affordance / Action-Coupling Standing

## 7.1 Why this is not merely U1

An interface can mediate action even when no discrete representation is interpreted as an instruction.

Examples:

```text
button
slider
steering control
touch surface
VR hand controller
haptic boundary
GUI hit region
robot control panel
voice interface
adaptive agent interface
```

The relation is not necessarily:

```text
message → execute message
```

but rather:

```text
perceived/actionable boundary
+ available action set
+ mapping from user/system action to downstream state transition
```

## 7.2 Existing deep coverage

MF4 already says:

```text
CausalInfluence ≠ Response ≠ Interaction ≠ Feedback ≠ Control ≠ Coordination
```

MF5-F deeply reconstructs actor-relative affordances/action possibilities:

```text
PossibleAction ≠ Affordance ≠ ChosenAction
Affordance ≠ geometric reachability
Affordance depends on actor capability × environment
```

MF5-G already notes:

```text
Designed interface space can be both representational and action-spatial.
```

Thus Interface is **not unexplored from zero**.

## 7.3 What remains unclosed

What has not received whole-domain closure is the specific Media/HCI claim that an interface is a relation which:

```text
selectively exposes possible actions
maps action to system transition
provides perceptual feedback
constrains reachable state space
can hide underlying implementation
```

and therefore can be a mediation layer even when neither side shares internal semantics.

MIT Press interface theory explicitly treats interface as a relationship/encounter between user and technology rather than merely a visible screen.

## 7.4 Strongest prospective falsifier

Hold fixed:

```text
actor capability
environment/system dynamics
available transitions
perceptible distinctions
representation content
mapping from action to transition
feedback
boundary/scope
```

and ask whether `InterfaceStanding` can still vary.

Current class:

```text
PARTIALLY DEEP / HIGH-VALUE DIRECT AUDIT
```


Elemental-media theory pushes even further, treating environments/infrastructures such as:

```text

```

as media or media-like world-organizing conditions.

## 9.2 Why Round A ownership labels were not enough

Round A said infrastructure is not merely Network and likely has external owners.

But ownership classification does not answer the ontological boundary question:

> **When does an enabling infrastructure/environment itself instantiate MediaRole, versus merely providing the physical/social condition in which MediaRole is realized?**

This goes directly to MF0.

## 9.3 Potential MF0 pressure

MF0 currently requires approximately:

```text
Distinction
+ Structured Mediation
+ Potential Functional Uptake
```

with mere causation rejected as too broad.

An expansive elemental-media definition risks admitting almost any environment that structures action.

The strongest challenge is therefore not `infrastructure is important`.

It is:

> **Can we construct an authoritative cross-regime case accepted as Media where no relevant distinction/recruitment standing exists, only enabling/conditioning structure?**

If yes, MF0 may face a real FRC.
If no, environmental/infrastructural media can be reconstructed as:

```text
World/Network/Runtime/Institution substrate
+ specific MediaRoles instantiated within/through it
```

## 9.4 Important separation

```text
Media Infrastructure
≠ Infrastructure that happens to host media
≠ MediaRole
≠ Network transport
≠ Environment
```

A data center can be essential to a streaming service while an individual cooling pipe need not itself instantiate a MediaRole under every scope.

Current class:

```text
UNKNOWN / VERY HIGH BOUNDARY PRESSURE
```

This region may have more foundational information value than another downstream concept reduction because it attacks the Media/non-Media boundary itself.

# 21. Media theory boundary confrontation

Round C identifies two competing broad intuitions:

## Narrow/role-based intuition

A thing/process is Media in a scope when structured distinctions are mediated and available for functional recruitment.

This is close to MF0.

## Expansive/environmental intuition

Media include infrastructures/elements/environments that condition or organize relations among humans, technology and world even when not foreground messages.

This appears in elemental/environmental/infrastructure media theory.

The rescan must not decide this by terminology.

The decisive test is:

> **Can the expansive cases be decomposed into enabling substrate plus specific recruited distinctions/constraints/relations, preserving MF0; or do accepted Media cases remain in which no such MediaRole exists?**

This is now one of the highest-value remaining foundational questions.

# 26. Research anchors used in the fresh scan

Representative external theory/evidence anchors include:

- John Durham Peters, *The Marvelous Clouds* (2015) — expansive/elemental Media account in which environments/infrastructures can function as media, pressuring a message/object-only ontology.
- Lisa Parks, Julia Velkova, Sander De Ridder et al., *Media Backends: Digital Infrastructures and Sociotechnical Relations* (2023) — sensors, digital assistants, algorithms, data centers and hidden infrastructure as systems organizing how digital media become media.
