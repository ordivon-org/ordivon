# Media Foundations

This directory contains the deeper first-principles reconstruction of Ordivon's Media World Model.

It is deliberately below the older M7 medium-profile program. M7 (`Writing / Still Visual / Audio / Motion / Interactive / Spatial / Live`) remains valid historical experiment/evidence about production profiles, but those categories are **not** treated as ontological primitives here. The MF program asks what makes mediation, signal, perception, representation, composition, space, time, state, agency, experience, sociality, computation, distribution and governance possible before rebuilding Studio/Web/Game/XR consumption layers.

## Research discipline

1. Decompose overloaded labels into typed primitives/relations.
2. Separate phenomenon, computational problem/model and implementation.
3. Cross-check with primary/authoritative literature.
4. Attack each theory with counterexamples before freezing.
5. Preserve uncertainty and competing theories when evidence does not decide.
6. Keep observed/preserved/inferred/generated content epistemically distinct.
7. Do not prematurely engineer Studio/Web/Game/XR from provisional foundations.
8. Treat finite resources as a recurring distinction-allocation problem, but reject the abstraction if MF2-I shows it has become vacuous.
