# 2. MF0 — Media Ontology (FROZEN)

## Core result

A medium is **not a natural object class**. `X` plays a medium role relative to a relation/context. The same entity may simultaneously function as Carrier, Artifact, Interface, Tool, Medium, Runtime component or Agent component.

Minimal candidate:

`Distinction + Structured Mediation + Potential Functional Uptake`

A mere causal chain is too broad. **Uptake / Recruitment** requires a downstream system to use variation *as a distinction* for perception, detection, inference, control, interpretation, memory, decision, communication or action.

Working mediation episode:

`E = <Distinction, Carrier, Transformation, Coupling, Recruitment, Agent/System, Context, Time>`

Representation, artifact, runtime, agency, persistence, network, conscious observer and intentional sender are optional rather than constitutive.

## Mediation depth

- M0 Physical/Causal

## Functional reading

A system reads a distinction when its future organization or behavior depends counterfactually on which member of that distinction is instantiated because that variation has been recruited into a functional relation.

## Representation / agency boundary

Representation is a functionally recruited state serving as a proxy for another state/domain under correctness conditions. `Agency ⟂ Representation`: they are orthogonal. Agency is provisionally goal/norm-relative closed-loop action selection; autonomy remains separate.

## Tool / Medium distinction

- Tool: Agent intention/action → World effect.
- Medium: Difference/World state → Agent/System-accessible difference.

Interactive systems may play both roles.

# 3. MF1 — Signal Foundations v1 (FROZEN)

## MF1-A — Signal ontology

- Reality ≠ Signal.
- Measurement selects an observable; it is model-mediated.
- General signal can be written `x:D→V`; D need not be time and V need not be scalar.
- Signal role = structured variation + discriminative recruitment.
- Signal ≠ Measurement ≠ Symbol ≠ Semantic meaning.
- Channel is the constrained relation through which distinctions propagate between boundaries.
- Media transformation can be understood as reorganization of distinguishability: for `T:X→Y`, `x_i ~ x_j` iff `T(x_i)=T(x_j)`.

## MF1-B — Sampling / observation

General observation is `y_n = L_n[x] + ε_n`, not necessarily point sampling.

- Sampling = choosing what questions can be asked of Reality.
- Recoverability depends on Observation Operator × Source Class.
- Aliasing = non-identifiability / distinction collapse.
- Injectivity/uniqueness and stability/conditioning are distinct.
- Nyquist is a theorem for constrained signal classes, not a universal ontology.
- AI reconstruction cannot recover distinctions absent from evidence; priors select plausible states within ambiguity classes.

## MF1-C — Quantization / precision

Quantization is a state-space partition: intentional equivalence classes over values.

- Bit depth ≠ measurement resolution ≠ precision ≠ trueness ≠ accuracy ≠ uncertainty.
- ENOB ≠ bits of Reality.
- Clipping is severe irreversible collapse.
- Non-uniform quantization is resource allocation over distinctions.
- Dither may trade structured nonlinear error for controlled stochastic uncertainty.

## MF1-D — Noise / uncertainty

General stochastic transformation: `Y ~ p(y|x)`.

Noise, randomness, error, bias, distortion and uncertainty are distinct. SNR is only a bounded summary. Detection, estimation, communication and reconstruction are all inference across stochastic mediation. Redundancy only helps against variation that the redundancy makes distinguishable.

## MF1-E — Transform / spectrum

Transform is representation/coordinate choice. Invertible transforms can radically change visible structure while preserving information. Sparsity, locality and complexity are representation-relative. Fourier coordinates are privileged by LTI/time-translation symmetry, not by metaphysical status.

## MF1-F — Coding / channel

Coding = engineered geometry of symbolic distinctions.

- Source coding = packing / removing predictable source redundancy.
- Channel coding = spacing / deliberately adding protective redundancy.
- Redundancy is a resource, not inherently waste.
- Capacity is reliable distinction rate under a channel law and constraints.
- Noise model ≠ adversary/security model.

## MF1-G — Compression / sufficiency

Lossless compression preserves all source distinctions while using shorter descriptions. Lossy compression intentionally collapses distinctions under an explicit distortion/value/task criterion.

Key distinctions:

- Recovery ≠ inference ≠ generation.
- Realistic/plausible ≠ faithful/source-grounded.
- Signal fidelity ≠ perceptual fidelity ≠ task fidelity.
- Reconstruction sufficiency ≠ perceptual sufficiency ≠ task/action sufficiency.
- Task specialization trades efficiency against future optionality.
- Decoder priors can synthesize plausible detail but cannot turn collapsed source distinctions into evidence.

## MF1-H — falsification/reconstruction

Camera RAW, PCM/audio, JPEG, video coding, streaming, event cameras, LiDAR, biological sensing, AI embeddings and generative reconstruction were used as falsifiers.

Required extensions survived:

- Observation can be stateful/context-dependent.
- Active observation/probing is required: `Y_t ~ p(y_t | X_t, U_t, C_t, Θ)`.
- Temporal utility/deadlines matter: correct information can arrive too late to be functionally useful.
- Evidence provenance is a first-class audit axis: directly observed / preserved / inferred / prior-generated.

Signal Foundations v1 therefore treats Signal World as **Distinction Flow** through selective, lossy/stochastic, resource-bounded transformations.

# 4. MF2 — Perception Foundations A–H (NOT YET FROZEN)

## MF2-A — Perception ontology

Perception is not Signal, Recognition or Conscious Awareness.

Working view: adaptive, embodied, action-coupled use/organization of sensory evidence into organism-available world/body-relative structured states.

Key distinctions:

- Distal state ≠ proximal stimulus.
- Receptor/transduction is selective and stateful.
- Perceptual processing ≠ conscious awareness.
- Perception ≠ semantic recognition.
- Bayesian reconstruction/inference and ecological/action-coupling are candidate model families, not ontology mandates.
- Modality is multilayered: physical carrier, receptor, neural pathway, represented variable, perceptual function and phenomenology must not be collapsed.
- Perception is a loop: action changes future evidence.

## MF2-B — Psychophysics / sensitivity

Perceptual sensitivity is probabilistic, nonlinear, contextual and adaptive.

- Threshold is generally an operational criterion on a psychometric function, not a literal hard sensory wall.
- JND/discrimination differs from subjective magnitude scaling.
- Weber relation, Fechner law and Stevens power law are distinct empirical/model structures with limited domains.
- Sensitivity ≠ decision criterion; response frequency cannot be read directly as sensory sensitivity.
- Physical geometry ≠ signal geometry ≠ perceptual discrimination geometry.
- Adaptation, masking, attention and context dynamically reshape local sensitivity.

Perception therefore uses an adaptive metric rather than a fixed ruler over Reality.

## MF2-C — Sensory encoding / efficient coding

Sensory representation is a resource-constrained distinction-allocation problem shaped by environmental statistics, noise, neural/metabolic/time budgets, body and task/action relevance.

- Efficient coding is typed: range, statistical, information, metabolic and task/action efficiency are different.
- Redundancy reduction, decorrelation, whitening, sparse coding, gain control, divisive normalization and adaptation are candidate mechanisms/strategies, not universal objectives.
- Information efficiency ≠ biological utility; probability ≠ importance.
- Adaptive codes introduce coding-context ambiguity; downstream interpretation may require encoder/adaptation state.
- Feature detectors can be understood as directions/regions of sensory distinction space made explicit by an encoding geometry.

## MF2-D — Perceptual organization / Gestalt

Perception does not merely encode distinctions; it organizes **relations among distinctions**.

- Gestalt factors (proximity, similarity, good continuation, common fate, closure) are competing structural evidence, not absolute laws/checklists.
- Edge ≠ contour ≠ boundary ≠ object boundary.
- Grouping, segmentation, contour, region/surface, border ownership, figure-ground, completion and proto-object are distinct levels.
- Local signal does not determine global organization alone; border ownership and illusory/completed contours are key falsifiers.
- Whole = Parts + Relations + Higher-order constraints.
- Object organization ≠ semantic recognition.
- Proto-object is a presemantic coherent unit that can be selected/tracked/acted upon.

## MF2-E — Constancy / invariance / persistence

Constancy ≠ invariance ≠ equivariance ≠ correspondence ≠ persistence.

- Good perception is not maximum invariance.
- Useful representation is stable to nuisance transformations while preserving/sensitively transforming task-relevant variables.
- Type identity ≠ token identity.
- Same object means continuity, not equality of appearance.
- Token identity is historical/spatiotemporal and may persist through occlusion via latent state.
- Object files / perceptual pointers are temporary continuity handles over changing state.
- Correspondence can be uncertain and observationally non-identifiable.

Perceptual object is provisionally a spatiotemporally organized persistent integration handle over changing observations.

## MF2-F — Multisensory integration / causal inference

Cue combination must first solve whether cues should be combined.

- Binding ≠ integration ≠ fusion.
- Reliability weighting is conditional on a common-cause model.
- Common cause is probabilistic; congruence is evidence rather than identity.
- Perceptual cause need not be an object: it may be an event, interaction or process.
- Spatial grouping, temporal correspondence and crossmodal causal binding unify provisionally as latent-source assignment across `Space × Time × Modality`.
- Modality is not the final organizational unit; multiple observations from one modality may map to different causes and different modalities may map to one cause.
- Multisensory coherence is distinct from per-channel signal fidelity.

## MF2-G — Prediction / priors

Prior ≠ prediction ≠ expectation ≠ context ≠ top-down signal.

- Priors are accumulated reusable world structure.
- Prediction is model-conditioned representation/distribution of unobserved or not-yet-observed state.
- Prediction error ≠ surprise.
- Prior influence should be uncertainty/precision-sensitive.
- Bayesian inference ≠ predictive-coding implementation.
- Expectation effects on choice do not automatically prove sensory/perceptual changes; decision criterion is a competing explanation.
- Strong priors help under ambiguity but can generate bias/false-positive percept-like states when miscalibrated.
- Perceptual content and evidence-grounding are separate axes.
- Learning must not write prior-generated/inferred content back as independent external evidence.

Deep result: a world model is useful because it constrains perception, but remains a model only if Reality can still correct it. Mature perception requires **calibrated revisability**.

## MF2-H — Attention / selection / salience

Attention is selective allocation/biasing of finite perceptual, cognitive and information-acquisition resources.

Strict distinctions:

- Attention ≠ Salience.
- Salience ≠ Priority.
- Attention ≠ Gaze.
- Attention ≠ Awareness.
- Expected ≠ Attended.
- Surprising ≠ Important.

Priority is an integrated selection state that may combine bottom-up distinctiveness, task relevance, learned value/history, uncertainty/information value, temporal urgency, action relevance and cost. This is an ontology-level decomposition, not a literal biological scalar equation.

Attention can be:

- spatial;
- feature-based;
- object-based;
- temporal;
- cross-modal/event/hypothesis selective;
- covert (processing changes without sensor movement);
- overt/active (gaze/head/body/sensor orientation changes future evidence).

Biased competition, normalization and neural priority-map theories are important model/mechanism families but must not be frozen as one universal neural algorithm.

Inattentional blindness and attentional blink reveal severe selection/access capacity limits, but no-report cannot automatically be equated with absence of all unconscious sensory processing. The exact necessity/sufficiency relationship between attention and conscious awareness remains unresolved and belongs partly to later Experience foundations.

Deep result:

`Attention = control of scarce perceptual and information-acquisition capacity.`

`Priority = current estimate/order of where that capacity is most worth spending.`
