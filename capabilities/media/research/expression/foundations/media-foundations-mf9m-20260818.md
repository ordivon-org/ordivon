# 34. FoundationReopenConditions for MF9 Experience Foundations v1

MF9 is frozen only under explicit reopen conditions.

## FRC-E1 — Bearerless Experience Counterexample

Reopen if there is a concrete, coherent case of genuine ExperienceStanding that cannot be represented as bearer-/locus-relative under **any** defensible minimal `PhenomenalBearerStanding`, including selfless/nondual cases.

## FRC-E2 — Occurrence Ontology Failure

Reopen if a genuine experience case cannot be represented as an occurrence/episode/state token under MF6-compatible occurrence semantics without distorting the phenomenon.

## FRC-E3 — Mandatory Content Failure

Reopen if decisive evidence establishes either:

```text
all ExperienceStanding requires one specific content form
```

or a genuine experience that cannot be represented by the current rich/reduced/minimal/indeterminate/contentlessness status space.

## FRC-E4 — Universal Subject-Individuation Criterion

Reopen if decisive evidence establishes a theory-neutral invariant that uniquely determines subject count/boundaries across ordinary brains, split brains, distributed nervous systems, nested AI and collective systems, making current partition neutrality materially incorrect.

## FRC-E5 — Subject/Bearer Partition Failure

Reopen if a concrete bearer case requires a subject relation not expressible as distinct/nested/overlapping/fused/fissioned/derived/composite candidate structures.

## FRC-E6 — Grounding-Neutrality Failure

Reopen if robust empirical/theoretical evidence decisively rules the broad GroundingStack into one necessary ontology in a way that changes the definition of ExperienceStanding rather than only filling a theory field.

## FRC-E7 — Property-Realism Target Failure

Reopen if realism/illusionism resolution shows that the current occurrence/property-status separation is incoherent—e.g. experience occurrence cannot be coherently retained independently of classic phenomenal-property realism or its rejection.

## FRC-E8 — Scalar Completeness Failure

Reopen if a single theory-neutral scalar is demonstrated to be sufficient and invariant for all relevant experiential comparisons across dream, anesthesia, DoC, psychedelics, MPE, development and cross-bearer cases, invalidating the profile/partial-order foundation.

## FRC-E9 — Evidence-Architecture Failure

Reopen if a validated evidence route demonstrates that the current evidence dimensions omit a necessary class of evidence or that positive/negative evidence asymmetry is systematically wrong.

## FRC-E10 — Substrate-Transfer Failure

Reopen if biological/artificial transfer evidence establishes a universal substrate necessity or universal organization-only sufficiency that materially changes the grounding-neutral bearer rules.

## FRC-E11 — Lower-Foundation Contradiction

Reopen MF9 and the relevant lower foundation only if a concrete Experience hard case demonstrates an actual contradiction with MF2–MF7 frozen ontology rather than a consumer-layer specialization.

## FRC-E12 — Agency Necessity / MF8 Coupling

If future evidence establishes that every genuine `AgencyStanding_v1` necessarily requires ExperienceStanding, trigger **MF8 FRC-A10**. This does not follow from current MF9 results.
