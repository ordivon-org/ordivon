# 0. Why B-M matters

Translation / Remediation is the last known residual inherited from the Round-A/B residual map.

It is qualitatively different from prior candidates because it directly attacks the meaning of **preservation across transformation**:

```text
language → language
text → speech
speech → text
image → description
video → captions / transcript / audio description
sound → notation
2D → 3D
live → recorded
interactive → non-interactive
human-readable → machine-readable
format A → format B
protocol/domain representation A → B
novel → film
work → adaptation
```

The central question is not whether such transformations are useful.

It is:

> **Does Translation / Remediation require a Media-specific primitive beyond MF1 transformation, MF3 typed representation/equivalence, MF4 composition/realization, MF5/MF6 geometry/time, MF7 identity/lineage, MF8 agency, and Human/Institution/Runtime/Network specialization?**

Or is the real ontology a typed transformation together with an explicit preservation/adequacy contract?

# 3. Translation is not one transformation family

A classic useful taxonomy distinguishes roughly:

```text
intralingual reformulation
interlingual translation
intersemiotic transformation
```

but B-M does not adopt these as primitive categories.

They merely demonstrate that ordinary `translation` usage spans transformations among:

```text
expressions within one language
languages
semiotic/modal systems
```

and therefore cannot be defined solely as word substitution between languages.

---

# 4. Translation does not require byte/material similarity

Obvious counterexample:

```text
English UTF-8 source
→ Chinese UTF-8 target
```

or:

```text
spoken utterance
→ written translation
```

Physical/code similarity may be near zero while substantial propositional/reference content is preserved.

Thus:

```text
MaterialSimilarity
↛ TranslationAdequacy
```

MF3 already permits content preservation through material/code transformation.

---

# 5. Byte identity does not imply translation identity

The same byte sequence can be interpreted under different:

```text
encoding
schema
language
namespace
quotation/context role
```

and may acquire different content.

Thus even identical bytes do not establish that source and target preserve the same content relation.

B-G/MF3 already cover context-sensitive grounding.

---

# 6. Literal-form preservation ≠ semantic preservation

A word-for-word mapping can preserve local lexical correspondences while producing a target expression that fails to preserve the intended proposition/reference/pragmatic use.

Conversely a target may depart strongly from source surface form to preserve use/content.

Therefore:

```text
SurfaceFormFidelity
≠ SemanticAdequacy
```

No universal literalness criterion survives.

---

# 7. Semantic/propositional preservation ≠ style preservation

B-G already identified:

```text
content
style
register
stance
pragmatic force
```

as distinct.

Two target expressions can preserve approximately the same propositional claim while differing in:

```text
formal/informal register
rhythm
rhyme
voice
tone
social indexicality
irony
politeness
```

Therefore:

```text
SemanticEquivalence
↛ StyleEquivalence
```

---

# 8. Style preservation can trade against literal semantic form

Poetic, rhetorical and idiomatic translation can deliberately alter literal form to preserve:

```text
rhythm
humor
rhetorical force
register
genre expectation
```

This creates multi-objective preservation rather than one scalar fidelity.

No one priority ordering is universal.

---

# 9. Pragmatic force ≠ propositional content

B-G already froze:

```text
SemanticContent ≠ IllocutionaryForce ≠ PerlocutionaryEffect
```

Translation inherits this.

A warning can preserve its factual proposition while becoming less urgent/polite/authoritative in the target context.

Thus:

```text
PropositionPreserved
↛ PragmaticForcePreserved
```

---

# 10. Reference can require contextual transformation

Dates, units, deictics, institution names, cultural references or local conventions may need target-context transformation to preserve intended reference/use.

Therefore preserving the exact source expression may fail to preserve the same referential standing for a target audience.

This reduces through:

```text
MF3 reference/context grounding
+ B-G ContextPreservationProfile
```

not a new translation primitive.

---

# 11. Translation does not guarantee consumer interpretation identity

Even an excellent translation can be interpreted differently by consumers with different knowledge, goals or cultural contexts.

Thus:

```text
TranslationAdequacy
↛ SameConsumerInterpretation
```

Human interpretation remains separate from grounded content standing.

---

# 12. Same consumer effect is not necessary for translation

Different consumers can react differently to the same source as well.

Therefore requiring identical emotional/behavioral outcomes would make ordinary same-language copying fail equivalence.

Thus:

```text
PerlocutionaryEffectIdentity
```

cannot be the universal criterion.

---

# 13. Same effect is also not sufficient

Two unrelated messages can accidentally produce the same behavior.

Therefore:

```text
SameDownstreamEffect
↛ SameMeaning / TranslationRelation
```

Function/effect equivalence and content equivalence remain distinct.

---

# 14. Translation need not be invertible

A target language/expression can collapse distinctions present in the source, or one target expression can be compatible with several source readings.

Therefore:

```text
Translate(A→B)
```

does not imply a unique inverse:

```text
Translate(B→A) = A
```

Translation is generally not an isomorphism.

---

# 15. Back-translation ≠ identity test

A round trip:

```text
A → B → A'
```

can yield:

```text
A' ≠ A in form
```

while preserving important content, or accidentally reproduce surface wording despite lost pragmatic/contextual information.

Therefore back-translation is evidence under a declared profile, not a universal identity theorem.

---

# 16. Translation-of is not necessarily symmetric

If B is a translation of A, A is normally not called a translation of B merely because a semantic relation exists.

The relation contains:

```text
source/target direction
transformation history
provenance
```

Therefore:

```text
TranslationOf(B,A)
```

is a typed asymmetric lineage relation, not merely an equivalence class.

This directly matches B-E's rejection of one symmetric Work equivalence class.

---

# 17. Translation-of is not universally transitive

Suppose:

```text
A → B preserves dimensions P1
B → C preserves dimensions P2
```

If `P1 != P2`, C may no longer adequately preserve the dimensions required relative to A.

Therefore:

```text
AdequateTranslation(B,A,P1)
∧ AdequateTranslation(C,B,P2)
↛ AdequateTranslation(C,A,P1)
```

without extra conditions.

Chain translation can accumulate typed loss/gain.

---

# 18. Equivalence itself may not be an equivalence relation

The word `equivalence` often suggests reflexive/symmetric/transitive mathematics.

But practical translation/remediation relations can be:

```text
asymmetric
purpose-relative
directional
lossy
partial
thresholded
multi-objective
```

Therefore use:

```text
PreservationRelation
AdequacyRelation
TransformationRelation
```

when mathematical equivalence properties are not proven.

This is a major B-M correction.

---

# 19. One source can have many valid translations

Different targets can legitimately prioritize:

```text
literal content
readability
style
terminology
pragmatic force
accessibility
performance constraints
```

Therefore:

```text
SourceRepresentation
↛ UniqueCorrectTarget
```

A typed adequacy set is more realistic than unique canonical translation.

# 20. One target can correspond to several sources

Compression, paraphrase, normalization or target-language underspecification can make multiple distinct sources map to the same target representation.

Thus:

```text
TargetIdentity
↛ SourceIdentity
```

Transformation provenance remains essential.

# 21. Translation can add information

Translator notes, explicitation, unit expansion, contextual clarification or accessibility descriptions can introduce target content not explicitly present in the source surface representation.

Therefore:

```text
Translation
≠ pure information-conserving channel
```

Added content must be typed as:

```text
source-grounded inference?
translator addition?
contextual explanation?
accessibility description?
```

and provenance preserved.

---

# 22. Translation can deliberately omit information

Summarized/adapted translation may omit repetition, cultural detail or low-priority content.

Then it is inappropriate to claim total content equivalence.

Use:

```text
PreservedDimensions
KnownLosses
```

rather than binary fidelity.

---

# 23. Omission is not automatically error

MF3 already established abstraction as selective omission/equivalence rather than automatic error.

A purpose-specific translation/remediation may validly omit dimensions irrelevant to the declared objective.

Therefore:

```text
Loss
≠ Failure universally
```

Failure is criterion-relative.

---

# 24. Addition is not automatically distortion

Audio description necessarily adds narrated linguistic material to convey important visual information through an auditory route.

Captions can add explicit labels for non-speech sounds that were not lexical text in the original audio.

Thus:

```text
TargetContainsNewSymbols
↛ Distortion
```

if the additions preserve/access source information under the declared purpose.

---

# 25. W3C accessibility provides a decisive cross-modal hard case

WCAG 2.2 requires text alternatives for non-text content that serve an **equivalent purpose**, with distinct rules for controls, tests, sensory experiences and time-based media.

This is strong evidence that:

```text
CrossModalAdequacy
```

is purpose/profile-relative rather than pixel/signal identity.

A text alternative to an image need not recreate the image's sensory realization; it must support the relevant purpose/information under the requirement.

---

# 26. Sensory experience falsifies universal full equivalence

WCAG explicitly treats content whose primary purpose is a particular sensory experience differently: a text alternative may identify/describe the content rather than reproduce the sensory experience itself.

Therefore:

```text
AccessibleAlternative
↛ SamePhenomenalExperience
```

and no cross-modal ontology should require experience identity.

MF9 remains separate.

---

# 27. Controls show purpose/function can dominate appearance

For non-text content that is a control/input, WCAG requires an accessible name describing its purpose.

Thus an accessible remediation can preserve:

```text
control identity / operation purpose
```

while discarding the exact visual appearance.

Therefore:

```text
FunctionalAdequacy
≠ VisualEquivalence
```

---

# 28. Captions ≠ subtitles ≠ transcript

W3C Media Accessibility requirements distinguish captions as same-language alternatives for audio that include dialogue/narration plus important non-speech information such as sounds/music/laughter.

Foreign-language subtitles serve a different translation function.

A transcript is another representation and can support different users; it is not simply interchangeable with synchronized captions.

Therefore:

```text
Caption
Subtitle
Transcript
```

are different remediation profiles.

---

# 29. Synchronization itself can be preserved information

For time-based media, timing matters.

A plain unsynchronized transcript may contain the words yet fail to preserve:

```text
when an utterance occurred
which visual action it aligned with
when an interactive action was available
```

Thus:

```text
LexicalContentPreserved
↛ TemporalAlignmentPreserved
```

MF6 is required.

---

# 30. Audio description ≠ transcript

Audio description adds narration of visual details—actions, characters, scene changes, on-screen text and other important visual information.

A transcript primarily textualizes spoken/non-speech/time-based information under its own profile.

Therefore:

```text
AudioDescriptionProfile
≠ TranscriptProfile
```

They preserve different dimensions through different modalities.

---

# 31. Full media alternative can preserve more than one modality

W3C's alternative for time-based media can include correctly sequenced textual descriptions of visual and auditory information.

This shows a target can be a **new composite representation** that explicitly integrates distinctions originally distributed across several modalities.

MF4 composition, not a new Remediation primitive, naturally handles this.

---

# 32. Interaction is a decisive falsifier against content-only equivalence

W3C requires that when synchronized media contains interaction, an alternative for time-based media provide means to achieve the outcomes/options of that interaction.

Therefore preserving only:

```text
words
images described
sounds described
```

may still be inadequate.

Need also preserve:

```text
ActionAffordance / Outcome Capability
```

This is a strong result:

```text
RepresentationalContentEquivalence
≠ InteractiveFunctionalEquivalence
```

# 48. Migration and emulation preserve different dimensions
