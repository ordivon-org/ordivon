

# 2. First destructive test — the definition fork

Try to define one universal `CommunicationStanding`.

## Fork A — weak definition

```text
Communication
= structured distinction propagation
+ downstream discriminative uptake
```

This covers:

- Shannon-style engineering communication;
- signaling mechanisms;
- sensor/actuator message paths;
- many biological cases;
- machine protocols.

But it is materially identical to:

```text
MF0 structured mediation / recruitment
+ MF1 signal/channel
```

Result:

```text
WeakCommunicationCore → collapses into MF0/MF1
```

## Fork B — intentional definition

Add:

```text
communicative intention
+ intended recipient
+ intended recognition
```

This captures a strong Gricean/ostensive human communicative act.

But it excludes or becomes controversial for:

- bacterial signaling;
- many animal signals;
- automated warnings;
- institutional/public representations whose current producer is absent;
- low-agency protocol systems;
- some inherited conventions;
- machine-generated messages where intention standing is delegated/operational rather than human-mental.

Result:

```text
IntentionalCommunicationCore → legitimate subtype, not universal communication primitive
```

## Fork C — common-ground definition

Add mutual knowledge/belief/common ground.

This fits collaborative dialogue but fails:

- first contact;
- one-way broadcast;
- emergency signaling;
- communication across weakly aligned populations;
- deception;
- asymmetric sender/receiver cases;
- opaque agents with only protocol-level interoperability.

Result:

```text
CommonGroundCommunicationCore → dialogue/grounding subtype
```

## Fork D — successful-understanding definition

Require recipient understanding.

Then:

```text
failed message
misunderstood warning
undelivered email
unread public statement
ambiguous signal
```

cannot be cleanly distinguished as communication attempt, delivery, encounter, uptake or failure.

Result:

```text
SuccessRequirement → destroys necessary failure-state distinctions
```

### B-A result 1

There is no currently defensible single communication essence that is both:

1. broad enough for all major regimes; and
2. narrower than MF0/MF1.

This is strong evidence against `Communication` as one primitive foundation.

# 3. Communication must be stage-typed

Ordinary language compresses several different events into “communication”.

Round B-A therefore introduces a **derived analysis ladder**, not a new foundation:

```text
CommunicativeStanding / Convention
        ↓
CommunicativeAttempt
        ↓
Transmission / Availability
        ↓
Delivery / Reachability
        ↓
Exposure / Encounter
        ↓
Perceptual / Operational Uptake
        ↓
Interpretive / Pragmatic Uptake
        ↓
Grounding / Acknowledgement / Repair
        ↓
Downstream Epistemic / Practical / Social Effect
```

These stages can dissociate.

Examples:

```text
email sent but server rejects
  Attempt = yes
  Delivery = no

email delivered but never opened
  Delivery = yes
  Encounter = no

warning seen but misunderstood
  Encounter = yes
  intended interpretation = no

lie correctly understood as the proposition asserted
  semantic uptake = yes
  truth = no

sarcasm heard literally
  signal/lexical uptake = yes
  pragmatic force uptake = no

public document archived for decades
  standing representation/public availability = yes
  current encounter = no
```

This ladder immediately connects Communication to the independent Round-A residual around **Encounter / Exposure**.

# 4. Regime 1 — Engineering communication

Canonical engineering communication studies source/message/channel/destination under noise/coding/capacity constraints.

Shannon's 1948 programme formalizes message transmission and reconstruction at another point; semantic/pragmatic interpretation is not needed for the engineering theory.

Ordivon decomposition:

```text
Message distinction/source class  → MF1
Encoding / channel / noise         → MF1 + Network
Transmission realization           → Network
Recovery / reconstruction          → MF1
Destination functional uptake      → MF0
```

Nothing foundation-level remains for Media.

Classification:

```text
EngineeringCommunication
= already-covered / owned-elsewhere
```

Cheap falsifier survived:

> A communication channel transporting random or encrypted symbols can be mathematically characterized without any communicative intention, social relation or pragmatic meaning.

This is precisely why engineering communication cannot define the universal social/pragmatic referent.

# 5. Regime 2 — Biological signaling / communication

Biological usage creates another destructive boundary.

Quorum-sensing literature explicitly distinguishes evolved signals from mere cues/manipulation in some cross-species cases. Thus even within biology:

```text
chemical effect ≠ signal automatically
signal ≠ cue
cue exploitation ≠ cooperative communication
```

Yet biological communication can exist without human-like explicit intention, language or common ground.

Ordivon decomposition:

```text
variation/carrier/channel          → MF0/MF1
receiver sensitivity/uptake        → MF2 or biological system-specific uptake
selected/recruited signal role     → MF0 + evolutionary/Human-or-Life owner
coordination effect                → MF7
agency, if genuinely present       → MF8
```

No Media-specific irreducible standing appears.

Classification:

```text
BiologicalCommunication
= reducible / cross-cutting
```

Important negative result:

```text
Communication ≠ communicative intention universally
```

# 8. Regime 5 — Dialogue, grounding and common ground

Clark/Brennan-style grounding and conversation-analysis repair expose important structure:

```text
contribution
→ evidence of understanding
→ common-ground update
→ trouble detection
→ repair initiation
→ repair outcome
```

Conversation analysis empirically distinguishes recurrent repair organization around problems of speaking, hearing and understanding; grounding work treats reference and understanding as collaborative rather than solely sender-side production.

However these structures are compositional:

```text
multiple bearers / social relation       → Human / sociality
joint action                              → MF8
turn/episode state                        → MF6/MF7
feedback / correction dynamics            → MF7
representational contribution             → MF3
perception/attention                       → MF2
communication channel                      → MF0/MF1/Network
```

Common ground is also not universal to all communication regimes.

Therefore:

```text
DialogueGrounding
= important derived interaction organization
≠ universal Communication primitive
```

Classification:

```text
Dialogue / Grounding / Repair
= reducible / cross-cutting
```

This result increases pressure on a later **Interaction / Encounter** analysis, not on Communication-as-foundation.

# 10. Regime 7 — Institutional / performative communication

Some communications do more than convey information:

```text
“I accept.”
“You are fired.”
“The meeting is adjourned.”
“This work is certified.”
“Access revoked.”
```

Under appropriate standing, the utterance/message can participate in changing rights, roles, commitments or statuses.

But the operative effect depends on:

```text
representation / message                → MF3
bearer/action/authority exercise        → MF8
institutional role / office / rule      → Institution/Host-follow-on
jurisdiction / law                      → Law/Institution
execution of technical effect           → Runtime/Host where applicable
```

The media vehicle does not generate constitutive power by itself.

Classification:

```text
InstitutionalCommunication
= owned-elsewhere / cross-cutting
```

No MF0–MF9 reopen is needed.

# 11. Regime 8 — Public / broadcast communication

Broadcast/public communication destroys the assumption that a successful communication ontology must contain one identified current receiver.

Useful separations:

```text
production
≠ publication
≠ public availability
≠ addressability
≠ reachability
≠ actual exposure
≠ uptake
```

A public statement can have stable representational and institutional standing while no specific person is currently encountering it.

A broadcast can address a role/class/public rather than a known individual.

An overhearer may understand a message despite not being its addressee; Clark's audience-design work distinguishes addressee, participant, overhearer and eavesdropper statuses.

Therefore:

```text
RecipientIdentity ≠ necessary as one known individual
AddressedRecipient ≠ ActualHearer
ActualHearer ≠ IntendedAddressee
PublicAvailability ≠ Encounter
```

Classification:

```text
Public/Broadcast Communication
= MF3 + Institution/Publicness + Network + Encounter
= cross-cutting
```

This again moves residual pressure away from Communication and toward:

```text
Publicness / Addressability / Exposure / Encounter
```

# 12. Regime 9 — Machine / Agent communication

Agent-era protocols are a high-value falsifier because they remove many implicit human assumptions.

Current A2A protocol design explicitly supports communication/interoperability between independent opaque agent systems. Agents can discover capabilities, negotiate modalities, exchange messages, maintain task context and collaborate without sharing internal memory, plans or tool implementations.

This demonstrates a practical regime in which:

```text
shared private internal model ≠ necessary
shared implementation         ≠ necessary
human-readable language       ≠ necessary
human audience                ≠ necessary
```

But interoperability still requires some public/shared protocol standing:

```text
message schema
role semantics
operation semantics
capability declarations
version / binding rules
```

Ordivon decomposition:

```text
protocol representation         → MF3
convention/interoperability      → Convention/Protocol residual
agent bearer/action/delegation   → MF8
message state/task lifecycle     → MF7
transport                        → Network
execution                        → Runtime/Harness
institutional/security authority → Host/Network/Security
```

Therefore Agent-era machine communication does not establish a new Communication primitive.

Classification:

```text
AgentCommunication
= cross-cutting / reducible
```

It **does** strengthen the independent Round-A pressure on `Convention / Protocol / Interoperability`.

# 13. Sender / receiver optionality audit

The words `sender` and `receiver` are themselves overloaded.

We need at least:

```text
Producer
Source
Transmitter
Publisher
Addressor
Sender-role
Carrier
Delivery system
Potential recipient
Addressee
Actual encounterer
Interpreter
Operational consumer
Beneficiary / affected party
Overhearer / eavesdropper
```

These need not coincide.

Examples:

- author dead, book still public;
- institution publishes via automated system;
- agent generates a message under delegated goal;
- one system writes a log for its future self/process;
- broadcaster addresses a class rather than known recipients;
- overhearer becomes actual interpreter though not addressee;
- a recipient is reachable but never encounters the message.

Therefore a universal primitive tuple:

```text
<Sender, Message, Channel, Receiver>
```

is useful for some regimes but is too coarse as Media ontology.

# 14. Self-communication / temporally separated bearer roles


cannot be universal.

MF7 persistence and MF4 subcomposition already let source/consumer roles be separated without asserting two independent agents.

Hence:


again weakening a single social primitive.

# 24. What survived the attack

Communication itself did not survive as a primitive, but three neighboring residuals gained pressure:

## R1 — Encounter / Exposure

The distinction between:

```text
delivery
availability
exposure
encounter
uptake
```

is essential to communication failure analysis and is not closed by Network transport.

## R2 — Convention / Protocol / Interoperability

Agent and language regimes require public/shared standing about how distinctions are to be interpreted/acted upon, while internal states can remain opaque.

MF3 convention grounding may still absorb this, but the residual deserves its own destructive test.

## R3 — Publicness / Addressability

Broadcast/public communication needs recipient classes, public availability and addressability that are not identical to transport or actual encounter.

These remain **residual candidates**, not foundations.
