# 0. Question

Round B-A reduced `Communication` and transferred residual pressure to:

```text
Encounter / Exposure
Convention / Protocol / Interoperability
Publicness / Addressability / Visibility
```

Round B-B asks:

> **Does Encounter / Exposure contain a Media-specific irreducible standing that cannot be represented by MF0–MF9 plus Network/Runtime/Harness/Human ownership?**

The cheapest prescribed falsifier is:

```text
same media object
same representation
same Network transport / reachability
same delivery
DIFFERENT actual exposure / encounter
```

If that difference cannot be represented by the frozen substrate, a new primitive may be needed.

If the difference maps cleanly to existing coupling, observation, perception, attention, recruitment or execution standings, Encounter/Exposure is a derived profile rather than a foundation.

# 3. External measurement falsifier — served ≠ viewable ≠ attended

Digital advertising measurement provides an unusually clean operational decomposition.

MRC/IAB viewability standards were introduced precisely because:

```text
ad fetched / served
≠ ad actually displayed in view
```

A fetched/loaded ad may be below the viewport, occluded, or otherwise not viewable.

The industry then deliberately defines the viewable impression as an **opportunity to see**, not proof of attention, engagement, comprehension or branding effect.

Thus even mature measurement practice requires:

```text
Served
≠ Viewable / Opportunity-to-see
≠ Attention
≠ Interpretation
≠ Effect
```

This is strong evidence that the Round-A residual is a real distinction.

But a real distinction is not automatically a new foundation.

# 4. Same-network / different-exposure falsifier

Construct two digital worlds.

## World A

```text
same page bytes
same ad/media object
same server response
same successful transport
same browser
same representation standing
ad rendered below the fold
user never scrolls
```

## World B

Everything is identical except:

```text
ad rendered inside the viewport for sufficient time
```

Media consequences differ:

```text
A: no visual opportunity-to-see
B: visual opportunity-to-see
```

Network cannot represent this difference because transport and delivery are identical.

Does frozen Media represent it?

Yes:

```text
MF5 positional standing / viewport relation differs
MF6 temporal presentation interval differs
MF0 consumer-relative coupling differs
MF1 observation/signal route to the sensory boundary differs
```

Therefore the cheapest falsifier proves:

```text
NetworkReachability ≠ ExposureOpportunity
```

but it does **not** prove:

```text
ExposureOpportunity = new primitive
```

The difference maps to existing Media coupling/observation/spatiotemporal relations.

# 5. Viewable / exposed but unattended falsifier

Now hold World B's viewability constant but vary attention.

## B1

The item is in the viewport while the user actively attends elsewhere.

## B2

The item is in the viewport and receives focal attention.

Perceptual and downstream outcomes may differ sharply despite identical presentation geometry.

Inattentional-blindness and perceptual-load results demonstrate that a clearly present visual stimulus may fail to enter normal awareness when attention is occupied elsewhere.

Ordivon already represents this through MF2:

```text
ExposureOpportunity
≠ AttentionStanding
≠ Awareness
```

No new Encounter primitive is necessary.

Important consequence:

```text
Viewable impression ≠ perceptual success
```

and therefore:

```text
Exposure ≠ Attention
```

must remain frozen as a derived separation.

# 6. Attention but no normal awareness

# 16. Machine / Agent exposure falsifier

Agent-era media is particularly useful because human perception can be removed entirely.

## M1 — stored but not selected

```text

```

## M2 — selected/materialized but not consumed

```text
bytes copied/materialized into execution or context staging
consumer process/model never reads the relevant region
```

## M3 — consumed/recruited

```text
consumer computation is counterfactually sensitive to distinctions in the object
```

These correspond to:

```text
availability / authority          → Runtime/Host/Harness
selection/materialization         → Harness/Runtime
signal/representation standing    → MF1/MF3
```

No phenomenology is required.

This is a decisive Agent-era result:

```text
Encounter cannot be constitutively human or perceptual.
```

If machine `encounter` means actual functional use, MF0 Recruitment already captures the key threshold.

If it means selected availability to a computation, it belongs mostly to Harness/Runtime presentation/context machinery plus MF0 coupling.

Therefore machine media does not rescue Encounter as a primitive.
