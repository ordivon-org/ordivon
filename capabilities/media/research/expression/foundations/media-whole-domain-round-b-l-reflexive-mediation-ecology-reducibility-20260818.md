# 2. Working candidate definitions

## 2.1 Feedback

A downstream state/output influences a later upstream input/state in the same scoped dynamical composition.

```text
Y_t → X_{t+1}
```

where X earlier influenced Y.

No agency or representation is required.

## 2.2 Performativity

A representation/model/prediction/policy participates causally in changing the target distribution/state against which that representation/model/policy is later evaluated or retrained.

This is stronger than generic feedback because the system's informational/predictive output enters the causal route that changes the object of future observation.

## 2.3 Reflexivity

Use narrowly:

> a system or participant represents/observes some aspect of the mediation process, its effects, its audience, itself or other participants and changes behavior partly in response to that representation/observation.

Thus reflexivity includes an informational self/other-model route, not merely physical feedback.

## 2.4 Mediation Ecology

A scoped composition containing several interacting Media roles/bearers plus users/agents/institutions and feedback relations through which mediation processes alter future mediation conditions.

`Ecology` here does **not** imply biological ontology.

# 91. Research anchors used

Representative primary/comparison anchors:

- Perdomo, Zrnic, Mendler-Dünner & Hardt, *Performative Prediction* (ICML 2020 / arXiv 2020) — deployed predictions/models can change the future data distribution; performative stability is a generic model-deployment feedback concept outside Media-specific ontology.
- Mendler-Dünner et al., *Stochastic Optimization for Performative Prediction* (2020) — deployment, rather than parameter update alone, triggers the distribution shift in performative settings.
- Chen et al., Google/YouTube, *Top-K Off-Policy Correction for a REINFORCE Recommender System* (WSDM 2019) — logged implicit feedback is biased because only earlier-policy-selected recommendations generate observed feedback.
- Lee et al., Google, *Bilateral Self-unbiased Recommender Learning for Missing-not-at-Random Implicit Feedback* (SIGIR 2022) — recommender-induced exposure bias: more frequently rendered items receive greater interaction opportunity.
- Mladenov et al., Google, *Optimizing Long-term Social Welfare in Recommender Systems* (ICML 2020) — provider viability and user utility are coupled in an induced dynamical system; myopic matching can be poor long-term.
- Zhan et al., Google, *Towards Content Provider-Aware Recommendation Systems* — user/provider states and feedback form coupled partially observable dynamics.
- Boutilier, Mladenov & Tennenholtz, Google, *Modeling Recommender Ecosystems* (AAAI 2024) — recommendation policies couple users, content providers, advertisers and other actors; long-horizon ecosystem modeling is distinct from myopic user optimization.
- Tu et al., LinkedIn, *Feedback Shaping: A Modeling Approach to Nurture Content Creation* (2021) — consumer feedback influences creator activity and platform policy can shape that feedback distribution.
- Acharya et al., *Producers Equilibria and Dynamics in Engagement-Driven Recommender Systems* (2024) — platform content-serving rules affect producer strategic equilibria/specialization.
