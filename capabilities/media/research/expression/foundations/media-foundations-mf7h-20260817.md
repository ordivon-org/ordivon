# 6. Final State definition

> **A state is a scope-relative configuration alternative of a bearer/system whose distinctions have non-arbitrary standing as specifying which condition/configuration of that bearer currently obtains under a declared granularity/equivalence and occurrence/validity scope. The state can be physical, biological, computational, formal, representational, belief/information, collective or hybrid depending standing route. Prediction, Markov sufficiency, observability, vector form, memory, persistence and dynamics are optional profiles rather than universal constituents.**

Compact:

```text
State
 = Bearer/Boundary
 + Admissible Configuration Possibility Domain
 + ConfigurationStanding
 + Granularity/Equivalence
 + StandingRoute
 + Occurrence/Validity Scope
```

### SH-013

### SH-014
**State is configuration-standing, not a synonym for all facts about reality.**

### SH-015
A single binary variable can define a legitimate coarse/formal state if its alternatives have configuration standing; high dimensionality is not required.


# 76. Final MF7 v1 axioms

### SD1 — Scoped Configuration
A state is always state of a declared bearer/system/formal target under boundary, granularity and occurrence/validity scope.

### SD2 — Configuration Standing
Statehood is grounded configuration standing, not vector/snapshot/label syntax.

### SD3 — Representation Firewall
State descriptions, observations, snapshots and beliefs do not transfer target-state standing without grounding.

### SD4 — Sufficiency Is Optional
Markov/predictive/behavioral sufficiency is a stronger profile, not state constitution.

### SD5 — Typed Multi-Standing
Spatial, temporal, state and representational standings can coexist without role identity.

### SD6 — Evolution Standing
Dynamics requires grounded continuation semantics among state/process occurrences.

### SD7 — No Syntax Collapse
Sequence, order, dependency, update syntax, equations or transition graphs do not establish target dynamics by themselves.

### SD8 — Dynamics Plurality
Deterministic, stochastic, nondeterministic, hybrid and history-dependent dynamics are equally admissible forms.

### SD9 — Law/Realization Separation
Dynamics ≠ trajectory ≠ run ≠ history ≠ log.

### SD10 — Boundary First
Open/closed, endogenous/exogenous, input/noise/control and reduced dynamics are boundary-relative.

### SD11 — Identity Separation
State equality/change does not decide bearer identity; persistence requires continuation + identity criterion.

### SD12 — Stability Family
Invariant/equilibrium/stability/attractor/regime/robustness/resilience/homeostasis are distinct dynamics profiles.

### SD13 — Control Standing
Control is controller-governed effective influence under access/action semantics, not generic cause/coupling or agency.

### SD14 — Closed-Loop Composition
Controller + plant + sensing/actuation can constitute a new dynamics whose properties differ from components.

### SD15 — Coarse Standing
Macro state is genuine state standing at a coarse scale; exact dynamic closure is optional.

### SD16 — Scale Relativity
Micro/macro and effective dynamics are declared scale relations, not reality ranks.

### SD17 — Collective Organization
Coupling can create joint modes/patterns/regimes not attributable to isolated component states in the same form.

### SD18 — Emergence Without Magic
Emergence is typed organization/scale dependence; derivability, predictability and irreducibility are separate claims.

### SD19 — Uncertainty/Provenance
State, dynamics, identity, control and macro claims carry evidence, provenance, uncertainty and standing route.

### SD20 — No Agency Smuggling
Goal, utility, preference, intention and agency are not constitutive to MF7 and remain for MF8.

# 79. Authoritative evidence anchors for MF7-H

- **Leslie Lamport, official TLA+ high-level view.** A behavior is modeled as a sequence of states; a state machine is specified by initial condition and next-state relation. Used to test formal StateStanding/EvolutionStanding without forcing physical ontology.
- **R. E. Kalman (1963), `Mathematical Description of Linear Dynamical Systems`.** Separates state-variable and input/output descriptions and analyzes controllable/observable/minimal realizations. Used to test state representation, sufficiency and control boundaries.
- **Edward N. Lorenz (1963), `Deterministic Nonperiodic Flow`.** Deterministic nonlinear dynamics can be nonperiodic and highly sensitive to initial conditions. Used to preserve determinism/predictability separation.
- **Daniel T. Gillespie (1976), stochastic chemical kinetics simulation.** Structured probability law produces stochastic time evolution/sample paths. Used to test stochastic EvolutionStanding.
- **Hazime Mori (1965) and Robert Zwanzig (1961/1972 correction).** Reduced collective variables can acquire generalized evolution with damping/memory/fluctuation terms. Used to test open/non-Markov/macroscopic state and dynamics.
- **POSIX.1-2024 `fork()` and `exec()`.** Fork creates a new process from a near-copy; exec replaces a process image. Used to test identity/state separation.
- **Judea Pearl (1995), `A Causal Calculus for Statistical Research`.** Distinguishes observation from external intervention. Used to test intervention/control boundaries.
- **Leo P. Kadanoff (1966) and Kenneth G. Wilson (1971+).** Collective/block variables and effective interactions under scale transformation. Used to test macro StateStanding, closure and effective dynamics.
