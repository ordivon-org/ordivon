# 2. Teleoperation and telepresence are already historically distinct

Sheridan's teleoperation/telerobotics/telepresence synthesis explicitly separates:

```text
Teleoperation
= human control of remote sensors/actuators

Telerobotics
= supervisory control of remote semiautomatic systems

Telepresence
= sensing/display arrangements enabling a human to feel present remotely
```

Therefore:

```text
RemoteControlStanding
≠ FeltRemotePresence
```

This is a foundationally decisive starting point.

---

# 3. Remote action without presence

Cheap cases:

```text
slow command-line administration of a distant server
batch command to a Mars rover
HTTP request to remote service
asynchronous industrial robot command
remote actuator controlled through sparse telemetry
```

A user can possess real remote action capability while experiencing no compelling `being there`.

Thus:

```text
TeleactionStanding
↛ PhenomenalTelepresence
```

D-B already owns operation binding and remote execution.

---

# 4. Presence without remote action

A user can experience compelling spatial/place presence in a virtual environment while having little or no ability to act on it.

Passive immersive scenes, 360 video, or constrained VR experiences are sufficient hard cases.

Therefore:

```text
PhenomenalPresence
↛ RemoteActionCapability
```

---

# 5. Presence without a remote physical target

Slater's Place Illusion theory concerns the subjective `being there` in immersive **virtual** environments.

The virtual place need not correspond to a currently existing remote physical location.

Therefore:

```text
PhenomenalSpatialPresence
↛ RemotePhysicalTargetExists
```

This prevents telepresence theory from defining presence solely as remote physical transportation-by-media.

---

# 6. Remote perceptual access without presence

A surveillance camera, telescope, dashboard, robot camera or delayed remote video can provide genuine perceptual/inferential access to a distant target.

The observer may continue to experience themselves simply as viewing a display at the local location.

Therefore:

```text
RemotePerceptualAccess
↛ PhenomenalPresenceAtTarget
```

MF2/MF3/MF5 already represent target access and represented spatial target.

---

# 7. Presence without current remote perceptual truth

A convincing prerecorded or synthetic virtual environment can elicit place-presence despite no live remote target being sensed.

Therefore:

```text
Presence
↛ CurrentRemoteObservationTruth
```

Presence is not epistemic proof of where a target currently is or what is currently happening.

# 8. Phenomenal presence is an experiential standing

MF9 already provides a home for the felt `being there` aspect:

```text
ExperienceStanding
+ PhenomenalCharacter/Field/Content
```

Presence reports and behavior are evidence routes, not the phenomenal standing itself.

Thus D-D must not create a new non-experiential primitive merely to rename one class of phenomenal content/character.

# 9. Presence report ≠ presence occurrence

A questionnaire answer, verbal report or behavioral response can be noisy, strategic or method-dependent.

MF9 already freezes:

```text
PresenceOfReport ≠ exact proof of reported phenomenal content
```

Therefore:

```text
PresenceScore

```

# 10. Immersion ≠ presence

A major VR tradition distinguishes:

```text
Immersion
= technical/system capability supporting sensorimotor/perceptual interaction

Presence
= subjective experiential response / being-there phenomenon
```

A system can be highly immersive while a particular user has weak presence, and less immersive media can produce meaningful mediated presence.

Thus:

```text
ImmersionProfile
≠ PhenomenalPresenceProfile
```

---

# 11. Technical capability is not subjective outcome

Field of view, tracking, resolution, latency, modality coverage and interaction fidelity can influence presence probability/strength.

But no one technical variable is itself presence.

Therefore:

```text
SystemProperty
≠ ExperienceStanding
```

MF9's mechanism/evidence firewall remains intact.

---

# 12. Place illusion ≠ plausibility

Slater explicitly separates:

```text
Place Illusion (PI)
= sensation of being in a place

Plausibility (Psi)
= feeling that depicted events are really occurring
```

A user can know cognitively that the environment is virtual while still experiencing PI.

Therefore:

```text
Presence/PlaceIllusion
≠ BeliefThatScenarioIsActuallyReal
```

---

# 13. Presence ≠ factual belief

A user can simultaneously maintain:

```text
propositional belief: "I am physically in the lab"
```

and:

```text
phenomenal/spatial response: "I feel located in the virtual place"
```

Thus:

```text
PhenomenalSelfLocation/Presence
≠ ExplicitWorldBelief
```

MF3/MF9 separate representation/belief from experience.

---

# 14. Realism ≠ presence

Highly stylized environments can support presence; photorealistic media can remain experientially distant.

Therefore:

```text
Visual/PhysicalRealism
```

is neither necessary nor sufficient universally.

Plausibility, sensorimotor congruence and task/context can matter independently.

# 15. Sensorimotor contingencies strongly matter for one presence route

Slater's Place Illusion account ties PI to the sensorimotor contingencies supported by the immersive system.

This is a strong **mechanistic/constitutive route for immersive spatial presence**, not a proof that every historically mediated presence requires closed-loop sensorimotor control.

D-D therefore distinguishes:

```text
ImmersiveSensorimotorPresenceRoute
```

from broader historical/social mediated-presence routes.

Bourdon's comparative theory explicitly spans:

```text
correspondence
```

Its comparative dimensions include:

```text

```

Therefore `mediated presence` is historically broader than immersive VR telepresence.

# 17. Broad mediated presence ≠ one mechanism

A letter, telephone call, live broadcast, VR world and telerobot can all produce some form of presence-at-distance while differing in:

```text
interactivity
latency
sensorimotor coupling
body mapping
reciprocity
liveness
spatiality
```

Thus:

```text
MediatedPresence
```

is an umbrella family, not evidence for a common primitive mechanism.

# 18. Liveness ≠ presence

A live broadcast can be genuinely live while the viewer has weak spatial/social presence.

A prerecorded immersive scene can induce strong place presence.

Therefore:

```text
LivenessStanding
≠ PresenceStanding
```

MF6/B-H already separate source event time, presentation time and recording.

# 19. Real-time ≠ presence

A low-latency videostream may remain experientially screen-like.

A delayed immersive experience can still produce substantial presence.

Therefore:

```text
LowLatency
↛ Presence
```

MF6 already freezes `LowLatency ≠ Synchronization` and D-D adds `LowLatency ≠ Presence`.

# 20. High latency degrades control without erasing teleoperation

Recent teleoperation studies show large command/feedback delays reduce task performance and alter cognitive load; haptic feedback can mitigate some effects.

But even high-delay systems remain genuine teleoperation systems.

Therefore:

```text
TeleoperationStanding
↛ LowLatency
```

and temporal quality belongs in a profile.

---

# 21. Haptic feedback changes sensorimotor quality, not ontology

Haptic feedback can improve contact-force control, velocity, confidence or cognitive performance in teleoperation.

It can strengthen embodiment/presence for some users/tasks.

But:

```text
Haptics
```

is not universally required for teleoperation, teleaction or mediated presence.

It is a modality/coupling profile.

---

# 22. Visual-only teleoperation remains teleoperation

Remote camera + joystick control is sufficient for genuine remote action.

Therefore:

```text
HapticChannel
```

is optional to the minimal teleaction standing.

---

# 23. Haptic-only/partial sensory routes can still carry remote state

Pseudo-haptic and haptic teleoperation research demonstrates that force/compliance information can be conveyed through nonvisual or transformed feedback routes.

Thus:

```text
Visuality
```

is not constitutive to remote action/presence architecture.

D-C's multimodal interface result survives.

# 24. Synchrony ≠ sensorimotor contingency

A system can present synchronous streams without mapping the user's actions to expected remote/virtual consequences.

Conversely a stable sensorimotor mapping can include fixed delay and remain learnable/calibratable.

Therefore:

```text
TemporalSynchrony
≠ SensorimotorContingency
```

# 25. Sensorimotor contingency ≠ objective agency

A virtual scene can update predictably with head motion, creating strong sensorimotor contingencies, without the user being an agent over every scene event.

Thus:

```text
SensorimotorContingency
≠ AgencyStanding
```

MF8 remains separate.

# 26. Sensorimotor contingency ≠ sense of agency

Some contingency can alter self-location/place presence without producing a strong felt authorship of every event.

Conversely agency can be felt over a discrete action without broad immersive place presence.

Therefore:

```text
SensorimotorCoupling
≠ SenseOfAgency
```

# 30. Sense of agency ≠ objective agency

# 38. Remote tool use ≠ body ownership

# 40. Remote robot embodiment can be partial

Operator may incorporate:

# 41. Body morphology ≠ action morphology

A remote robot can have nonhuman kinematics while still being controllable and partially incorporated.

Therefore human-shape correspondence is not universally required for teleaction or tool incorporation.

---

# 42. Human-like avatar appearance can modulate ownership but is not constitutive

VR body research finds appearance/personalization can alter ownership/presence measures, but nonidentical and even transformed bodies can still be embodied under suitable contingencies.

Thus:

```text
AppearanceSimilarity
```

is a modulator/profile, not the ontology of embodiment.

# 43. Motion synchrony is influential but not one universal key

Synchronous visuomotor/visuotactile relations often strengthen ownership/agency/presence.

But experiments show first-person perspective/spatial overlap and other cues can sometimes sustain ownership under reduced congruence.

Therefore:

```text
PerfectMotionSynchrony
```

is neither a universal necessary nor sufficient condition for every embodiment dimension.

---

# 44. Embodiment ≠ presence

An avatar body can be owned/controlled to varying degrees while place presence varies separately with display/system/environment factors.

Empirical studies report differential effects of motion synchrony, appearance and immersion on ownership, agency, self-location and presence.

Therefore:

```text
EmbodimentProfile
≠ PresenceProfile
```

# 45. Presence ≠ body ownership

# 73. Presence can influence behavior without proving factual relocation
