# Media Cross-owner Bridges

Bridge entries state where Media should defer to another semantic owner. They do not copy or redefine the source owner's truth.

## SCD — Semantics of Computational Descriptions

When Media representations, protocols, transformations, operative tokens or related structures function specifically as **computational descriptions**, Media defers the semantic-standing questions to SCD. This includes observation/accessibility, comparison/refinement, admissibility/specification, transformation/dependency/evolution and related description semantics.

Media may describe the mediation role and derived profile around such objects; it must not silently make MF3, Round-B protocol profiles or D-B operative profiles the global owner of computational-description semantics.

## Computational Possibility

Computational Possibility owns formal regime **possibility / impossibility / applicability constraints**. It does not own actual Media facts, actual Runtime execution state or the concrete occurrence of a media event. Media consumes those formal constraints where relevant rather than duplicating them.

## Runtime

Runtime owns concrete execution and runtime-state evidence. D-B `ExecutionEligibilityProfile`, `ActivationExecutionTrace` and `OperativeMediaProfile` are Media-side derived structures around operative mediation; they do not establish that execution actually occurred or define Runtime state.

## Other owner boundaries

- Interlocus (historical owner identity/name: `research-owner:network` / Network) — qualified cross-locus capability, transport/routing/reachability substrate.
- Harness — generic agent/tool orchestration support.
- Host / Institution — authority, status, obligation and governance.
- Human — general cognition, sociality, culture, meaning and evaluation where Media is only an environment.
- World — material, causal, physical and reality truth.
- Finance — generic value, incentive, market and resource relations.
- Game — play/game/challenge specialization.
- Security — generic authorization, adversarial and privacy specializations where available.

Bridge changes are reference-boundary refinements. They do not reopen MF0–MF9 unless a concrete Foundation claim is actually falsified.
