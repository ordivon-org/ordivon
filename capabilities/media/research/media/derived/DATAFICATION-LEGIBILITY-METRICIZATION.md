# Datafication / Legibility / Metricization

**Status: important derived Media reality; not MF10.**

Round D-E established that datafication, legibility and metricization matter because they reshape what can be seen, compared, evaluated, governed and acted upon. Their importance does not require treating them as a new primitive.

## Canonical derived chain

```text
Target Reality / Activity
→ Instrumentation
→ Capture / Trace
→ Data Representation / Schema
→ Aggregation
→ Metric / Indicator / Proxy
→ Legibility for Consumer / Query
→ Evaluation / Decision
→ Authority / Capability
→ Action / Outcome
```

Every arrow is independently fallible. The chain therefore must not be compressed into the assumption that recorded data equals reality, that a metric equals its target, or that legibility is neutral.

- DataficationPipelineProfile
- LegibilityProfile
- MetricProxyProfile

## Boundary

This layer may reference representations, mediation, observation and control already present in MF0–MF9, and may bridge to other owners when computational semantics, execution, institutional authority or domain facts are involved. It does not absorb those owners and does not create a Datafication/Legibility primitive.
