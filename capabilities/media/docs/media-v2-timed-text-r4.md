# Media v2 — standard timed-text migration R4

## External authority

W3C IMSC Text Profile 1.3 became a Recommendation on 2026-05-21. `ttconv` is listed in the W3C IMSC 1.3 implementation report and its canonical model follows TTML2 as constrained by IMSC 1.3. R4 pins `ttconv==1.2.3` rather than tracking an unbounded latest release.

## Architecture

```text
TTML source
  -> xmllint (well-formedness / xml:lang)
  -> ttconv 1.2.3 (format normalization)
  -> normalized WebVTT
  -> FFprobe subtitle packets
  -> explicit delivery assertions
  -> digest-bound EvidenceReceipt
```

Media v2 does not implement subtitle parsing, timestamp parsing, TTML conversion, SRT conversion, or WebVTT conversion.

## Important falsifier

`ttconv` accepted a WebVTT cue whose end timestamp preceded its start timestamp. Therefore successful `ttconv` conversion is **not** treated as sufficient delivery validation or complete IMSC conformance evidence. FFprobe exposes this case as a subtitle packet with negative duration, which the Media v2 profile rejects.

## Conformance boundary

The TTML output used here is generated by the `ttconv` IMSC writer and can be re-read and converted by the same external tool. R4 does **not** claim independent IMSC 1.3 conformance. Such a claim requires an appropriate independent validator/conformance implementation.

## Runtime introduction migration

The legacy Ordivon JSON timed-text file was used once to produce a migration WebVTT artifact. `ttconv` then produced a TTML standard source with `xml:lang="en"`, plus WebVTT and SRT delivery derivatives. Direct legacy-export VTT -> SRT and VTT -> TTML -> SRT were byte-identical, establishing bounded conversion equivalence for the current nine cues.

After R4 acceptance, the production's `sources.timedText` points to the TTML standard source. The old JSON file remains in the repository only as historical/migration evidence, not as the current timed-text authority.

## Truth boundary

Mechanical cue count, positive durations, non-empty packet payloads, language declaration, and maximum end time are machine-checked. Semantic caption completeness, speaker correctness, reading quality, audio-description need, audience comprehension, WCAG outcome, and publication standing remain separate evidence.
