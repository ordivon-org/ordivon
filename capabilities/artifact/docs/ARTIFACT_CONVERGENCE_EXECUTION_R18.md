(https://docs.temporal.io/design-patterns,
https://docs.temporal.io/activity-definition); Podman API grants full
authority as its service user
(https://docs.podman.io/en/latest/markdown/podman-system-service.1.html).
Prefer native Activity routing or existing Runtime admission with bounded
exact operation and durable output roles. Do not expose root socket,
change systemd protection blindly or duplicate Runtime. Actual isolated
witness uses distinct orchestration and native Activity queues, native
ArtifactOperation and explicit OCI recipe, exact 11 role readback, 11
history events and Replayer PASS. It is a test-only Workflow, not deployed
ArtifactWorkflow or a production authorization mechanism. Sandbox rejects
filesystem resolution at Workflow import; keep I/O in native Activities.

I=(exact subject, profile, recipe, operation ID, admitted execution route);
O=(native result, role receipts, standing); S=Temporal history, existing
receipt fence and owner physical state; pre=qualified source and method,
authenticated route, exact inputs; post=scheduled Activity route observed,
returned roles verified, receipt replay same intent; inv=legacy one-argument
observation hook unchanged, explicit recipe cannot alias old receipt,
no fallback, no promotion of incomplete profile; eff=actual bounded
native verifier; epsilon=task queue name alone is not authority, no
universal safety or whole readset proof; prov=source/Job/receipt/history.
