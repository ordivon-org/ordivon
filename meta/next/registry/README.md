# Registry

The Registry is a declarative catalog of currently known knowledge, capabilities, providers, validators and evidence-backed compositions.

It is not an ontology of the world and not a fixed Ordivon topology. Entries are discovered and loaded into a task-local working set when relevant.

R1 uses plain JSON so agents and ordinary programs can inspect entries without a custom runtime or schema service. More formal representations are added only if real use demonstrates a need.
