# Game Domain Profile — R0 Skeleton

Status: structure only; no new Game implementation is authorized by this file.

## Entity of Interest

A game product/service across its relevant life cycle.

## Initial life-cycle investigation targets

The actual profile must be derived from mature game-industry, platform and systems-engineering sources rather than from the historical Ordivon Game architecture. Candidate areas to investigate include:

- concept / product intent;
- requirements and game design;
- asset/content production;
- software/gameplay implementation;
- integration;
- verification and validation;
- build/package/release;
- operation/support/live service where applicable;
- maintenance/evolution;
- retirement/archive.

## Required R1 outputs

1. externally grounded Game taxonomy;
2. life-cycle profile;
3. standards/body-of-knowledge map;
4. methods/algorithms map;
5. capability/tool map;
6. workflow map;
7. V&V/acceptance map;
8. one real problem-to-verified-result vertical slice.

Historical `ordivon-game` is an evidence and migration source, not the authority for this taxonomy.
