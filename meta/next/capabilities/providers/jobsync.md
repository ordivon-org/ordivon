# Provider reference: JobSync

Status: **REFERENCE ONLY / NO ACTIVE BINDING / NO VERIFIED CONSUMER**

JobSync overlaps Reactive Resume on tracker/product state and is not selected as an Ordivon Career product. The current verified opportunity slice already uses the official Greenhouse API directly.

Its Greenhouse / Lever / Ashby scheduled discovery, company-directory organization and review-before-promote patterns remain useful design references. They are not an active provider layer and should not be copied or deployed until a concrete Opportunity Intake consumer proves that direct official ATS interfaces are insufficient.

Exact employer/ATS sources remain authoritative for current vacancy content and application effects.
