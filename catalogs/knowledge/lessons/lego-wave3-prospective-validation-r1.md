## Cross-lens separation

The four Wave 3 lenses are retained only because their decision objects are different:

- Exploration Policy: allocate repeated trial budget among already-defined comparable options.
- C-K Design: generate/partition concepts and knowledge when the desired object is not yet known.
- Evolutionary Search: transform/select a population when representation and evaluator are already meaningful.
- Organizational Cybernetics: diagnose autonomy/coordination/control/environment/policy relations in organizations; it is not a candidate-search method.

Routing law:

1. If the object itself is not known, use C-K before search optimization.
2. If candidate representation/evaluator are not trustworthy, do not use evolutionary search.
3. If choices are not repeated/comparable with attributable feedback, do not use bandit-style exploration policy.
4. If the problem is organizational coordination/adaptation rather than candidate choice, use organizational cybernetics instead of search lenses.
5. Do not stack all four merely because the word "exploration" appears.
