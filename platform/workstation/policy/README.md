# Policy boundary

OPA is selected for generic declarative admission/policy evaluation. This directory must not become a second semantic rule engine.

A policy may answer questions such as whether a deployment satisfies declared operational prerequisites. It must not infer domain truth that belongs to Research, Finance, Security, Network, Host, Runtime, or another owner.

Owner-specific evidence is projected into policy input. The owner remains responsible for the meaning of that evidence and for any final semantic verdict.
