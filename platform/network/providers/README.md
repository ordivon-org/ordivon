# Providers

Provider-specific server catalogs, endpoint identity, transport profiles and evidence live here. Provider material may compose generic capabilities but must not be imported by generic core validation or acceptance.


## Shared provider egress semantic owner

config/provider-egress.json is the platform-neutral semantic identity for the current shared
physical provider carrier. The historical browserless namespace/unit names are compatibility
identifiers for the current realization; they do not make Browserless the provider-carrier owner.
Consumers retain their own destination/effect policy and refer to the semantic authority as
provider-egress.
