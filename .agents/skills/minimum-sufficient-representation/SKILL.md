# Minimum Sufficient Representation — optional method, not a default First

**Status: rejected as Ordivon-wide default.** This method can be activated
only for a named consumer and bounded representation family when its benefit
can be tested. `Minimal` and `Sufficient` are independent requirements. A
smaller description or fewer concepts do not establish safety, correctness,
absence of hidden dependencies or coverage of unknown requirements.

## When worthwhile

For a named present consumer, compare a baseline representation and a bounded
candidate family under the **same** typed interface, owner, assumptions,
behavioral acceptance and observable outcomes. Prefer fewer duplicated
mechanisms only if actual integration/maintenance/runtime costs decrease and
no required behavior or recoverable unique evidence is discarded. Use an
existing contract/trace checker; return UNKNOWN if behavior preservation or
external consumer impact cannot be assessed.

## Limits and cost

- Global minimality needs a defined search space, legitimate objective and
  proof that no smaller candidate satisfies *all* specified constraints.
  Unknown requirements, evolving environments and undecidable equivalence
  can make that impossible or disproportionately expensive.
- "Sufficient" is always **relative** to named specification, consumer,
  environment, failure model and evidence. Passing a suite does not guarantee
  coverage of future attacks or unknown consumers.
- Optimizing compression can erase distinctions required for diagnosis,
  security, causality, rollback or independent falsification. Deletion must
  retain the last recoverable source where relevant consumption is UNKNOWN.
- Additional optimization/verification can exceed any savings. Stop if the
  marginal expected gain is lower than proof, integration and repair cost.

## Relation to stronger methods

Default to `recursive-lego-calculus` and its CEGAR model when formal
abstraction matters. Preserve sound concrete-to-abstract simulation; validate
counterexamples in the concrete Owner. **A real counterexample calls for a
repair; a proved spurious one may justify refining the abstraction.** Neither
is evidence that an abstraction is globally minimum or completely sufficient.

Result: `ADOPT_SCOPED`, `REJECT`, or `UNKNOWN`, with the actual consumer,
source cut, observed behavioral evidence, estimated costs and rollback path.
Do not add a permanent governor, new executor or universal score.
