# LEGO Lens Compiler

Lens Compiler treats mature disciplines as a large candidate library and the active LEGO lens set as a small, evidence-selected working set.

The goal is not to collect theories. The goal is to import the smallest rigorous operator that changes a real decision, exposes a real failure, or prevents an invalid inference.

## Activation

Use when:
- Lens Router has already processed an evidence-backed problem signature;
- Router returned NO_LENS while a material decision-relevant method gap remains;
- a mature external discipline may have stronger operators than an ad-hoc Ordivon rule.

Do not invoke merely because a topic can be described with interesting scientific vocabulary. Do not invoke when Router returned DOMAIN_METHOD or an admitted lens already owns the question.

## Pipeline

1. **Bind the Router handoff.**
   - exact system/phenomenon;
   - decision to improve;
   - evidence boundary;
   - Router result and rejected candidates;
   - exact uncovered method residue.

2. **Preserve/refine the problem signature.**
   Start from the evidence-backed Router signature. Refine only coordinates needed to search the uncovered residue; do not invent activation signals. Useful examples:
   - dynamics / delay / feedback;
   - partial observability;
   - strategic adaptation / incentives;
   - causal intervention;
   - dependency density / topology / cascades;
   - failures / hazards / recovery;
   - information flow / leakage / compression;
   - congestion / capacity / queues;
   - stochastic uncertainty / sequential choice;
   - resource allocation / constrained optimization;
   - measurement validity / calibration;
   - distributed coordination / consensus;
   - organizational recursion / autonomy;
   - human cognition / interaction;
   - open-ended design / search.

3. **Verify the method gap.**
   Confirm that the handoff is not already covered by a domain-native method or admitted registry lens. If it is, stop and return to Lens Router. Compiler does not maintain a second routing catalog.

4. **Search mature disciplines only for the uncovered residue.**
   A candidate discipline must contribute more than vocabulary: a model, operator, diagnostic, experiment design, theorem/constraint, or failure test relevant to the decision.

5. **Type-check the mapping.**
   Define a mapping from target objects/relations into the discipline's primitives.
   Require:
   - target entities correspond to meaningful source primitives;
   - source assumptions are explicit and plausibly satisfied/testable;
   - source operators preserve the intended semantics;
   - outputs can map back to an observable decision consequence.
   Reject a candidate as METAPHOR_ONLY when this fails.

6. **Compile a thin lens card.**
   State:
   - activation;
   - inputs;
   - source discipline and authorities;
   - primitive mapping;
   - assumptions;
   - operators;
   - outputs;
   - non-claims;
   - promotion law;
   - stop condition.

7. **Shadow before promotion.**
   Run the candidate beside the current method on one bounded case. Ask whether it produces a unique:
   - decision change;
   - corrected boundary/edge;
   - failure/hazard;
   - falsifiable experiment;
   - invalid-method prevention;
   - measurable uncertainty/cost reduction;
   - justified no-change unavailable from cheaper lenses.

8. **Prospective test when consequences justify it.**
   Prefer a case chosen before seeing the lens result. Preserve baseline output and compare deltas.

9. **Assign candidate lifecycle evidence.**
   - CANDIDATE — source-grounded but untested;
   - SHADOW — applied without decision authority;
   - PROSPECTIVE — undergoing predeclared validation;
   - ACTIVE / MERGE / RETIRE are registry lifecycle outcomes and are not self-assigned by Compiler.

10. **Stop and hand back.**
    Return the candidate card and evidence to Lens Router / registry admission. A compiled lens remains derived analysis unless the normal admission contract accepts it; project/domain truth still requires its natural owner.

## Lens-market rule

The active set should compete on marginal decision value rather than prestige or conceptual breadth.

Qualitative preference:

```
marginal lens value
~ unique decision/failure/uncertainty reduction
  / routing + evidence + execution + cognitive cost
```

Do not force numeric scoring without a defensible measurement model.

## Type-check failures

Reject or demote when:
- the mapping is only metaphorical;
- core source assumptions are false or untestable in the target;
- another active lens already produces the same actionable output more cheaply;
- the lens produces only terminology;
- the result cannot change a decision or bounded experiment;
- outputs cannot be validated independently;
- the lens requires smuggling domain authority it does not possess.

## Output

Produce:
- target + decision;
- problem signature;
- Router handoff and rejected candidates;
- uncovered residue;
- candidate discipline(s);
- mapping/type-check result;
- temporary lens card;
- baseline comparison;
- candidate lifecycle standing: CANDIDATE / SHADOW / PROSPECTIVE;
- recommended registry disposition when enough evidence exists: ADMIT / MERGE / RETIRE / KEEP_IN_RESERVE;
- next evidence or experiment.

## Promotion law

A discipline is not promoted because it explains a past case elegantly. Durable retention requires repeated unique value, preferably across unrelated domains, and must pass the Lens Router registry-admission/overlap contract.

Compiler itself cannot set ACTIVE standing or mutate the registry. Nothing here adds a mandatory field to LEGO Core or project-lego-plan-r1.

## Non-claims

- Similarity is not structural equivalence.
- Structural mapping is not truth.
- A mature discipline is not automatically applicable outside its assumptions.
- A successful single case is not cross-domain validation.
- More lenses do not imply better reasoning.
- A lens cannot grant itself authority by describing its own success.

## Stop condition

Stop when the Router gap disappears, an existing/domain-native method owns the question, the candidate fails type-check, or marginal decision value is negligible. Return any durable candidate evidence to Router/registry admission instead of keeping a parallel catalog.
