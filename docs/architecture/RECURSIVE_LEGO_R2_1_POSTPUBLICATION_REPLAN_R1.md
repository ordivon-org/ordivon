### B3 — Preregister design and analysis

Recommended first inferential design: randomized blocked paired comparison at the **task-instance level**.

- block by task family/difficulty;
- randomize arm order/assignment reproducibly;
- use fresh Agents for each arm to avoid carryover;
- repeated provider calls inside one task are nested stochastic measurements, not independent `n`;
- evaluator remains blind to arm identity where practical.

Primary endpoints should be few and preregistered. Suggested primary pair:

1. independent semantic acceptance of final outcome;
2. rework/invalid-step burden before qualification.

Secondary/diagnostic endpoints:
- illegal composition/operator steps;
- failure-localization/minimal-frontier accuracy;
- unnecessary full restarts;
- tool/model calls, tokens and wall time;
- UNKNOWN handling and verifier disagreement;
- representation changes and successful repair locus.

Do not create a weighted “overall intelligence score”.
