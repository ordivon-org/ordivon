# B03 — Method Router Agent Skill Acceptance

Date: 2026-09-21
Status: ACCEPTED

The Method Router is implemented as a canonical Agent Skill at:

`meta/next/.agents/skills/method-router/`

It routes a scoped problem to the smallest useful subset of existing standards-backed method Skills. It does not implement a registry, trigger engine, learned ranker, tool executor, workflow engine, or method authority.

The routing map covers current canonical methods including systems engineering, DSM, compositional contracts, causal intervention, FMEA/FTA, STPA, feedback control, organizational cybernetics, information-flow analysis, evolutionary search, exploration policy and project-kernel decomposition.

Focused verification: 3/3 PASS.

The Skill remains independently canonical and may be consumed directly without Agent Plugin packaging.
