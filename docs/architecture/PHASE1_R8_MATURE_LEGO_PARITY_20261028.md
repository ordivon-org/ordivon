## DELETE / REUSE / KEEP MINIMUM DELTA decision principle

First discover actual users, production and public-facing contracts and effects from exact source, service, Work, provider, CLI/Skill/MCP, build/CI and scientific replay. Distinguish no observed consumer from proven no consumer. For each actual responsibility, test whether a mature upstream implementation covers the contract and edge cases. If it does, prefer direct upstream use and eliminate duplicative internal wrappers after cutover; if Ordivon adds only a necessary source-bound invariant or consent adapter, keep that minimal adapter. When no consumer is left, remove the smallest carrier after independent negative checks and native tests. UNKNOWN blocks destructive source or live changes; it does not become a reason for permanent preservation.
