# LEGO Theory Wave 3 R1

Date: 2026-09-18
Status: ACTIVE / PROSPECTIVELY VALIDATED WITH CONDITIONAL ALGORITHMIC ADOPTION

## Purpose

Wave 3 extends LEGO from analysis of an existing system toward disciplined creation, adaptive search, and organization:

1. exploration policy — how to allocate repeated experiment/search budget under uncertainty;
2. C-K design — how concepts and knowledge expand together when the desired object is not yet known;
3. evolutionary search — how candidate populations can vary and be selected without collapsing fitness into truth;
4. organizational cybernetics — how semi-autonomous units coordinate, adapt, and preserve identity under environmental complexity.

No Wave 3 concept is a mandatory LEGO Core field.

## W3-1 Exploration Policy

Primary mature foundation:
- multi-armed bandits / sequential decision theory.

Critical distinction:

`cumulative-reward optimization != pure exploration / best-option identification`

Use only when:
- decisions repeat;
- feedback can update later choices;
- trials have a meaningful budget/horizon.

Safety, authority, and irreversible effects remain outside reward optimization.

## W3-2 C-K Design

Primary mature foundation:
- Hatchuel-Weil C-K design theory.

Critical distinction:

`Concept space C != Knowledge space K`

The method tracks:
- C -> C concept partitions;
- C -> K experiments/analysis;
- K -> C concepts enabled by knowledge;
- K -> K knowledge expansion.

Its role is generative. It does not select products or convert concepts into facts.

## W3-3 Evolutionary Search

Primary mature foundation:
- evolutionary computing.

Core loop:

`population -> variation -> evaluation -> selection/archive -> next population`

Required safety boundary:

`fitness != domain truth != production authority`

Search requires candidate identity, lineage, diversity, independent verification, and explicit termination/restart.

## W3-4 Organizational Cybernetics

Primary mature foundation:
- Stafford Beer / Viable System Model.

Use the VSM functions as diagnostic coordinates:
- operations;
- coordination;
- internal control;
- environment/future intelligence;
- policy/identity.

Also inspect recursion and requisite variety.

The model is not a five-service architecture template. Published VSM applications and empirical tests must be allowed to challenge the mapping.

### Routing separation

Do not treat the three search/design lenses as interchangeable:

1. Desired object not yet known -> C-K Design.
2. Options already defined and repeated comparable feedback exists -> Exploration Policy.
3. Candidate representation and evaluator are trustworthy enough for population variation -> Evolutionary Search.
4. Problem is autonomy/coordination/control/environment/policy across organizational units -> Organizational Cybernetics.

Do not activate all four merely because a task contains the words search, exploration, adaptation, or optimization.

No Wave 3 object is promoted into the common LEGO schema. Algorithmic search remains subordinate to domain authority and independent verification.
