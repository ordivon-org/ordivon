# Planning

This directory contains only planning artifacts that still affect future work: active migration ratchets, prospective/pre-registered plans, and unresolved replacement decisions.

Planning is not runtime authority. Source code, schemas, provider-native state, configuration, tests, and external standards own the current executable truth appropriate to their domains.

When a plan has been implemented and its outcome is protected by current tests, architecture contracts, migration records, or evidence, remove the completed construction artifact from the working tree. Git history remains the historical owner of the old plan.

Do not introduce a repository-wide Ordivon planning ontology or plan schema merely to preserve completed work. Use a mature issue/project/work system when a durable collaborative planning provider is actually bound.
