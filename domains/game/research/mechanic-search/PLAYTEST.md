# Room Encounter — exploratory matched-margin paired study
Two technical previews, not commercial releases. A is original Trial; B
changes ordinary Guard block 3->2 and initial HP 48->53. Both start Classic;
facilitator selects T before each run. R restarts active condition; A/Space
attacks, G guards, N opens the door, choose Unlock, S/L save/load.
Extract each package into a separate folder. Verify SHA256SUMS before use.
Each condition has its own Godot user directory OrdivonRoomStudy/A or B.
Do not use these experimental builds for ongoing production play.
For consenting participants, assign balanced AB/BA before observation;
no strategy coaching. Record anonymous session code, condition and order,
binary SHA, win/loss/quit, duration, voluntary explanations of forecast and
Guard, observed repeated waiting and friction. Note any switch to Classic as
protocol deviation. Ask after each run how they understood the next hit and
whether choices felt meaningful; do not claim blind study or infer population
effects from this exploratory comparison. No identifiers, recordings or telemetry
required. A/B are paired but the HP difference is visible. No Human sessions
have been performed. This is separate from the existing Classic/Trial and R7 studies.
