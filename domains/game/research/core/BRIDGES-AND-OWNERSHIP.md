# Ordivon Game — Bridges & Ownership

This surface records consolidation-time owner boundaries. It is a navigation guard, not a global reassignment of other owners.

## Game-owned research responsibilities

Game owns:

- Game / PlayPractice constitutive semantics;
- Game-local action / control / skill responsibilities;
- Game-relative challenge / failure / mastery assessment;
- Game-local authoritative case status and derived Game views.

## Consumed owner-external truth

Game must not duplicate owner-external foundations merely because a Game consumer needs them:

- **Human:** experienced difficulty, frustration, flow, subjective competence, Human learning/retention, felt agency/body ownership/self-location, Human experience/value.
- **World:** underlying event/history/reality, physical/material truth, general dynamics and causal reality.
- **Media:** broader representation/signal/perceptual encoding and media/audience representation; Game owns only Game-relative projections where Game semantics require them.
- **Runtime:** generic physical execution, crash/receipt/response-loss recovery, technical recovery semantics.
- **Harness / Host:** generic orchestration, invocation, context/session and execution-coordination machinery.
- **Normative / external institutions:** general legitimacy and external normative admission; Game owns local constitutive/effective rule and current binding-status semantics only.

## Bridge rule

```text
consume/project owner-external truth
!= duplicate its semantic authority inside Game
```

Any future global ownership change requires cross-owner reconciliation rather than silent local promotion.
