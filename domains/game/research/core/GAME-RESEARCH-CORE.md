# Ordivon Game — Research Core

## Architecture

The current Game research root is exposed through six distinct lanes:

1. [Current Foundations](CURRENT-FOUNDATIONS.md)
2. [Practical Reconstruction](PRACTICAL-RECONSTRUCTION.md)
3. [Coverage & Frontier](COVERAGE-AND-FRONTIER.md)
4. [Precursor Genealogy](PRECURSOR-GENEALOGY.md)
5. [Negative / Superseded History](NEGATIVE-AND-SUPERSEDED-HISTORY.md)
6. [Product / Direction Research](PRODUCT-AND-DIRECTION-RESEARCH.md)

Cross-owner boundaries are indexed separately in [Bridges & Ownership](BRIDGES-AND-OWNERSHIP.md).

## Layering rule

```text
Current semantic authority      → GDF0–GDF3 frozen Foundation artifacts
Derived practical reconstruction → R0 / GPR1–GPR7
Coverage evidence                → whole-Game scans + C1–C9
Historical substrate             → R1–R29 / F1–F9
Negative history                 → cancelled / superseded branches and handoffs
Product/direction research       → GAME_CORE_* / Station Zero treatment research
```

These layers are intentionally not flattened into one registry.

## Foundation presentation families

The four current GDF identities may be explained through three families:

```text
Ludic Constitution
  → GDF0 Play / Game

Interactive Capability & Performance
  → GDF1 Action / Control / Skill
  → GDF2 Challenge / Failure / Mastery

Authoritative Practice Resolution
  → GDF3 Authoritative Case Determination
```

The families are explanatory compression only. They do **not** renumber, merge, or replace GDF0–GDF3.
