# Game Stage Lens

Use G0-G8 only when a coarse coordination vocabulary is useful for investment, scope or production communication.

## Authority

This Skill is **optional and advisory**. It is not the canonical lifecycle of Game, and it must not block creative composition. A project may skip, merge, reorder, rename, loop through, or entirely ignore these stages.

## Optional vocabulary

- G0 Define
- G1 Preproduction / Core Design
- G2 Kernel / Graybox Prototype
- G3 Playable Prototype
- G4 Vertical Slice
- G5 Production / Content Expansion
- G6 Alpha / Content-complete Validation
- G7 Beta / Polish / Release Candidate
- G8 Release / Operate / Learn

These labels summarize one possible production trajectory. They do not establish what makes a game good, creative, playable, interesting, shippable, or worth continuing.

## Use pattern

Apply the minimum useful label, if any. When reality does not fit the sequence, preserve reality and drop the label rather than forcing the work into the model.

## Non-goals

- no mandatory gates;
- no universal order;
- no product-selection authority;
- no evidence upgrade merely from stage naming;
- no restriction on experimental or unconventional production paths.
