# First Formal Game — Post-F0 Product Composition Value of Information R1

Status: **DECISION ACTIVE / PRE-G0 / PRODUCT NOT SELECTED**  
Observed: 2026-09-14

## Decision question

After PC01 and PC02 have both survived bounded composition falsifiers, which next experiment removes the most product-selection uncertainty per bounded unit of implementation/evidence cost?

This document **does not replace the historical composition definitions** in `GAME_PRODUCT_COMPOSITION_R1.md`. It supersedes only the next experiment-allocation decision after the newly observed PC01/PC02 evidence.

## Decision law

Do not rank by implementation maturity, code volume, historical familiarity, or the original FIRST/SECOND/THIRD execution order.

Allocate the next experiment to the live alternative whose cheapest valid carrier has the best combination of:

1. **remaining uncertainty that still changes product selection**;
2. **low bounded falsifier cost**;
3. **high elimination power** if the claim fails;
4. **orthogonality** to already-developed candidates, reducing capability/sunk-cost bias;
5. **claim-method fit** — do not use more automation when the unresolved variable is constitutively Human.

No synthetic precision score is assigned. The comparison is ordinal and evidence-bound.

## PC01 — Causal Works

### Current evidence

`SURVIVES_PC01_F0_STRUCTURAL_COMPOSITION` and PC01-F1 mechanical interactive acceptance both survive.

The current carrier already establishes, mechanically and within scope:

- diagnosis can precede architecture commitment and change the selected architecture;
- scarce inspection has positive expected value under the frozen F0 model;
- changed operating context revalues the preferred architecture (`process → route → source` without scanning);
- switching/persistence cost changes policy;
- architecture persists causally across cycles;

### Dominant remaining uncertainty

The highest-value remaining questions are now player-facing:

- can a Human form and revise the intended causal model from the presented signals?
- does diagnosis feel like a strategic choice rather than mandatory information tax?
- are delayed consequences legible enough to support attribution?
- does the repeated loop create valued mastery/replay rather than only mechanical non-degeneracy?

These cannot be established by another symbolic sweep or synthetic policy alone.

### Cheapest valid next carrier

A bounded Human-facing legibility/comprehension/playability probe on the existing F1 carrier, with mechanical telemetry retained as support.

### Allocation standing

`SURVIVOR / HUMAN-EVIDENCE FRONTIER / DO NOT DEEPEN MECHANICS NOW`

Incremental build cost is low, but the **valid evidence cost is Human** and this experiment does not broaden the candidate basis. It is therefore not the highest marginal VoI before the orthogonal PC03 branch receives one whole-composition falsifier.

## PC03 — Loop Cartographer

### Current evidence

PC03 has **no whole-product composition carrier yet**, but it does not start from zero.

The reusable PGP-A apparatus already establishes mechanically:

- direct left/right+jump control changes physical state;
- collision/hazard/reset paths execute;
- three timing-sensitive rooms have mechanically completable paths;
- reset is immediate;
- a naive always-jump policy clears the easy room but repeatedly fails the timing-gated room;
- the apparatus therefore contains a real timing distinction.

This evidence does **not** establish Human mastery, flow, learning, retry desire, or player value. Historical T05 failure remains a negative boundary and must not be retuned into success.

### Live whole-composition uncertainty

PC03 asks a different product question from PC01/PC02:

> Can one stable movement grammar support a loop where understanding a world/traversal rule changes later route choice, while execution remains meaningfully demanding after the rule is understood?

The cheapest experiment can still eliminate the composition mechanically before expensive Human evidence.

### Cheapest valid next carrier

Build an **interactive PC03-F0 whole-composition falsifier by reusing PGP-A**, not a symbolic-only model and not a new engine stack.

Minimum carrier:

1. retain the stable move+jump verb set and immediate retry;
2. arrange a compact 4–6-region looping map;
3. introduce one stable, legible traversal/world rule that applies in more than one place;
4. include one shortcut that is physically available through the same verbs from the beginning — **no inventory key and no authoritative `knowledgeUnlocked` gate**;
5. include matched safe and demanding/fast lines;
6. reset World progress while leaving the rule itself stable, so progress can be carried by player knowledge rather than account state;
7. later route choice must materially differ when the rule is understood;
8. knowing the rule must not remove execution demand from the demanding line.

Automated/mechanical checks may establish:

- same verb grammar across all regions;
- no item/boolean knowledge gate controls the shortcut;
- safe and fast paths are both reachable;
- an uninformed bounded baseline does not exploit the shortcut reliably while an informed policy changes route choice;
- an informed but timing-insensitive policy still fails the demanding line where an informed timing-aware policy succeeds;
- reset removes transient World progress without changing the traversal rule;
- the same learned rule is reusable in at least two locations;
- retry latency remains bounded and no repeated dead traversal is mechanically required.

Human evidence remains required later for:

- felt mastery / self-attributed improvement;
- whether rule discovery is understandable rather than arbitrary;
- whether execution remains satisfying after understanding;
- whether repeated traversal feels like practice rather than dead time;
- voluntary retry, flow and overall player value.

### Allocation standing

`NEXT EXECUTABLE / HIGHEST MARGINAL VoI / ANTI-SYSTEM-BIAS CONTROL`

Why:

- it tests the only current whole-product alternative whose composition coupling is still unfalsified;
- PGP-A makes the implementation cost low-to-medium rather than greenfield;
- failure cheaply removes a materially different product family before Human-testing budget is concentrated on PC01/PC02;
- survival creates a broader and less capability-biased basis for later Human comparison;
- it prevents PC01's greater implementation maturity from becoming accidental product authority.
