### PGP-A — Precision Traversal

The apparatus contains three bounded rooms:

1. direct gap;
2. timing gate;
3. safe-vs-fast line.

Player controls are left/right plus jump. Misses reset immediately. The surface exposes live room, attempt, miss-reset and completion state but no score, collectibles, progression economy or story reward.

Automated browser evidence establishes:

- keyboard input changes the physical state;
- manual reset works;
- collision/hazard/reset paths execute;
- all three timing-sensitive rooms have a mechanically completable keyboard path;
- room-completion events are retained in local session evidence.

A useful negative occurred during apparatus validation: a naive always-jump policy clears Room 1 but repeatedly fails the Room 2 hazard. The final automation therefore waits for grounded position before issuing human-like keydown/keyup jumps. This is evidence that the apparatus contains an actual timing distinction, not evidence that a human experiences mastery or flow.

### PGP-D — Investigation

The apparatus contains one authored relay-sabotage case with six independently inspectable clues and three live hypotheses.

Automated browser evidence establishes:

- clue access works in arbitrary order;
- the authoritative answer remains sealed before determination;
- the player must commit both a hypothesis and a mechanism/reason;
- a multi-clue causal determination path can be completed;
- the result is revealed only after commitment.

Automation does **not** establish an earned aha, fairness, causal understanding or replay value.

### PGP-I — Creation / Expression

The apparatus provides five primitive types under a six-piece budget, position/scale/rotation transforms, undo, revision save, and revision comparison.

Automated browser evidence establishes:

- primitives can be composed;
- a selected primitive can be transformed;
- undo state is retained;
- at least two distinct revisions can be saved and compared;
- session evidence persists locally.

Automation does **not** establish divergent authorship, intention, expressive ownership, aesthetic value or desire to continue creating.
