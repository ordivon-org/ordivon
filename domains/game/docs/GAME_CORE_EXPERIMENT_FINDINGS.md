# Ordivon Game Core — Early Experiment Findings

## Evidence boundary

The first Concept Lab round used direct browser inspection, autonomy-vs-cheap-baseline E2E, fresh-agent blind play and deletion pressure. Station Zero additionally contributes much deeper deterministic/live-Agent, recovery, replay and product-surface evidence accumulated over prior rounds.

These results establish mechanism and structural evidence. They do not establish human fun, retention, market demand or a product winner.

## Method finding — make the treatment eligible to fail

The first blind-play pass exposed treatment defects before product conclusions were trustworthy:

- Casefile had a trace/clue mismatch and over-direct evidence;
- Last Light under-expressed food/progress cost relative to relationship recovery;
- Echo Hunt admitted impossible boundary moves and originally made information-gathering unfairly lethal.

Correct principle:

> A prototype must first be capable of failing for the intended design reason before its result can update the Game Core model.

## Station Zero finding — delegation is real but expensive experientially

Station Zero strongly supports:

- `model output ≠ World truth`;
- bounded observation and action admission;
- autonomous decisions can produce materially different World trajectories;
- feedback changes later Agent behavior;
- recovery/replay can preserve causal evidence;
- mixed cognition tiers are viable.

But it also exposes a recurrent failure region:

```text
rich delegation machinery
→ plan/configuration/review burden
→ player acts like operator of an evidence system
```

The durable lesson is not “delegated tactics wins” or “delegation fails.” It is that delegated agency must create enough responsibility, surprise or strategic leverage to repay its interpretive/administrative cost.

## Casefile finding — epistemic separation is a promising mapping

Casefile demonstrates that this World discipline can become player-native play:

```text
Reality
≠ Observation
≠ Belief
≠ Statement
≠ Player inference
```

The treatment can produce contradictions a player may act on without exposing internal provider/evidence machinery.

Fresh blind play showed the loop was operable and exposed a real breadth-vs-depth investigation tradeoff. However the matched autonomy treatment did not materially outperform the cheaper fixed/policy testimony treatment.

Therefore:

- **retain** epistemic/social inference as an important Core direction;
- **retain** Casefile as an executable treatment;
- **do not** select Casefile as a product;
- **do not** infer that live model dialogue is required.

## Last Light finding — relationship value remains unresolved

The current treatment does not yet isolate dependency/trust well enough. Resource optimization dominated behavior.

This does not reject companion/relationship games. It says the current treatment has low discriminative power for the hypothesis we care about.

The direction remains open and should only receive a better experiment if relationship/persistent-character mechanisms become important to the next Core question.

## Echo Hunt finding — cognition cost can be rejected locally

After correcting treatment defects, richer adaptive behavior and a cheap pursuit/adaptive policy produced effectively similar fresh-player trajectories in the tested slice.

Therefore current evidence rejects:

> “this predator experience requires richer/model cognition.”

It does **not** reject:

> adversarial adaptation as a game direction.

This distinction must be preserved in future negative results.

## Cross-treatment findings worth carrying forward

1. **Game form precedes tool choice.** Existing infrastructure or model access does not select the experience.
2. **Agent-first does not mean LLM-first.** Policy, model, human and mixed cognition are interchangeable implementation classes until experience proves otherwise.
3. **Authority separation survives materially different worlds.** Station Zero and Casefile both benefit from cognition/inference being separate from authoritative Reality.
4. **Hidden state needs player-legible evidence.** Uncertainty becomes play only when players can form and revise a model.
5. **Persistence must alter later possibility.** Retained logs alone are not experiential history.
6. **Player-facing vocabulary should be domain-native.** Provider/Candidate/hash/revision concepts belong below the experience unless they are themselves the game.
7. **Prototype evidence is local.** A result may narrow one mechanism claim without selecting or eliminating an entire genre/direction.
8. **Search breadth matters.** Four treatments are nowhere near enough to declare the first Ordivon Game form.

## No selection result

The previous `Casefile SELECT / Last Light DEFER / Echo Hunt REJECT` wording is superseded.

Current interpretation:

```text
Station Zero → strong delegation reference + administration-pressure evidence
Casefile     → promising epistemic/inference treatment
Last Light   → relationship treatment currently inconclusive
Echo Hunt    → adversarial treatment; expensive cognition not earned in tested slice
```

There is **no product winner**.

## Next research use

The next step is not another concept contest. It is to decompose Game Core and the accumulated findings into a higher-level map of:

```text
Core responsibility
× agency topology
× consequence type
× persistence horizon
× player-value mode
× Agent participation mode
```

Then select only a few high-information experiments that distinguish competing hypotheses.
