# Ordivon Game — Practical Reconstruction R0–GPR6 Closeout / Residual Coverage Search

## 0. Why this round exists

GPR6 completed the six priority clusters selected by R0:

```text
P1 Role / Authority
P2 Determination / Contestability
P3 Evidence / Norm / Explanation
P4 Enforcement / Remedy
P5 Role Bundle Templates
P6 Human / Agent Vocabulary Views
```

The wrong next move would be:

```text

```

This round therefore reopens **coverage**, not foundations.

```text

B. Did R0 itself cover the whole practical-reconstruction space implied by frozen GDF0-GDF3?
```

Those questions must not be conflated.

# 19. Recovery has the strongest terminology collision

Current repository uses `recovery` for at least four unrelated practical meanings.

## A. Technical durable recovery

```text
store.recover(runId)
turnService.recover(runId)
playService.recover(runId)
```

This means:

```text
reconstruct / verify committed durable state after crash or response loss
```

It is Runtime/Game persistence semantics.

## B. Gameplay objective verb

```text
recover-research-core
```

means:

```text
retrieve/extract cargo
```

not post-failure continuation.

## C. Gameplay responsibility vocabulary

```text
recover-civilian
support-civilian-recovery
```

means rescue-task work.

## D. GDF2 FailureRecovery

means authoritative continuation after a scoped failure/outcome:

```text
continue
checkpoint restore
revive
reset
alternate route
new run
no continuation
```

These four must not share one semantic object merely because English uses `recover`.
