# Ordivon Game Foundations Research — R29 Whole-Corpus Synthesis, Redundancy Audit, Causal Closure and Foundation Falsification

## 0. Status and boundary

R1–R28 deliberately expanded the search space. R29 performs the opposite operation.

R29 asks:

> Which distinctions are genuinely independent semantic coordinates, which are recurrent derived domain views, which are player/design criteria, and which belong only to implementation?

The objective is **not** to prove a metaphysically final ontology of all games.

The objective is to freeze the smallest currently justified semantic foundation stack that:

```text
1. preserves the counterfactual distinctions established by R1–R28;
2. survives materially different GameForms;
3. keeps authority / truth / belief / value / control boundaries explicit;
4. does not promote every useful concept into an equal primitive;
5. can be reopened when a falsifier exposes a genuinely independent missing coordinate.
```

Starting warnings:

```text
EncodingSufficiency != ExplanatorySufficiency
MathematicalRepresentability != SemanticEliminability
Primitive != Important
Derived != Disposable
NamedRound != Primitive
StateVariable != MeaningfulOntology
Graph != DomainSemantics
Scalar != ValuePlurality
SameImplementation != SameWorldSemantics
DifferentImplementation != DifferentWorldSemantics

WorldModel != GameDefinition
GameFoundation != ProductArchitecture
FoundationResearch != ProductSelection
ResearchRound != G-stage
```

No product is selected by R29.

---

# 1. R29 method — deletion before addition

For each concept R29 asks:

```text
What counterfactual does this concept preserve?
Can the same counterfactual be represented by lower semantic coordinates?
Would doing so merely encode the distinction, or still expose its causal meaning?
Does the distinction recur across materially different GameForms?
Who/what owns its authority?
Is it world state, Subject state, relation, process, view, design criterion or implementation?
What breaks if we delete it?
```

R29 prefers compression only when the relevant answers remain legible.

---

# 2. Foundation Admission Test

A future candidate deserves promotion toward an independent foundation coordinate only if it survives all of the following.

## 2.1 Counterfactual separability

```text
Holding relevant other coordinates fixed,
changing candidate X can change a meaningful prediction / reachable future.
```

## 2.2 Semantic irreducibility at the chosen level

The distinction cannot be reconstructed from lower coordinates without reintroducing the same semantic distinction under another name or hiding it inside an opaque state variable.

## 2.3 Cross-form portability

The distinction survives at least two materially different GameForms rather than one content genre or implementation style.

## 2.4 Authority clarity

The model can say what makes the candidate true/false/current/binding and who may change it.

## 2.5 Implementation independence

The distinction survives replacement of engine, model, database, renderer or cognition mechanism when diegetic semantics are unchanged.

## 2.6 Deletion cost

Deleting the candidate forces systematic semantic conflation, repeated ad-hoc exceptions or loss of tested player-relevant counterfactuals.

## 2.7 Level test

The candidate is not merely:

```text
an implementation mechanism,
a descriptive summary,
a domain-specific convenience view,
or a player-value metric.
```

If it is one of those, it may remain first-class vocabulary without becoming a foundation coordinate.

# 3. External pressure tests

R29 uses several external frameworks as adversarial compression tests rather than imported ontologies.

## 3.1 State-transition / POMDP pressure test

Kaelbling, Littman & Cassandra's POMDP formulation demonstrates the power of a compact sequential-decision substrate built around state, actions, probabilistic transitions, observations and policies/belief state under partial observability.

R29 lesson:

```text
State / Transition / Observation / Policy
are genuinely high-yield coordinates.
```

But POMDP compactness does not establish that Game semantics should reduce to a scalar reward plus an untyped state vector. Identity authority, social obligation, authored provenance, player interpretation and cultural continuity can all be *encoded* in state without being *explained* by the POMDP vocabulary.

## 3.2 Stochastic / Markov games pressure test

Shapley's stochastic games and Littman's Markov-game framework extend dynamic state/action transition reasoning to interacting players/agents with different goals.

R29 lesson:

```text
Multi-Subject strategic interaction
can be built over a shared causal state-transition substrate.
```

This supports treating Strategy as a domain view over Subject policies, beliefs and coupled consequences rather than a new physical primitive.

## 3.3 Causal-model pressure test

Pearl's causal-diagram work shows that graph structure plus subject-matter assumptions can support intervention/counterfactual queries; causal structure is not recovered from correlation alone.

R29 lesson:

```text
Causality is a general cross-domain relation/test.
Domain-specific “XCausality” names need not each become primitives.
```

But a bare graph does not supply edge semantics, authority or domain meaning by itself.

## 3.4 Marr/Poggio and Newell — levels matter

Marr & Poggio distinguish computational, algorithmic/mechanistic and implementation levels. Newell's knowledge-level analysis similarly argues that a system can be characterized at a level that is not exhausted by its lower implementation description.

R29 lesson:

```text
Lower-level reducibility
!=
license to erase higher-level explanatory semantics.
```

This is the central defense against both ontology inflation and ontology collapse.

## 3.5 MDA — mechanics, dynamics and player experience are different views

Hunicke, LeBlanc & Zubek's MDA framework distinguishes mechanics, dynamics and aesthetics/player experience as different design views.

R29 lesson:

```text
Player experience criteria should not be stored as if they were ordinary World facts.
```

The exact MDA taxonomy is not imported, but the level separation survives R1–R28 strongly.

## 3.6 Juul — do not freeze one brittle universal game definition

Juul's classic game model emphasizes rules, variable outcomes, outcome value, player effort/attachment and negotiable consequences, while also noting that computer games such as MMORPGs challenge the classic boundary.

R29 lesson:

```text
Do not confuse our operational Ordivon foundation stack
with a necessary-and-sufficient metaphysical definition of every “game”.
```

## 3.7 Ostrom/Crawford — institutions are structured domain semantics over repeated situations

Crawford & Ostrom analyze institutions through rules, norms and shared strategies in repeated situations embedded in a physical/social world.

R29 lesson:

```text
Institution is compositionally grounded,
but its typed rule/norm/authority semantics remain useful explanatory structure.
```

Derived does not mean useless.

## 3.8 Moral/conventional distinction — R15 “Norm” was too broad as a generic label

Nucci & Turiel's moral/conventional studies and later social-domain work distinguish judgments treated as authority-dependent social conventions from many judgments treated as more authority-independent moral concerns.

R29 lesson:

```text
R15's
Norm = SharedExpectation + DistributedEnforcement
should be read canonically as SocialNorm,
not as the definition of all normative evaluation.
```

Private moral/value commitments remain representable through R18 Value/Commitment and belief/evaluation structures without social enforcement.

## 3.9 Grice / signaling-convention pressure test for Language

Gricean communication analysis makes speaker meaning depend on communicative intention, while signaling/convention models show how stable signal–response systems can arise through coordination.

R29 lesson:

```text
Language does not force a new foundation coordinate by default.
```

Signal, Symbol, SharedMeaning, Grammar, CommunicationIntent, Belief, Convention, Learning and Culture already expose the relevant causal distinctions at the current level.

## 3.10 Sacred values pressure test

Sacred-value research shows that some values/commitments are treated as non-tradable and resist ordinary material trade-off framing.

R29 lesson:

```text
Value must remain plural / non-scalarizable by default.
```

R18's “scalarize late” rule survives; Religion/Morality do not require a universal utility scalar.

# 4. The first major R29 result — the corpus contains different levels

R1–R28 are not twenty-eight equal ontology modules.

R29 separates four levels.

## Level A — Semantic causal coordinates

The smallest currently justified coordinates used to state what exists, what can change, what is observed/valued and what is authoritative.

## Level B — Derived domain views

Stable reusable compositions such as:

```text
Resource
Risk
Strategy
Relationship
Institution
IdentityContent
Emotion
Learning
Culture
Narrative
Creation
Economy
```

These may be crucial to a product without being independent foundation coordinates.

## Level C — Player/design meta-criteria

Examples:

```text
PlayerValue
Fun
Engagement
Tension
Depth
Difficulty
Legibility
Playable-X
Fantasy / target experience
```

These evaluate/couple the causal system to player experience; they are not ordinary diegetic facts by default.

## Level D — Implementation mechanisms

Examples:

```text
LLM
FSM
behavior tree
RL algorithm
vector store
database
network protocol
render engine
clock implementation
UI widget
procedural generator
```

Implementation can realize semantic coordinates but does not own their meaning automatically.

Strong law:

```text
Primitive != Important
Derived != Disposable
Implementation != Semantics
```

# 6. Encoding sufficiency versus semantic sufficiency

The strongest R29 distinction is:

```text
EncodingSufficiency =
“I can put enough variables in state to reproduce behavior.”

SemanticSufficiency =
“I can state the distinctions, authority, counterfactuals and invariants
at the level where design/reasoning depends on them.”
```

A Turing-complete program can encode everything in one byte array.

That does not make:

```text
ByteArray
```

a useful Game foundation ontology.

Likewise:

```text
State = {everything}
```

is not an explanation.

# 7. Compression candidate A — one universal State

Candidate:

```text
Game = State + Update(State)
```

## Strength

Extremely compact; computationally universal enough in principle.

## Failure

It erases tested distinctions unless they are smuggled back into state labels:

```text
WorldTruth vs Belief
Value vs Fact
Identity vs Similarity
Authority vs Observation
Policy vs Capability
Rule vs CurrentState
Player vs Character
History vs Memory
```

Verdict:

```text
Encoding-sufficient.
Semantically underfit.
Reject as foundation surface.
```

---

# 8. Compression candidate B — POMDP / Markov-game surface

Candidate family:

```text
State
Actions
Transition
Observation
Reward / utility
Policy / Agents
```

## Strength

Excellent for sequential decision, uncertainty, planning and interacting policies.

## Failure 1 — scalar reward pressure

R18, R20, R22 and R29 sacred-value tests show that:

```text
Value != one universal scalar by default.
```

## Failure 2 — authority/provenance hidden in state

Clone identity, legal ownership, generated world claims, tradition lineage and shared relational facts can be encoded, but the formalism does not itself preserve their semantic authority boundaries.

## Failure 3 — derived domain semantics disappear

Institution, relationship, culture and authorship become anonymous state variables unless typed views are retained.

Verdict:

```text
Excellent algorithmic/decision formalism.
Insufficient as the complete explanatory Game ontology.
```

---

# 9. Compression candidate C — flat list of all R1–R28 terms

Candidate:

```text
Make every named distinction a first-class primitive.
```

## Strength

Maximum local semantic legibility.

## Failure

Produces:

```text
duplicate topology primitives
duplicate causality primitives
duplicate authority primitives
duplicate contracts
duplicate Playable-X criteria
historical round ownership masquerading as ontology
```

It also obscures relationships such as:

```text
Risk = Uncertainty × Valued Consequences
Learning = experience-linked retained Subject transition
Strategy = coupled Subject policies/beliefs
Culture = distributed socially transmitted/reproduced structure
```

Verdict:

```text
Semantically overfit.
Reject as primitive stack.
```

# 10. Compression candidate D — layered semantic kernel + typed domain views

R29 retains this architecture.

```text
Layer A: Semantic causal coordinates
Layer B: Derived domain views
Layer C: Player/design criteria
Layer D: Implementation
```

This gives the smallest stack found so far that preserves R1–R28 counterfactuals without turning the repository into either a byte array or a dictionary of 1,000 primitives.

# 11. Game Foundations v1 — semantic coordinate kernel

R29 freezes the following **semantic coordinate families**, not mandatory database tables.

```text
F1  Entity / Reference
F2  State
F3  Relation
F4  Transition / Constraint
F5  Time
F6  Authority / Provenance
F7  Observation / Representation
F8  Evaluation / Motivation
F9  Action / Capability / Policy / Control
```

The grouping is deliberate.

These coordinates are not claimed to be mathematically irreducible. They are the smallest currently justified **explanatory coordinates** under the Foundation Admission Test.

---

# 12. F1 — Entity / Reference

Question:

```text
What referent are we talking about?
```

Minimal role:

```text
Entity = authoritative referent capable of bearing state/relations through a relevant scope.
```

R24 shows why this cannot disappear into qualitative state equality:

```text
same state != same entity
clone similarity != numerical identity
```

Entity identity can be domain-/authority-relative across time; richer Identity remains a derived view.

---

# 13. F2 — State

Question:

```text
What is currently the case under a specified authority/time scope?
```

State may include:

```text
physical
social
economic
institutional
created-artifact
subject-internal
```

facts.

State is not equivalent to observation, belief or narrative description.

---

# 14. F3 — Relation

Question:

```text
How are entities/states structurally related?
```

Examples:

```text
adjacent-to
owns
member-of
trusts
can-observe
committed-to
parent-of
controls
recognized-by
transmits-to
```

A relation can be directed, asymmetric, weighted, scoped and temporal.

R16/R25/R28 show that flattening all relations into object attributes loses topology and multi-party semantics.

---

# 15. F4 — Transition / Constraint

Question:

```text
What changes are possible, admissible and resolved how?
```

A useful semantic decomposition:

```text
TransitionSemantics =
Trigger / Intent
+ Preconditions
+ Capability / Authority checks
+ Constraints / Rules
+ Resolution
+ State/Relation changes
+ emitted Events / Evidence
```

Rules/constraints need not be a separate ontological substance: they define admissible/resolution structure over transitions and state.

---

# 16. Event is realized transition, not a separate primitive family

R29 compresses:

```text
Event = realized occurrence/change under Transition + Time semantics.
```

Events remain useful first-class records, but do not require a new coordinate beyond transition/time/provenance.

---

# 17. F5 — Time

Question:

```text
How are states/events/processes ordered, extended, synchronized and mapped among frames?
```

R23 remains authoritative:

```text
Time != Clock
ClockOrder != CausalOrder
Simultaneity != Concurrency
```

Time is retained because ordering/duration can change consequence while a static state description remains identical.

---

# 18. F6 — Authority / Provenance

Questions:

```text
What makes this claim/state/identity/transition binding?
Where did this current state/form/claim come from?
Who/process may change it?
```

Generic form:

```text
Authority(scope, claimType, t)
→ adjudicator / criterion / owning transition semantics
```

```text
Provenance(x)
→ causal / authorship / lineage / source path relevant to x
```

These are cross-cutting semantics rather than separate IdentityAuthority, UpdateAuthority, RelationalAuthority, etc. primitives.

---

# 19. Authority is not centralized by definition

Authority may be:

```text
World rule
institution
shared/joint state protocol
subject-local belief authority
player choice
external reality feed
adjudicated consensus
```

Different claim types can have different authorities.

```text
WorldTruth authority
!= SubjectBelief authority
!= IdentityRecognition authority
```

# 20. F7 — Observation / Representation

Question:

```text
What evidence becomes available to whom, and how is it represented internally?
```

R17 gives the canonical epistemic chain:

```text
WorldTruth
→ Signal
→ Observation
→ Interpretation
→ Belief
→ Statement
```

R27 adds Memory/SelfModel as retained or self-referential representation views.

R29 groups these under an epistemic coordinate while preserving the distinctions internally.

# 21. Observation != Representation

Observation is newly available evidence/percept.

Representation includes:

```text
belief
memory
world model
self-model
opponent model
uncertainty distribution
```

The grouping means one semantic family, not synonymy.

# 22. F8 — Evaluation / Motivation

Question:

```text
What matters to the relevant Subject/participant, and how are alternatives evaluated?
```

R18 remains canonical:

```text
Need
Value
Desire
Preference
Goal
Commitment
```

are distinct useful structures.

R29 retains them as a typed internal family under one broader evaluative coordinate.

Strong law:

```text
Evaluation != WorldTruth
Value != Reward
Value != one scalar
```

# 23. Player Value and Subject Value remain distinct

```text
SubjectValue
= what matters inside a modeled Subject.

PlayerValue
= design/evaluative judgment about the human/participant experience.
```

A villain may value domination while the player values strategic tension.

Do not merge them into one utility function.

---

# 24. F9 — Action / Capability / Policy / Control

Question:

```text
What can act, what does it select, and whose intent causally influences the transition?
```

R21 remains authoritative internally:

```text
Intent != Input != Command != Action != Outcome
Affordance != Capability != Legality
Control != SenseOfAgency
```

R29 groups these as one action/control semantic coordinate family because they jointly connect Subjects/participants to transitions, but none of their internal separations are deleted.

---

# 25. Policy is not Capability

```text
Capability = can execute.
Policy = how/selects what to attempt.
Control = whose intent can change action/trajectory.
```

All three can vary independently in counterexamples already established by R10/R11/R21.

---

# 26. World becomes a composition, not another primitive beside the kernel

R9 survives as:

```text
World =
authoritative composition of
Entities + State + Relations
+ Transition/Constraint semantics
+ Time
+ Authority/Provenance
```

A World may expose none, some or many Subjects.

---

# 27. Subject becomes a composition

R10/R18/R21/R27 synthesize to:

```text
Subject =
Entity
+ bounded Observation
+ Internal Representation / State
+ Evaluation / Motive Structure
+ Capability
+ Policy
+ consequential Action participation
```

Not every Actor needs every Subject component.

```text
Object
→ Actor
→ Subject
```

remains a useful complexity gradient.

---

# 28. Player is a role at the system boundary, not necessarily a World Subject

A Player may:

```text
control a Character
control several Subjects
edit the World
make meta-decisions
observe without diegetic embodiment
```

Therefore:

```text
Player != Character != Subject
```

R24/R21 already proved this locally; R29 makes it structural.

---

# 29. Participant coupling

Player interaction can be described without a new primitive family:

```text
World/Subject State
→ Observation Surface
→ Player Interpretation
→ Intent
→ Control Mapping
→ admitted Transition
→ Consequence
→ Feedback Observation
→ Attribution / Learning
```

Interface and feedback are mappings over F7/F9 plus presentation. They remain product-critical even though they are not separate world ontology coordinates.

---

# 30. History is derived but foundationally important

R13/R23/R27 synthesize:

```text
History =
past Events/States whose causal/provenance traces
remain relevant to present/future structure.
```

It derives from:

```text
Transition
+ Time
+ retained State/Relation traces
+ Provenance
```

Therefore:

```text
History is not an independent semantic coordinate,
but deleting the History view would destroy useful reasoning.
```

This is a canonical example of:

```text
Derived != Disposable.
```

---

# 31. Memory is a Subject-facing history projection

R27 remains canonical:

```text
Memory = past-derived trace/information/state
made functionally available to present/future cognition/action.
```

It derives from history/state/representation/retrieval, not from a separate universal memory substance.

# 35. Contract family compression

R22/R23/R25/R27 introduced:

```text
UncertaintyContract
TemporalContract
RelationalContract

```

R29 treats these as typed instances of a design/semantic specification view:


R29 compresses them into:

