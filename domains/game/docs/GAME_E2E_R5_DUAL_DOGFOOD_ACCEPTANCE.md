# Game E2E R5 — Dual-Game No-Judgment-Loss Acceptance

## 0. Purpose

Subtraction is successful only if the recomposed Game E2E preserves or improves judgment/falsification power while reducing Game-owned generic machinery.

The two current materially different dogfood lineages are:

```text
Station Zero v3
Veilwild R1 / R4 corpus
```

No new synthetic second game is required for this round.

## 1. Acceptance dimensions

R5 must report each dimension independently. No single scalar maturity score can hide an UNKNOWN.

```text
DomainSemanticPreservation
TechnicalFailureDetection
CandidateIdentityIntegrity
RecoveryIntegrity
HumanClaimDiscipline
RightsDiscipline
NonSpoilingObservation
CrossOwnerSubstitution
GenericInfrastructureReduction
CrossGameReuse
```

## 2. Station Zero matrix

The recomposed path must preserve at least these Game judgments:

| Class | Required preservation |
| --- | --- |
| World authority | physical/numerical/temporal/terminal state remains Game World authority |
| Candidate/action admission | model prose cannot directly mutate Game state |
| planning identity | immutable planning/turn identities remain exact |
| hidden information | enemy/private plan or hidden World truth cannot leak through player projection |
| replay | exact historical world reconstruction remains possible |
| uncertain durable turn | original identity is observed/recovered; no blind new-identity retry |
| deterministic policy | equivalent input ordering retains identical authoritative result digests where contract requires it |
| product projection | Mission Control/play view does not create second truth |
| Human claims | browser or synthetic success does not imply fun/value |

## 3. Veilwild R4 historical failure matrix

At minimum, R5 must still detect or refuse to overclaim these historical classes:

| Historical class | Required R5 behavior |
| --- | --- |
| missing Godot scene `unique_id` | technical/source gate must fail or remain unresolved until physical source is repaired |
| stale selected-runtime identity | exact candidate/source/artifact binding must reject stale green evidence |
| wrong provenance/consumer path | evidence must bind to exact producer/consumer bytes or remain inadmissible |
| strict oracle parse/runtime failure | candidate technical admission fails closed |
| pre-ready lifecycle timing | fixed-frame or premature readiness assumptions must not mint PASS |
| cross-candidate evidence composition | prohibited by default |
| build identity misuse | exact build artifact must be resolved before final evaluation |
| rights false-green | provenance alone cannot authorize distribution |
| telemetry semantic inference | transport layer cannot invent Game owner semantics |
| Human claim overreach | fun/fairness/comprehension/comfort/accessibility fit stay UNKNOWN without Human evidence |
| hidden target-coordinate leakage | non-spoiling observation requirement must fail if hidden truth leaks |
| producer-only finality | independent destroyer must be able to contradict premature final claims |

## 4. Human-evidence acceptance

R5 is not allowed to graduate merely by preserving UNKNOWN forever.

At least one real player-research path must be representable through Research E2E as:

```text
DecisionToInform
→ researchIntent
→ exact targetOfInquiry (candidate/build/condition/population)
→ claimBoundary
→ evaluationLogic / method profile
→ observed evidence
→ scoped standing
→ Game decision
```

Synthetic subjects may support structural claims but cannot substitute for Human experience claims by identity.

## 5. Cross-owner substitution acceptance

For each migrated generic concern, record:

```text
old Game-local owner
current replacement owner
exact consumer
failure mode if replacement unavailable
recovery/currentness rule
before/after Game-owned LOC or surface count
replay evidence
```

A replacement that only moves files without changing semantic ownership does not count as subtraction.

## 6. Reduction acceptance

R5 succeeds only if all hold:

```text
Game-specific generic infrastructure decreases materially;
Game-specific semantic authority does not decrease;
Station Zero judgment coverage does not decrease;
Veilwild R4 failure coverage does not decrease;
Human/rights UNKNOWN states remain explicit rather than cosmetically upgraded;
owner-mechanical coordination decreases;
new Game/profile bootstrap requires fewer fixed Agent roles and fewer duplicate schemas.
```

## 7. Promotion gate

Default-ready Game E2E promotion requires:

1. recomposed Station Zero replay PASS within its exact scope;
2. Veilwild historical failure-matrix replay PASS/expected-fail with no false green;
3. current owner substitution for at least the strongest generic duplicate (`src/host-contract` family);
4. no unresolved cross-candidate or rights false-green;
5. Human claims remain correctly scoped, with at least one Research-E2E player-evidence path exercised when feasible;
6. independent destroyer review;
7. explicit residual list for any Game-owned generic machinery that remains because substitution failure was demonstrated.
