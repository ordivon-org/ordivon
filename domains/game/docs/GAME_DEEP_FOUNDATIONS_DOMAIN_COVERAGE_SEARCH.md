# Ordivon Game Deep Foundations — Whole-Referent Domain Coverage / Residual Search

## 0. Status and boundary

This search begins from a deliberately empty next-route assumption.

Frozen and not re-run:

```text
GDF0 Play / Game                       = FROZEN
GDF1 Action / Control / Skill          = FROZEN
GDF2 Challenge / Failure / Mastery     = FROZEN
R1-R29 / F1-F9                         = FROZEN SEMANTIC SUBSTRATE
```

Withdrawn navigation assumption:

```text
next = Game Feel
```

is not used.

Likewise the previously named Time/Rhythm, Space and Strategy handoffs are treated only as evidence that those regions exist. They receive no priority from numbering or historical mention.

The question here is not:

```text
Which familiar Game-design topic should be GDF3?
```

It is:

```text
What parts of the reality denoted by Game remain
(a) deeply covered,
(b) semantically named but mechanistically shallow,
(c) only indirectly represented,
(d) owned elsewhere,
(e) cross-cutting,
(f) structurally homeless even in our current vocabulary?
```

Only after that map is built may a next deep-foundation object be admitted.

---

# 1. Coverage vocabulary

This audit uses six distinct statuses.

```text
D  = deep / frozen: survived dedicated counterfactual, cross-form and owner-boundary work.
S  = strong semantic/domain coverage: terms and causal distinctions exist, but no dedicated deep GDF reconstruction.
P  = partial: important pieces exist, but recurrent mechanisms or regimes remain under-modeled.
H  = structurally homeless: recurrent Game reality lacks a clear Game-native research owner/view in the current corpus.
X  = owned elsewhere: Game must consume a boundary contract but should not duplicate the lower science.
A  = Agent-era amplified/new configuration: existing distinction is stressed or newly composable; not automatically a new primitive.
```

Two warnings:

```text
Encoding coverage != explanatory/mechanistic coverage.
Named vocabulary != coverage.
```

R29 proved a strong semantic kernel on its test set. It did not prove exhaustive Game-domain knowledge.

| CSCW/communities of practice/fandom | R25/R28 partial | participation-role topology, spectatorship and community→game feedback are weak |

| experience management/player modeling/DDA | GDF2 can consume changed difficulty; R27 models Subject learning | **Game adapting itself to a player model** is not the same as player/Subject learning and is not deeply owned |
| rhetoric/hermeneutics/procedural meaning/ideology | R8/R28/R29 semantic closure tests | interpretation effects remain cross-owner; no new coordinate signal |
| accessibility/inclusive design | GDF1 control remapping/shared control; GDF2 attribution | population/body variability and social access remain partial; lower mechanisms cross-owner |
| serious games/education/human computation/citizen science | participation purpose/external stakes represented in GDF0 | role identity can shift player↔worker↔learner↔research participant; participation topology remains weak |
| gambling/regulation | R22 risk + GDF0 external stakes | legal/harm mechanisms external; Game-local stake coupling is representable |
| queueing/matching/rating | little explicit Game coverage | opponent/teammate availability and population composition can become a causal part of reachable play |
| security/cheating/exploit studies | GDF0 rules/authority gives encoding | exploit legitimacy, anti-cheat, verification and dispute adjudication are not deep |

Several external anchors directly demonstrate the residual rather than merely naming it:

- speedrunning research shows community-defined categories, disputed glitch/exploit admissibility, hardware requirements and record-verification practices can alter what counts as valid play without changing base executable code;
- theorycrafting can occur outside the executable yet reshape both play norms and developer design decisions;
- streaming/audience-participation systems can turn viewers into causally effective participants without giving them ordinary avatar control;
- experience-management systems explicitly observe/model players and modify a running game's dynamics;
- virtual-world research exposes operator/EULA/governance power outside ordinary in-world player roles;
- emergence research treats macro gameplay patterns as products of interacting mechanics rather than authored event lists.

These examples are not exceptions. They reveal missing organization types.

# 5. Structurally homeless reality classes

## H1 — Participation-role topology

Current documents use `player`, `participant`, `Subject`, `community`, `institution` and `Agent`, but do not deeply reconstruct the space of Game-relative roles.

Repeated roles include:

```text
player / competitor / teammate
spectator / audience
coach / advisor
referee / judge / verifier
GM / facilitator
moderator
experience director
operator / steward
creator / modder
broadcaster / commentator
research participant / worker / learner
synthetic player / synthetic facilitator / synthetic judge
```

The same entity can hold several roles, switch roles over time, or contribute through an aggregate collective.

The missing relation is not merely identity. It is:

```text
which role can observe / propose / act / evaluate / adjudicate /
modify rules / modify content / verify history / allocate participation /
at what scope, authority and time.
```

Status: **H + A; Game-owned candidate.**

## H2 — Mediation / adjudication / contestability

GDF0 deeply models current rule authority, but not the recurrent process by which ambiguous events/actions/rules are interpreted and contested.

Examples:

```text
referee ruling
TTRPG GM resolving open intent
speedrun glitch/exploit/category dispute
anti-cheat or tournament verification
natural-language action interpretation
moderation appeal
community rule vote
```

Important separations likely include:

```text
Rule != Interpretation != Ruling != Enforcement != Appeal
Proposal != Adjudication != Authority
Ambiguity != Randomness
Disagreement != RuleChange
```

Status: **H + A; strong Game-owned candidate.**

## H3 — Meta-game / paratext / cross-instance practice

Important Game behavior occurs outside the current GameInstance:

```text
theorycraft
wiki/guide knowledge
scouting
build/deck preparation
draft/ban phase
tournament bracket
speedrun category design
modding
community optimization norms
patch adaptation
```

R13/R15/R17/R19/R20/R28 contain pieces, but there is no deep account of when external practice becomes constitutive of later GameStructure or PlayerCausalAccess.

Status: **H/P; Game + Practice/Culture boundary.**

## H4 — Population ecology / matching / availability

For many online games, other participants are not merely subjects already present in a match. The **population itself** shapes whether a match exists and what forms of play are reachable.

Relevant variables include:

```text
population size/composition
time-zone and queue availability
rating distribution
role scarcity
party/network structure
migration/churn
smurf/bot prevalence
matchmaker policy
opponent/team diversity
```

A player can face a different effective Game despite identical local rules because population/matching changes the reachable opponent/team distribution.

Status: **H + A; Game/Social/Network boundary.**

## H5 — Game stewardship / adaptive experience management

R27 models a Subject changing from experience. This residual is the inverse loop:

```text
Game observes Player
→ constructs/updates Player model
→ selects a steering policy
→ changes challenge/content/rules/dynamics/presentation
→ observes resulting Player
```

This includes:

```text
AI Director
dynamic difficulty
personalized quest/content selection
multiplayer experience management
live event steering
adaptive tutorialization
runtime generative curation
```

It creates specific authority/fairness/legibility questions because the Game itself becomes an adaptive controller.

Status: **H + A; Game-owned, but may be a subtype of a larger mediation topology.**

## H6 — Endogenous dynamics / emergence / systemic regimes

R9 names simulation and the R29 World stack contains Dynamics/Emergent Structure, but the corpus lacks a dedicated model of:

```text
feedback loops
attractors / cycles / runaway processes
cascades
phase/regime changes
self-organization
macrostate formation
path dependence / hysteresis
systemic fragility / resilience
cross-scale causation views
```

These matter in strategy, economy, ecology, colony sims, physics sandboxes and multi-Agent worlds.

Status: **P/H, but general dynamics are primarily World-owned; Game owns player-facing systemic causality and design consumption.**

## H7 — Performance / spectatorship / observational participation

The corpus treats PlayerCausalAccess primarily around action/planning/interpretation/expression. It has not deeply separated:

```text
performer
viewer
judge
audience collective
broadcaster
commentator
```

nor studied when observation itself is the intended practice versus when audiences causally enter GameStructure.

Status: **H, strongly overlaps H1 rather than standing alone.**

## H8 — Productive play / property / labor / platform power

UGC and persistent worlds can turn players into creators, maintainers, traders, moderators and laborers under platform ownership.

R14/R15/R20/R28 make this representable, but do not deeply explain:

```text
platform ownership of generated value
creator compensation
moderation labor
algorithmic discovery/access
account/property dependence
operator exit/voice asymmetry
```

Status: **P/H; substantial Finance/Law/Social ownership, Game consumes local contracts.**

## H9 — Authoring-runtime boundary collapse

Production Agents are not automatically Game Agents. However, some systems intentionally make design itself part of runtime play:

```text
player changes rules/mechanics
AI generates mechanics during play
co-creative world building with persistent authority
player+Agent jointly author future possibility space
```

R20 handles authorship and generation, and R29 handles promotion authority, but not the full loop in which the GameForm is intentionally mutable through participation.

Status: **P/A; candidate subproblem of mediation/stewardship rather than an independent first route.**

## H10 — Epistemic inquiry as extended practice

R17 covers information and belief, R27 learning, R12 causal legibility. The missing depth is a practice in which players collectively build/test external models of the Game itself:

```text
hypothesis formation
experimentation
instrumentation/log analysis
reverse engineering
theorycraft
collective verification
model publication/adoption
```

Status: **P/H; strongly coupled to H3 rather than independent.**

# 6. Agent-era perturbation pass

Agent-era novelty does not come mainly from “more intelligent NPCs.” It changes the **role and adaptation topology** of Game systems.

## 6.1 Production Agent

```text
Game production/design assistance
!= runtime Game participation
```

Mixed-initiative generation, AI level design and mechanic generation expand production capability. This belongs primarily to Studio/production unless generated decisions are admitted into runtime Game authority.

## 6.2 Runtime system Agent

A runtime Agent can act as:

```text
semantic adjudicator
experience manager/director
moderator
matchmaker
rule/content curator
GM/facilitator
verifier
```

This is a stronger perturbation to H1/H2/H5 than to ordinary NPC theory.

## 6.3 World-subject Agent

Persistent NPC/agent identity, learning, relationships and culture are already substantially modeled by R10/R24-R28. New implementations do not themselves reopen foundations.

## 6.4 Synthetic player population

Agents can become:

```text
opponents
teammates
queue fillers
training partners
market actors
culture carriers
playtest populations
```

This can change H4 population ecology even when each individual Agent is representable through existing Subject/Action models.

## 6.5 Role fusion

One synthetic entity may simultaneously be:

```text
player + coach + referee + content generator + memory keeper
```

Entity identity therefore cannot stand in for role identity or authority.

This is a major reason H1/H2 deserve independent deep attention.

## 6.6 Semantic openness

Language-native action expands proposal space, but R29 already gives:

```text
Generation / natural-language proposal
→ candidate
→ authority/adjudication
→ admitted consequence
```

The unresolved issue is not a new semantic primitive. It is how adjudication remains stable, contestable, legible and scoped when action meaning cannot be enumerated ahead of time.

## 6.7 Adaptive-game closed loop

Inference makes H5 cheaper and more expressive:

```text
observe player → infer state/preferences/skill → alter game → observe response
```

The danger is not only prediction error. Hidden adaptation can change the player's effective rules/challenge/opponent distribution and create fairness, attribution and manipulation problems.

## 6.8 Inference economics

Latency, token/compute cost and model availability can become resources or operational constraints. F14/R23-style resource/time semantics can represent these. No new foundation coordinate is indicated.

# 7. Residual clustering — do not select by noun count

The ten homeless/partial classes are not ten independent foundations.

Counterfactual dependency groups them into four larger residual continents.

## Residual A — Participation / Mediation Ecology

Contains primarily:

```text
H1 participation roles
H2 adjudication/contestability
H5 adaptive stewardship
H7 spectatorship/performance
parts of H3 meta-practice
parts of H4 population roles
parts of H9 runtime co-authoring
```

Shared question:

> Who is causally participating in the Game, through which role, with what observation/action/evaluation/adjudication/change authority, and how can those roles transition or compose?

This question is absent as a deep Game-native object despite recurring across tabletop, sport, speedrun, esports, live service, streaming, UGC and Agent-native systems.

## Residual B — System Dynamics / Emergence

Contains H6 plus systemic parts of economy/strategy/culture/population.

Shared question:

> How do local transition relations compose into persistent macro-regimes that players can model and alter?

Large real gap, but much of the substrate belongs Ordivon World; Game's owner is the player-facing systemic causality contract.

## Residual C — Meta-Practice / Extended Game Apparatus

Contains H3/H10 plus hardware/platform/paratext/modding/verification.

Shared question:

> When do external knowledge, artifacts, communities and cross-instance practices become constitutive of effective play?

Important, but GDF0 PlayPractice/effective overlays and R28 Culture already give part of the owner. It may become a downstream branch of Residual A.

## Residual D — Population / Platform Political Economy

Contains H4/H8 and governance/market/labor/property issues.

Shared question:

> How do population supply, matching, platform authority and external value extraction alter reachable play?

Important, especially in online/live-service games, but ownership is split across Game, Network, Finance, Law/Institution and Social foundations.

# 8. Cheapest falsifier battery

A next branch must survive tests that distinguish a genuine missing deep responsibility from a renamed old topic.

## F-A1 — passive spectator

Two observers receive the same Game evidence. Neither has GameAction authority.
One is recognized as an official judge with scoring authority; the other is an ordinary spectator.

If current analysis treats them identically because both merely observe, it loses a real Game counterfactual.

Result:

```text
requires role + authority relation;
not reducible to Player action or observation alone.
```

## F-A2 — audience participation transition

A livestream viewer initially only watches. Later the same viewer's cheer/jeer input is aggregated into a parameter that changes an AI fighter's strength.

The entity is continuous; its Game-relative causal role changes.

Result:

```text
EntityIdentity != ParticipationRole.
Spectator != causal nonparticipant by identity.
Direct avatar control != necessary for Game participation.
```

## F-A3 — referee/adjudicator

Hold physical event history fixed; change only the authoritative ruling on whether the event satisfies a rule/category criterion.
The score/validity/history changes.

Result:

```text
GameAction semantics + Rule truth alone do not describe the mediation process;
Ruling authority is causally relevant.
F1-F9 can encode it, so no new semantic coordinate is required.
```

## F-A4 — TTRPG Game Master

A player proposes an open-ended action whose exact transition is not enumerated. The GM interprets intent, decides applicability, introduces world evidence and resolves consequence under a practice's authority.

Result:

```text
facilitator can participate without occupying ordinary player/opponent role;
world-generation + adjudication + rule interpretation can compose in one role.
```

## F-A5 — adaptive director

Hold current player action and visible local state fixed. Change the hidden experience-manager model/steering policy. The next encounter distribution changes.

Result:

```text
SubjectLearning != GameAdaptation.
OpponentAction != exhaustive model of runtime mediation.
```

## F-A6 — role-fused Agent

One Agent instance proposes player actions and also evaluates whether those actions are legal.
Compare against two separate Agents with independent authorities.

Result:

```text
SameEntity can host incompatible or separable roles;
role topology/authority must be explicit to reason about conflict of interest and provenance.
```

### Residual-A verdict

Survives all six tests as a coherent missing **deep responsibility family**.
It does not require a new F1-F9 primitive.
It is not a synonym for Game Feel, Time, Space or Strategy.

---

## F-B1 — macrostate without new primitive

A local resource-loop model produces stable, oscillatory and runaway regimes under different parameters/topologies.

Can F1-F5/F9 + history/topology represent the counterfactuals?

Yes.

The missing object is explanatory/systemic depth, not semantic encoding.

## F-B2 — ownership test

Remove Game/player semantics and ask whether the same attractor/cascade/resilience theory still applies to ecology, networks or physical systems.

Yes.

Result:

```text
general Dynamics/Emergence is substantially World-owned.
Game should later consume PlayableSystemDynamics rather than duplicate the full theory first.
```

### Residual-B verdict

Large residual, but lower immediate Game ownership than A.

---

## F-C1 — theorycraft outside executable

Hold executable fixed. Add a community model/wiki that changes accepted builds, guild recruitment thresholds and later developer balance changes.

Existing R17/R19/R28/GDF0 can encode many pieces, but no single deep cross-instance practice model exists.

## F-C2 — deletion test

If Participation/Role/Mediation is reconstructed first, can much of this case be represented as external participants/practices producing observations/evaluations/adjudications that feed later Game instances?

Substantially yes.

### Residual-C verdict

Important, but partly dependent on A. Do not select first.

---

## F-D1 — empty queue

Same local rules and player capability; one region/time has a healthy opponent population and another has no compatible players.
Reachable play differs before any match starts.

Population availability is causally real.

## F-D2 — ownership split

The same phenomenon requires queueing/network capacity, matching policy, social population, economic incentives and Game rules.

### Residual-D verdict

Real but cross-project. Preserve as a future cross-cutting branch; do not force all of it into Game now.

# 9. Foundation reopen audit

## R29 F1-F9

None of A-D requires a tenth semantic coordinate.

```text
Participation role
= Entity/Reference + Relation + State + Authority/Provenance
  + Observation + Evaluation + Action/Policy + Time.

Adjudication
= Representation/interpretation + Authority + Transition/Constraint + Provenance.

Adaptive director
= Observation + Representation + Evaluation + Policy/Action
  acting on Game State/Transition under scoped Authority.

Dynamics/emergence
= State + Relation + Transition + Time + History/topology views.

Population ecology
= Entities + Relations + State + Time + Policy/Transition.
```

Therefore all R29 FoundationReopenConditions remain **NOT TRIGGERED**.

## GDF0 Play/Game

No new target level beyond structure/enactment/behavior-experience/practice-category/external coupling is forced.
Participation/mediation cuts across those levels rather than replacing them.

