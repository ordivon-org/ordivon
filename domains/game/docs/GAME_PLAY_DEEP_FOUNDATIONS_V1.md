# Ordivon Game — Play / Game Deep Foundations v1

## 0. Status and scope

This document freezes the first deep foundation layer produced by GDF0-A→H.

It does **not** reopen or replace R1–R29 / F1–F9.

```text
R1–R29 / F1–F9
= semantic substrate

Play / Game Deep Foundations v1
= target separation + durable coupling/authority/evidence laws

Later GDF branches
= mechanistic depth for action, skill, challenge, feel, social play, etc.
```

The core conclusion is deliberately non-essentialist:

```text
No single rule, goal, motive, frame, learning mechanism,
agency metric or cultural label is accepted as the universal essence of Play or Game.
```

This is not a claim that Play/Game have no mechanisms. It is a claim about the evidence after cross-context, matched, historical/cultural and Agent-era falsification.

---

# 1. Two coupled targets, not one essence

## 1.1 Play-side targets

```text
PlayBehavior
= externally characterizable organization of behavior that may be identified
  without proving subjective experience.

PlayMode / PlayExperience
= participant-side mode/experience/valuation during an episode.

PlayFrame
= local interpretation/organization under which actions, roles or objects
  acquire play-relevant meanings/evaluations.

PlayPractice
= recurrent socially/materially/culturally organized form of play enactment.
```

These are related but non-identical.

```text
ObservedPlayBehavior != proven PlayExperience
```

## 1.2 Game-side targets

```text
GameStructure
= an effective, currently resolvable normative action/consequence structure
  supporting differentiated roles/actions/states/evaluations under some rule authority.

GameArtifact
= material/software/textual/social artifact that affords or carries parts
  of one or more GameStructures.

GameInstance
= one concrete enactment/history under an effective GameStructure.

Gameplay / Enactment
= participant execution/interaction through a GameStructure.

GameCategory
= historically transmitted/socially recognized practice/category identity
  whose recognition may feed back into later interpretation and enactment.
```

Strong law:

```text
Play != Game
```

There can be Play without a formal GameStructure and GameStructure/GameExecution without evidence of PlayExperience.

---

# 2. Final target map

The frozen target map is not a vertical stack.

```text
Artifact / Material Affordance
        ↕
Effective Rule Topology ↔ Practice / Community / Institution
        ↕                         ↕
GameStructure / Agency Scaffold ↔ Frame / Evaluation / External Coupling
        ↕                         ↕
Gameplay / Enactment ↔ Participant Mode / Experience
        ↕                         ↕
History / Practice / Category / Recognition
```

Play-side and Game-side variables can change one another over time.

Therefore:

```text
SameArtifact != SameEffectiveGameStructure
SameTaskStructure != SameParticipantExperience
MechanisticSimilarity != CulturalCategoryIdentity
```

---

# 3. Effective rules and authority

A Game's effective constraints need not live in one rulebook or executable.

```text
EffectiveRuleTopology may include:
formal/artifact rules
material constraints
participant commitments/self-imposed rules
community/social conventions
institutional/tournament regulation
```

Each rule/constraint can differ in:

```text
scope
authority
visibility
mutability
currentness
sanction/adjudication
activation conditions
```

Frozen laws:

```text
FormalRuleSet != EffectiveGameConstraints
GameArtifact != CompleteGameStructure
StableRuleContent != necessary for historical/practice continuity
RuleRepresentation != RuleAuthority
RuleProposal != RuleAuthority
RuleBelief != CurrentRuleTruth
```

Rule mutability is compatible with GameStructure when current rule semantics and change authority remain sufficiently resolvable for the relevant participants/system.

---

# 4. Constitutive overlays

A practice/community/institution overlay is structurally constitutive when changing it changes one or more of:

```text
admissible action
role or object meaning
goal/evaluation
timing/phase semantics
transition interpretation
valid evidence/history/verification
```

Therefore a speedrun category, self-imposed challenge, tournament ruleset or folk-game convention can become part of the effective GameStructure without being encoded in the base artifact.

But labels/skins that alter no relevant relation need not be constitutive.

---

# 5. Evaluation must remain layered

Freeze:

```text
GameGoal
!= ParticipationPurpose
!= Process/PlayerValue
!= ExternalStake
```

Examples:

```text
GameGoal:
  win / survive / build / solve / locally chosen project

ParticipationPurpose:
  leisure / work / training / career / social obligation / research

Process/PlayerValue:
  mastery / curiosity / expression / attachment / sociality / aesthetics / etc.

ExternalStake:
  money / reputation / bodily risk / legal/institutional consequence / status
```

No fixed global terminal goal is required for all Game forms.

```text
NoFixedGlobalGoal != NoEvaluation
```

Local evaluation may be dynamic, plural, participant-authored and non-scalar.

This fact is a general agency property, not a Game essence.

---

# 6. Structure, behavior, experience and category are separate evidence targets

Freeze the following evidence boundaries:

```text
GameExecution != PlayExperience
PerformanceEffect != MotivationEffect != ExperienceEffect != CategoryEffect
StructuralCompetence != evidence of subjective PlayExperience
GameCategory cue != GameStructure
```

A configuration/frame/category cue can change interpretation, motivation or behavior while mechanics remain mostly fixed.

A rule/practice overlay can change effective structure while the artifact remains fixed.

Neither direction licenses cross-target inference without evidence.

---

# 7. Frame authority and sociality

A PlayFrame need not be negotiated socially in the current episode.

Possible maintenance loci include:

```text
self
dyad/group
community
institution
artifact/system
hybrid
```

Therefore:

```text
ContemporaneousSocialNegotiation != necessary for PlayFrame
FrameOrigin != CurrentFrameMaintenanceLocus
```

Solitary play can use culturally acquired meanings while being maintained by one participant in the current episode.

---

# 8. Practice, lineage and category

Cultural/historical GameIdentity is not exact ruleset identity.

```text
Transmission != ExactReplication
SocialHistoricalGameIdentity != hash(ruleset)
```

Practice identity can persist through bounded change when relevant communities/institutions recognize lineage/continuity.

Conversely a small overlay can create a distinct recognized practice/category.

GameCategory is frozen as a separate target:

```text
GameCategory
= historically transmitted/socially recognized practice/category identity
```

with two laws:

```text
MechanisticSimilarity != CulturalCategoryIdentity
CulturalCategoryIdentity != MechanicalEquivalence
```

Category recognition is not merely passive: through expectations, norms and authority it can influence later enactment. This CategoryFeedback is retained as a derived social-historical model, not as the mechanical definition of Game.

---

# 9. External consequence coupling

Play/Game is not sealed from ordinary reality.

```text
PlayFrame != ConsequenceIsolation
```

External coupling may vary across channels:

```text
bodily
economic
social
reputational
identity
institutional/legal
knowledge/skill
```

Professional sport/esport, gambling and training show that high external stakes can coexist with recognizable GameStructure.

ExternalInstrumentality/ConsequenceCoupling remain derived coordinates, not category tests.

# 12. Agent-era anti-collapse contract

Agent systems do not currently require a new Play/Game primitive.

They strengthen the following separations:

```text
Synthetic competence != PlayExperience evidence
RuleProposal != RuleAuthority
RuleBelief != CurrentRuleTruth
NaturalLanguageIntent != AuthoritativeEffect
ModelFluency != Legitimacy
ProviderModelIdentity != AgentIdentity
ConventionEmergence != InstitutionalLegitimacy
Generation != Authorship != Adoption != CategoryLegitimacy
ProductionAgentNeed != RuntimeAgentNeed
```

Open natural-language action/goal spaces expand representation and policy surfaces; they do not grant unbounded effect authority.

Persistent Agent identity is governed by identity/history/recognition authority, not provider-model equality.

# 13. Owner boundaries

## Game owns

```text
effective rule/action/evaluation/consequence structure
player-facing causal access to that structure
gameplay/enactment semantics
constitutive overlays and current rule authority within a GamePractice
coupling between GameStructure and participant action/value surfaces
```

## Human owns lower mechanisms

```text
motivation / need satisfaction
affect/appraisal
motor learning
curiosity/developmental mechanisms
social motivation
subjective experience mechanisms
```

Game may study how its structures recruit these mechanisms but should not duplicate Human foundations.

## Media owns lower mechanisms

```text
signal
perception
attention
representation
multimodal presentation/feedback medium
```

Game owns what distinctions must be made legible for play, not the complete science of perception/representation.

## World / social-institutional owners

```text
cross-domain identity/reality linkage
institutional authority
cultural/historical processes
law/economy/material constraints where they extend beyond Game-local semantics
```

Game retains the GamePractice-specific consumption contract.

# 15. FoundationReopenConditions — Play/Game Deep Foundations v1

Reopen this GDF0 foundation only if one of the following occurs.

## PRC-1 Target collapse

Strong evidence shows two currently separated targets are necessarily identical across the relevant scope, e.g. PlayBehavior cannot in principle diverge from PlayExperience, or GameArtifact uniquely determines effective GameStructure.

## PRC-2 Missing target class

A materially important Play/Game phenomenon cannot be represented without adding a distinct target level beyond structure, enactment, behavior/experience, practice/category and external coupling.

## PRC-3 Rule/authority failure

A real GamePractice requires rule/currentness/authority semantics that cannot be represented through existing F1–F9 plus EffectiveRuleTopology/constitutive-overlay relations.

## PRC-4 Evaluation failure

A clear intentional Gameplay case cannot be modeled with any local/dynamic relevance/evaluation relation while still requiring policy selection semantics.

## PRC-5 Category/mechanism failure

Cross-cultural/historical evidence shows GameCategory is mechanically recoverable in a way that invalidates Category/Mechanism nonidentity, or conversely category/practice evidence is causally irrelevant in a way that invalidates the current coupling model.

## PRC-6 Agent-era primitive failure

A synthetic/Agent-era Game requires a new semantic primitive that cannot be represented using F1–F9 and the frozen target/authority distinctions—rather than merely a new representation, policy, identity or authority configuration.

## PRC-7 Downstream contradiction

Later GDF1+ mechanistic work produces a repeated, cross-GameForm contradiction with a frozen GDF0 law rather than a local derived-model failure.

Absent one of these conditions:

```text
Do not reopen GDF0 because a new genre, product, Agent architecture,
interface, mechanic or research vocabulary appears.
```

# 16. Freeze verdict

```text
Play and Game are frozen as separate but coupled research targets.

No one-sentence universal essence is frozen.

GameCategory remains part of the target map but not part of mechanical essence.

F1–F9 remain unchanged.

GDF0 is complete at v1.
```

This freeze claims research sufficiency for the **GDF0 boundary problem**, not exhaustive understanding of all Game phenomena.
