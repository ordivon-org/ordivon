# Ordivon Game Deep Foundations — GDF0-C

## 0. Question

GDF0-A separated the target objects. GDF0-B showed that many famous theories are not direct competitors because they explain different levels.

GDF0-C asks a harder question:

> What minimal mechanisms can actually generate important regions of Play/Game phenomena, what disappears under ablation, and which mechanisms belong to Game rather than Human/Media/World?

The goal is **not** another definition contest.

The goal is a generative/mechanistic decomposition.

Strong starting constraints:

```text
GameStructure != PlayMode
GameExecution != PlayExperience
Definition != Identification != Mechanism != Function != Value
GameGoal != ParticipationPurpose != PlayerValue != ExternalStake
GameCategory != structural similarity alone
```

R1–R29 / F1–F9 remain frozen unless a concrete R29 FoundationReopenCondition appears.

# 2. First major C result — there is no justified one-mechanism Play theory

The six priority mechanisms from B do not form six competing universal definitions.

They partition into different causal roles:

```text
Participant-side valuation:
P — Process / local activity valuation

Coupling / authority:
F — Frame + EvaluationLayering

Structural action substrate:
S — AgencyScaffold / EffectiveRuleTopology

Subset generative mechanisms:
E — Exploration / possibility sampling / learning progress
R — Perturbation / self-handicap / recovery

Game-specific design mechanism candidate:
A — AgencySculpting / PolicyDifferentiation
```

Immediate consequence:

```text
Play/Game phenomena are likely generated by mechanism composition,
not by one universal mechanism repeated at every level.
```

This is not yet a theorem about all Play. It is the best model after B's target alignment and C's ablation analysis.

Candidate:

```text
C7 MechanismFamilyView =
Play/Game explanations should specify which mechanism family
is responsible for which explanandum rather than force one essence.
```

Novelty status:

```text
N1 synthesis candidate
```

# 3. P-model — Process / Local Activity Valuation

## 3.1 Target

```text
PlayMode / continuation / participant-relative valuation
```

Not GameStructure.

## 3.2 Minimal variables

```text
LocalOutcomeValue
ProcessValue
ParticipationPurpose
ExternalStake
Perceived competence/autonomy/relatedness or other Human-level motives
Current affect/appraisal
```

GDF0-C deliberately does **not** claim one universal psychological utility function.

A minimal decision view is only:

```text
Continue / re-enter / attend / invest effort
can depend on value attached to the unfolding activity itself,
not only on terminal/external outcome.
```

This is consistent with intrinsic/process-valued play accounts and with Self-Determination Theory research on autonomy, competence and relatedness in human motivation. Video-game research using SDT reports associations between in-game autonomy/competence need satisfaction and enjoyment/preference, but this is Human motivational evidence, not a definition of Game.

## 3.3 Mechanism

The mechanism family is:

```text
Activity state / feedback / action possibilities
        ↓ participant appraisal / motive system
ProcessValue_t
        ↓
attention / continuation / effort / re-entry
```

## 3.4 Ablation

If:

```text
ProcessValue = 0
```

an episode may still continue because:

```text
ExternalStake
obligation
achievement value
social duty
training requirement
```

Therefore P is not necessary for GameExecution.

Conversely high process value can occur in:

```text
music
art
craft
science
conversation
exercise
```

without GameStructure.

Therefore P is not sufficient for Game.

## 3.5 Nearest non-game neighbor

```text
absorbing artistic/scientific/physical practice
```

## 3.6 Falsifier

A strong universal P-theory would fail if valued PlayMode systematically persists while all process-local valuation is genuinely absent and only external outcomes matter.

That claim is difficult to establish because human valuation is not directly observable. GDF0-C therefore treats P as a participant-side latent mechanism family, not an easily executable Game-owned variable.

## 3.7 Owner boundary

```text
Human owns:
  motivation / need satisfaction / affect / intrinsic-extrinsic regulation.

Game owns:
  the structures, feedback and action problems that couple to those motives.
```

## 3.8 Verdict

```text
P-model: RETAIN as participant-side mechanism family.
Game-specific discriminator: NO.
Universal Play essence: NO.
```

# 4. F-model — Frame + EvaluationLayering

## 4.1 Target

```text
PlayFrame
local meaning/evaluation authority
GameGoal vs ParticipationPurpose vs ExternalStake
```

## 4.2 Minimal variables

```text
FrameScope
LocalRole/Meaning mapping
LocalEvaluationAuthority
GameGoal / local criterion
ParticipationPurpose
PlayerValue
ExternalStake
ConsequenceCoupling
Entry / exit / frame-change semantics
```

## 4.3 Mechanism

The same physical action can receive different local status when the frame/evaluation authority changes.

```text
PhysicalAction
+ Frame / Rule authority
→ LocalActionMeaning
→ LocalEvaluation
→ participant policy / interpretation
```

Examples:

```text
contact → legal tackle / foul / assault
object movement → chess move / meaningless relocation
intentional loss → strategic sacrifice / sabotage / comic play
```

The frame need not isolate consequences from reality.

```text
PlayFrame != ConsequenceIsolation
```

## 4.4 Ablation

Remove the local frame/evaluation layer while holding physical transitions fixed:

```text
local roles / success / failure / move meaning disappear or change.
```

But the same mechanism exists in:

```text
ritual
law
professional procedure
scientific protocol
institution
```

so it cannot uniquely identify Game.

## 4.5 Nearest non-game neighbor

```text
ritual or institutional procedure with constitutive rules
```

## 4.6 Falsifier

Find a clear GameStructure where no scoped local rule/evaluation/meaning relation exists at any level and where all action meaning is exhausted by ordinary external semantics.

Open-ended sandboxes are the strongest pressure and are analyzed separately below.

## 4.7 Verdict

```text
F-model: RETAIN as coupling/authority substrate.
Game-specific discriminator: NO.
```

# 5. S-model — AgencyScaffold / EffectiveRuleTopology

## 5.1 Target

```text
GameStructure / NormativeActionProblem
```

## 5.2 Minimal variables

```text
State / situation
Participant roles
Observation / information
Action / capability set
Constraints / rule topology
Transition / resolution
Local evaluation/relevance
Feedback
Authority / rule-change semantics
```

Compact form:

```text
AgencyScaffold =
<State, Observation, Capability, Constraint,
 Transition, Evaluation, Feedback, Authority>
```

## 5.3 Mechanism

The scaffold defines a local action problem:

```text
Situation
→ observable distinctions
→ available/admissible actions
→ different consequences
→ feedback/evaluation
→ revised policy/model
```

## 5.4 Ablation

Remove different components:

```text
No differentiated action/capability
→ participant influence collapses.

No consequential transition differences
→ choice becomes causally decorative.

No observation/feedback
→ policy learning/modelability may collapse.

No evaluation/relevance relation
→ the model cannot order one intentional policy as more fitting than another,
  though physical actions can still occur.

No authority/currentness
→ mutable/social/generated rules can conflict without adjudication.
```

## 5.5 Nearest non-game neighbor

```text
exam
training drill
workflow
market procedure
ritual
```

All can instantiate an AgencyScaffold-like action problem.

## 5.6 Verdict

```text
S-model: RETAIN as structural substrate.
GameStructure may be one family of AgencyScaffolds.
Game-specific discriminator: NOT ESTABLISHED.
```

C6 remains N1 synthesis, not a metaphysical definition.



```text

```

```text
EnvironmentModelProgress
!=
ExecutionDiscrimination
```

This does **not** prove that a human still enjoys or replays the task.


is false in the toy model.

```text

```


# 8. A-model — AgencySculpting / PolicyDifferentiation

This is the strongest specifically Game-design-relevant candidate surviving B.

## 8.1 Problem

`constraints shape behavior` is trivial and applies to law, work and physics.

C therefore requires a more discriminating claim.

## 8.2 Minimal variables

For a context/situation `c` and action `a`:

```text
Q(c, a)
= local value / fit / consequence under the current scaffold.
```

A scaffold has stronger **PolicyDifferentiation** when relevant context changes which action/policy is locally preferable, legal, expressive or effective in a learnable way.

Two useful structural measures:

```text
UniqueOptimalActions
= number of distinct locally best actions across tested contexts.

AdaptivePolicyGain
= E_c[max_a Q(c,a)]
  - max_a E_c[Q(c,a)]
```

Interpretation:

```text
first term  = value available to a context-sensitive policy
second term = best context-blind fixed action
```

`AdaptivePolicyGain > 0` means using context to select action can matter under the chosen evaluation model.

This is **not** a Player Value score.

## 8.3 Executable paired probe

Hold fixed:

```text
4 contexts
4 actions
4 legal actions per context
same maximum payoff scale
```

### Flat-dominance condition

```text
unique optimal actions = 1
best contextual value  = 5.0
best context-blind      = 5.0
AdaptivePolicyGain      = 0.0
```

### Context-sculpted condition

```text
unique optimal actions = 4
best contextual value  = 5.0
best context-blind      = 2.25
AdaptivePolicyGain      = 2.75
```

Strong structural result:

```text
ActionCount / ConstraintQuantity
!=
PolicyDifferentiation
```

The same amount of nominal choice can encode radically different context-sensitive agency structure.

## 8.4 Why this is stronger than C2 ConstraintTransformation

C2 said:

```text
constraints transform possibility.
```

That is too general.

A says:

```text
specific interactions among
context × information × capability × constraint × evaluation × feedback
can create or destroy meaningful policy differentiation.
```

This yields a measurable counterfactual.

## 8.5 Nearest non-game neighbor

```text
adaptive work procedure
medical decision protocol
training scenario
engineering control task
```

These can also have high AdaptivePolicyGain.

Therefore:

```text
PolicyDifferentiation is not Game identity.
```

Its importance is as a **design mechanism** that can turn otherwise decorative or dominated choices into learnable action distinctions.

## 8.6 Falsifier

For a claimed AgencySculpting mechanic:

```text
if replacing the supposedly important context/constraint/information distinction
leaves policy ordering, reachable consequences, learning and expression unchanged,
then the mechanic is not sculpting agency at that level.
```

This is directly compatible with earlier Ordivon deletion/control audits.

## 8.7 Verdict

```text
C5 AgencySculpting: RETAIN.
PolicyDifferentiation / AdaptivePolicyGain: new operationalization.
Game essence: NO.
Player value: UNPROVEN without human evidence.
```

Novelty status:

```text
C8 PolicyDifferentiationOperationalization = N1/N2 candidate.
```

The mathematical ingredients are ordinary decision theory; novelty, if any, would lie in the Game-science synthesis and use as a falsifier. No scientific novelty claim is made.

# 9. Open-ended Game pressure — fixed goal is not required for local evaluation

B left unresolved whether sandbox/open-ended Gameplay can exist with no evaluation/commitment structure at any scale.

C separates:

```text
FixedGlobalTerminalGoal
from
Local / Dynamic Evaluation
```

Canonical probe:

```text
fixed global terminal goal = false
```

but a player-selected project can temporarily value actions differently:

```text
symmetry project → left/right placement preferred
height project   → stacking preferred
color project    → painting preferred
```

Ablate all evaluation/relevance relations:

```text
physical action remains possible
but intentional policy ordering disappears from the model.
```

Strong law:

```text
NoFixedGlobalGoal != NoEvaluation
```

More precisely:

```text
intentional choice requires some participant-relative relevance/evaluation relation,
but that relation need not be authored, fixed, terminal, scalar or global.
```

This is already compatible with R18/F8 and does not add a new semantic primitive.

Important boundary:

GDF0-C has **not** proved:

```text
Every culturally recognized game must contain an explicit evaluation system.
```

The current claim is mechanistic/semantic:

```text
if we want to explain intentional policy rather than mere physical action,
some relevance/evaluation relation must exist somewhere in the participant coupling.
```

Candidate:


# 10. P/F/S/E/R/A are compositional, not mutually exclusive

A single Game/Play episode may instantiate several mechanisms simultaneously.

Example — unfamiliar action roguelike:

```text
S AgencyScaffold
+ A AgencySculpting
+ E exploration / model acquisition
+ R perturbation / recovery
+ P process valuation
+ F local evaluation/frame
```

After hundreds of hours:

```text
E may decline strongly
while
A / R / execution mastery / P
remain important.
```

Example — free pretend play:

```text
P process valuation
+ F frame/local meaning
+ dynamic local S scaffold
+ E possibility exploration
```

but little stable authored GameArtifact.

Example — professional chess:

```text
S + A + F
with strong ExternalStake
and variable P
```

Example — animal rough play:

```text
PlayBehavior
+ likely P-like endogenous valuation (inferred, not directly observed)
+ F-like play signaling/frame
+ R perturbation/recovery
```

without human cultural GameCategory.

Thus mechanism composition explains more than forcing one universal definition.

# 16. External theory pressure added in C

## 16.1 Self-Determination Theory / game motivation

Ryan & Deci distinguish intrinsic and extrinsic motivation while emphasizing autonomy, competence and relatedness in self-determined functioning. Game-specific SDT work by Ryan, Rigby, Przybylski and later Przybylski/Rigby/Ryan connects perceived in-game need satisfaction with enjoyment/engagement.

GDF0-C lesson:

```text
participant motivation has real structure,
but Game should not convert Human motivational theory into Game ontology.
```

P-model remains a cross-owner coupling target.

## 16.2 Computational intrinsic motivation

Oudeyer & Kaplan show that `intrinsic motivation` in computational models can mean materially different mechanisms: novelty, prediction error, learning progress and competence-related signals among others.

GDF0-C lesson:

```text
Curiosity / intrinsic signal != one scalar primitive.
Exploration mechanisms must name their exact update/reward rule.
```

This supports E-model decomposition.

## 16.3 Nguyen agency pressure

Nguyen's `Games: Agency as Art` argues that games specify abilities and goals and thereby forms of agency; striving play further separates temporary local ends from higher-order participation purpose.

GDF0-C lesson:

```text
A/S/F mechanism family has strong external conceptual support,
but AgencyScaffold/Sculpting must remain narrower than a universal Game essence.
```
