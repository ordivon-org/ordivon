# Ordivon Game Core Research Reset

## Decision

The prior post-dogfood round made one useful correction and then overreached.

Useful correction:

```text
Station Zero
= strong executable reference experiment
!= universal Ordivon Game form
```

Overreach:

```text
small direction search
→ prototype comparison
→ Casefile selected
→ invented G6 candidate
```

That progression is withdrawn.

At that historical reset point, `DEVELOPMENT_MODEL.md` was treated as the only authority for G0–G8 semantics. This statement is retained as provenance only and is superseded by the creative-open current frontier:

```text
G0 Define
G1 Preproduction / core design
G2 Kernel / graybox prototype
G3 Playable prototype
G4 Vertical Slice
G5 Production / content expansion
G6 Alpha / content-complete validation
G7 Beta / polish / release candidate
G8 Release / operate / learn
```

Research rounds are search methods in the historical programme, not product stages or creative admission law. Today G0–G8 itself is an optional Skill vocabulary, so research or product work need not map to it at all.

## Current product truth

No new Ordivon Game product has been selected by the recent concept experiments.

- Station Zero remains the registered executable and the strongest delegation/tactical reference world.
- Station Zero v3 remains an executable reference experiment with valuable historical machine/runtime/production evidence.
- Casefile is an executable **epistemic/social-deduction treatment**.
- Last Light is a lightweight **relationship/dependence treatment**.
- Echo Hunt is a lightweight **adversarial-adaptation treatment**.
- Living Outpost and Creative Social World remain unbuilt direction hypotheses.

None of these statements assigns a new product to G0–G8.

## What the research is actually trying to learn

The Station Zero-era compression:

```text
Ordivon Game
= authoritative World
+ meaningful agency
+ player experience
+ persistent consequence
```

remains useful as a **historical pressure lens**, but current GDF0–GDF3 research does not justify treating it as a universal Game ontology. In particular, `persistent consequence` is conditional on the relevant evaluation/history horizon, `player experience` is an evidence target rather than Game-owned phenomenological truth, and some valid GameForms require neither a rich World nor cross-session persistence.

The historical programme separated these three representations:

```text
Game semantic foundations             → GDF0–GDF3
Development-use Game lenses           → GAME_DEVELOPMENT_CORE.md
Optional stage vocabulary             → DEVELOPMENT_MODEL.md G0–G8
```

Current creative work may use, mix, replace or ignore these representations.

The research question is now broader than “which Core mapping wins?” It is:

> Which stable responsibilities, causal bridges and evidence loops let Ordivon discover, validate, produce and evolve materially different games without prototype momentum, Agent affinity, measurability bias or stage labels choosing the product?

The cross-paradigm evidence is retained in `GAME_DEVELOPMENT_PARADIGM_RESEARCH.md`; `GAME_DEVELOPMENT_CORE.md` is historical/source material for the optional D1–D8 Skill, not the current mandatory responsibility model.

Examples of candidate laws to attack rather than assume:

- autonomy creates value when the player cannot or should not directly control the autonomous subject;
- partial information creates value when players can infer from evidence and act on uncertainty;
- persistence creates value only when history changes later possibilities, identity, relationships, or interpretation;
- model cognition earns cost only when a cheaper policy loses material experience value;
- Agent consequence matters when it changes authoritative state, not merely dialogue;
- player-facing presentation should expose game meaning, not internal evidence machinery.

These remain hypotheses until they survive materially different worlds.

## Treatment interpretation

### Station Zero — delegation / tactical consequence

Tests whether responsibility for capable autonomous subordinates, bounded knowledge, simultaneous consequence and feedback produce valuable delegated play.

Strong evidence:

- cognition can be separated from legal World authority;
- autonomous action can materially change trajectories;
- bounded information and owned feedback matter;
- cheaper policies and live cognition can be compared exactly;
- recovery/replay can preserve causal evidence.

Important pressure:

- delegation can become configuration/review work;
- research/evidence surfaces can crowd out player experience;
- technical Agent sophistication does not establish fun.

### Casefile — knowledge / testimony / inference

Tests whether authoritative hidden truth separated from observation, belief, statement and player inference creates useful social/deduction play.

The executable treatment is retained because it provides a materially different World pressure from Station Zero. It is not a selected product.

### Last Light — relationship / dependence

Tests whether a competent subject the player needs but cannot fully control can generate trust, frustration, sacrifice and attachment.

Current treatment is inconclusive because resource economy dominates the intended relationship signal. The direction remains open.

### Echo Hunt — adversarial adaptation

Tests whether an opponent that adapts to player behavior creates additional suspense, inference and mastery.

Current evidence says the tested richer-autonomy treatment did not materially outperform a cheap adaptive policy. This rejects **unearned cognition cost**, not the adversarial-adaptation direction itself.

## Search-space warning

The first concept wave sampled only a small part of the reachable space. Important unsampled or weakly sampled axes include:

- creation / co-creation;
- economy / exchange / ownership;
- institutions and organization;
- reputation and culture;
- long-horizon world transformation;
- exploration of places shaped by independent inhabitants;
- cooperation among peers rather than commander/subordinate topology;
- competition among persistent actors;
- many-Agent emergence with mixed cognition tiers;
- authored narrative interacting with autonomous history;
- social rituals and norms;
- construction, ecology and resource transformation.

Therefore no “winner” claim is currently admissible.

## Research discipline

For each Core hypothesis:

```text
Core mechanism
→ materially different game-form pressure
→ cheapest treatment
→ cheap/control baseline
→ real trajectory / play
→ observe consequence
→ retain, narrow, or reject the hypothesis
```

A treatment may be disposable. A negative result can reject only the mechanism/treatment claim actually tested; it must not silently eliminate an entire game direction.

## Stop rules

Do not currently:

- promote Casefile into a product roadmap;
- continue Station Zero content production because its infrastructure is mature;
- select a first commercial/release game from the current four treatments;
- open product G4/G5/G6 work based on research-stage terminology;
- build a universal Game engine from Station Zero + Casefile;
- introduce live model cognition where a cheaper policy remains experientially equivalent;
- scale Studio production before a real product form is intentionally selected.

## Current frontier

Current Game direction is **creative-open** rather than stage- or ontology-gated.

1. any game type, mechanic, rule, representation, control scheme, content structure or interaction may be combined experimentally; unknown combinations are exploration targets, not invalid states;
2. retain Station Zero, Casefile, Concept Lab, PC01-PC03, E01-E03 and other playables as reusable experience/evidence apparatus, not as privileged product ancestors or mandatory templates;
3. use the twelve-game teardown and future top-project teardowns as a mechanism-combination experience library with hypotheses, confounds and falsifiers; similarity suggests experiments but never authorizes or rejects a design;
4. treat D1-D8, G0-G8 and the World/Observation/Action/Transition model as optional repository-local Skills that may be applied, replaced or deleted when useful;
5. keep R1-R29 and later foundation work as research knowledge rather than creative admission law; a future game may contradict or replace those abstractions without first satisfying a framework reopen gate;
6. prefer fast reversible prototypes, direct play, paper/formal analysis, simulation, engine experiments or production slices according to the actual question; no prototype medium or process model is universally required; for production tooling, consume → adapt → fork → own only as actual pressure justifies;
7. preserve the epistemic boundary that EvidenceSubject, Method, Measure and Claim remain distinct; component evidence does not automatically become composition evidence, and machine/synthetic evidence does not automatically become Human evidence;
8. preserve owner/currentness/effect boundaries: credentials are not authority, historical state is not current state, and external effects require explicit authority;
9. measure progress by useful possibilities discovered, assumptions falsified, experience learned and decision-relevant uncertainty reduced—not compliance with a development framework;
10. when a framework or Skill stops increasing insight, remove it rather than fitting the game to it.
