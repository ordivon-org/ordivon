# Game LEGO authority

First-party Game products and playable research apparatus: RETIRED.
Current reusable knowledge responsibilities: planning/lego-plan-r1.json,
external sources, mechanism experience, relationships and counterexamples.

Game does not own a generic engine, Mod-loader, workflow service, runtime,
AI model, state store, or enjoyment authority. A new actual game owns its
own state/rules and player modification boundary. Mature engine and
mathematical providers own their internal implementations.

Unknown creative compositions are open. Claims about a resulting game
require evidence specific to that game. Player-authored rules may replace
the original game rather than imitate historical Game rules.

Old code remains in source Git history, not hidden active infrastructure.
Other domains' historical proof records remain their own responsibility.
