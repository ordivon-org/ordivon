# Game Factory — actual consumer authority

For tasks use [the production line](factory-pipeline.md) and ../AGENTS.md. Real game behavior belongs to the chosen native Godot/Bevy process, source provenance to Git and locked dependencies, platform binary build to its native exporter, and repository publication to GitHub required checks.

The existing planning/lego-plan-r1.json records available G01–G11 responsibilities and actual consumer witnesses, not an obligation to refine every LEGO. Existing Game knowledge JSON and TypeScript read-only CLIs are advisory input only. The old product-selection/profile documents and unconsumed prototype-composition query are retired.

| Consumer | Native Human route | Actual Agent/CI evidence scope |
| --- | --- | --- |
| Godot scene | game GUI and visible controls | factory:validate:godot (bounded native game and alternate component tests) |
| Godot export | Linux/Windows desktop native binary | factory:package:room (native Linux smoke and both archives) |
| Bevy app | native graphical build | factory:validate:bevy and factory:build:bevy (locked Cargo and source/ECS tests) |
| Existing source knowledge | inspect cited references | pnpm knowledge queries (retrieval only) |
| Isolated R7 research | separate frozen-study process only | test:autonomous-study, no candidate generation before independent protocol gates |

Agent mechanical completion is not player enjoyment or physical Windows acceptance. Do not turn the separate R7 research artifact into a factory approval requirement.
