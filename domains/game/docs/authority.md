# Game Content Authority

## Context

Game simultaneously contains one registered executable, one broader product vision, and an implemented but unregistered v3 replacement path. Treating the newest phase file as the whole product would confuse deployed behavior, target design, and future possibility.

## Decision

Historical P3 research also proved a stronger `Subject × Cognition × Actor × Intent` binding without importing Harness/World-private schemas; GC1 removed that dormant optional mechanism after confirming that no production caller enabled it and current product/recovery behavior was unchanged. The law remains; the unused binding machinery does not. Game still acquires no global Embodiment, Presence, Subject, or Cognition registry.

## Consequences

The registered Station Zero executable, v3 reference experiment, Concept Lab, Casefile and Pre-G0 playables are deliberately separate. Existing experiments are retained apparatus/reference evidence and receive no new product momentum from the current Game Development Core programme. No recent treatment is a selected product winner. The R1–R29 foundations corpus is durable repository state rather than conversation-only context. R29 synthesizes R1–R28 into provisional Game Foundations v1: Entity/Reference, State, Relation, Transition/Constraint, Time, Authority/Provenance, Observation/Representation, Evaluation/Motivation and Action/Capability/Policy/Control are the smallest currently justified semantic coordinate families; World, Subject, Resource/Economy, Risk, Strategy, Creation/Narrative, Identity/Self-model, Relationship, Institution/SocialNorm, Emotion, Learning and Culture are typed derived views/compositions where useful; PlayerValue/Playable-X are design/meta criteria; implementation mechanisms remain separate. R29 also narrows R15 generic Norm to SocialNorm, compresses typed Topology/Causality/Authority/Contract/Playable families and finds no forced independent foundation in the tested morality/language/politics/law/religion/education/technology/ideology falsifiers. The foundation-expansion programme is provisionally frozen. The exact next frontier is Pre-G0 Game Direction Search; Foundations reopen only under the R29 FoundationReopenCondition. DEVELOPMENT_MODEL.md remains sole authority for G0–G8 semantics, and no product has yet been selected. `STATION_ZERO_V3_PRODUCT.md` preserves v3 reference identity and historical programme evidence; P0/P1/P2/P3 remain canonical for their exact owner-local contracts.

## Status

Accepted and active. Reopen when v3 is registered, the current executable is removed, a second world is admitted, or stable human-oriented specifications replace the phase-coded target set.
