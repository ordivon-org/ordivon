# Ordivon Game — C9 Outside-Vocabulary Unknown-Continent Scan & Stopping Decision

## 0. Why C9 exists

C1-C8 deliberately attacked named candidates.
That creates a residual risk:

```text
selection bias:
we may only have proven that our inherited vocabulary is exhausted,
not that the whole Game referent has no other structurally important continent.
```

C9 therefore **does not select another residual noun**.

Instead it samples unusual regimes and asks:

```text
Does this case require a target class,
authority relation,
continuity relation,
or constitutive responsibility
that cannot be represented by:

F1-F9
GDF0 Play/Game
GDF1 Action/Control/Skill
GDF2 Challenge/Failure/Mastery
GDF3 Authoritative Case Determination
GPR1-GPR7 practical reconstructions
C1 GameInstance Constitution / Continuity
owner-external World/Human/Media/Runtime/Network/Social/Institutional/Law/Security foundations?
```

Only such a case counts as a genuinely new continent.



No spatial-boundary target is missing.

# 4. Probe C9-F3 — socially expanded games with unwitting nonplayers

Pervasive-game research explicitly studies games that blur social boundaries and involve nonplayers/bystanders.

The key distinction is:

```text
causally affects Game
!= participant by identity.
```

GPR6 already freezes:

```text

CausalComponent != ParticipantByIdentity.
```

C1 already distinguishes admitted membership from outsider status.

Therefore:

```text
UnwittingCausalActor
!= missing participant target.
```

This is a strong outside-vocabulary confirmation of GPR6+C1.

# 5. Probe C9-F4 — participant does not need full awareness of GameStructure

Formal work on games with awareness shows players may be unaware of available moves or of other parts of game structure.

Therefore:

```text
ParticipantBeliefAboutGame
!= CurrentGameStructureByIdentity
```

and:

```text
CommonKnowledgeOfStructure
!= necessary condition for participation.
```

R17/F7 already separates information/belief/model from World/Game truth.
GDF0 already separates RuleBelief from CurrentRuleTruth.

No awareness primitive.

# 6. Probe C9-F5 — Nomic: changing rules is itself a move

Peter Suber's Nomic makes rule change part of ordinary play.

Therefore:

```text
GameAction
can target EffectiveRuleTopology itself.
```

This is an extreme case, but GDF0 already states that rule mutability is compatible with GameStructure under resolvable change authority/currentness.
GPR1 already includes change-rule/policy operations.

No new meta-rule ontology is required.

---

# 7. Probe C9-F6 — Nomic: rules governing rule change can change themselves

Nomic explicitly permits self-application: rules governing amendment may themselves be amended/repealed under the current rule system.

Therefore:

```text
RuleChangeAuthority
need not live in an absolutely immutable meta-layer.
```

This is important because a naive ontology might require:

```text
immutable meta-rules above mutable rules above gameplay.
```

C9 rejects that stack.

Existing F1-F9 relation/policy/authority semantics can represent self-referential change without adding a semantic tier.

# 8. Probe C9-F7 — Nomic can change so much that players dispute whether it is still the same game

Suber explicitly notes that after many amendments players may feel they are playing a different game.

Therefore:

```text
RuleChangeMagnitude

```

This was already C7/GDF0 territory:

```text
semantic delta magnitude != identity split threshold
```

No new self-amendment continuity primitive.

# 9. Probe C9-F8 — zero-player / autonomous unfolding

Conway's Game of Life is widely described as a zero-player game: after an initial state, rules deterministically evolve the system without further player input.

Pressure:

```text
continuous participant action
!= necessary for a socially recognized thing to be called a game.
```

But C9 does **not** infer that every cellular automaton satisfies Ordivon's `GameStructure` essence merely because its name contains `Game`.

The frozen distinction is sufficient:

```text
GameCategory/linguistic-social recognition
!= GameStructure by identity.
```

And an autonomous system trajectory can be represented through World/F2-F4 whether or not it qualifies as a GameStructure.

No missing zero-player primitive.
