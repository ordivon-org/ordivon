# Ordivon Game Core Direction Space

## Search question

What kinds of game form transform Ordivon's durable Core into player value?

```text
authoritative World
+ meaningful agency
+ player experience
+ persistent consequence
```

The purpose is to discover stable mappings and failure regions. Existing code, installed tools and current model providers do not get votes on product form.

## Structural lessons already useful

Mature games provide pressure examples rather than templates to copy:

- **Duskers:** uncertainty can itself become an interface when evidence supports inference and action.
- **RimWorld:** autonomous actors become memorable when persistent state turns events into recognizable character history.
- **Wildermyth:** history has experiential value when the past becomes identity rather than merely retained data.
- **The Alters:** autonomy becomes socially meaningful when the player needs another subject's competence but cannot reduce that subject to a tool.
- **Shadows of Doubt:** authoritative world truth separated from inhabitants' knowledge can make the world itself a reasoning object.
- **Return of the Obra Dinn / Pentiment:** deduction becomes play when the player must commit a model instead of passively revealing exposition.
- **Rain World / Alien: Isolation:** adaptive/individualistic opposition can create value without dialogue or LLM cognition.

## First experimental lenses

These are not candidates competing for product selection. They isolate different mappings from Core to Experience.

| Treatment / hypothesis | Core pressure | Desired experience | Current evidence role |
| --- | --- | --- | --- |
| Station Zero / delegated crisis command | autonomy + bounded information + delegated consequence | responsibility, anticipation, strategic interpretation | strong executable reference; administration risk |
| Casefile / social deduction | hidden truth + asymmetric knowledge + testimony + commitment | curiosity, suspicion, deduction | executable epistemic treatment |
| Last Light / dependent companion | autonomy + memory + relationship consequence | trust, care, frustration, sacrifice | lightweight inconclusive treatment |
| Echo Hunt / adaptive predator | adversarial adaptation + partial sensory information | dread, inference, mastery | cheap-policy control shows cognition-cost caution |
| Living Outpost | many persistent inhabitants + resources + social/economic history | stewardship, emergent story | direction hypothesis; not yet a cheap valid treatment |
| Creative Social World | autonomous co-creation + artifacts + shared history | expression, surprise, collaboration | direction hypothesis; very broad |

## Missing dimensions

The current matrix is far from exhaustive. Important directions still need decomposition before implementation:

### Agency topology

- direct-avatar action with one autonomous counterpart;
- peer cooperation;
- party/companion autonomy;
- hierarchy/delegation;
- population/institution autonomy;
- world editing / indirect ecological agency;
- creator/co-creator relationships.

### Consequence type

- spatial/physical;
- survival/resource;
- social/relationship;
- economic/ownership;
- institutional/legal;
- epistemic/information;
- creative/artifact;
- ecological/world transformation;
- narrative/identity.

### Persistence horizon

- one decision;
- one encounter;
- one run;
- campaign;
- cross-session character;
- persistent society/world.

### Player-value mode

- mastery;
- suspense;
- curiosity;
- attachment;
- expression;
- exploration;
- stewardship;
- competition;
- cooperation;
- surprise;
- beauty/aesthetic experience;
- social interpretation.

### Agent participation mode

- policy-only;
- bounded model cognition;
- mixed hierarchy;
- persistent character memory;
- organization/institution;
- adversary;
- companion;
- subordinate;
- inhabitant;
- economic actor;
- co-creator.

The research problem is combinatorial. We should not instantiate every combination. We need experiments that maximize discrimination among Core hypotheses.

## Existing treatment foundations

### Station Zero

```text
Fantasy: responsible commander
Control: delegated organization
Core loop: observe → intent → delegated execution → consequence → interpret
Agent value question: does local autonomy make responsibility/delegation materially different from direct tactical control?
```

### Casefile

```text
Fantasy: investigator inside a living incident
Control: information acquisition + commitment
Core loop: inspect/question → compare evidence/testimony → confront → accuse
Core question: does World truth ≠ observation ≠ belief ≠ statement create satisfying inference?
```

### Last Light

```text
Fantasy: survive with someone needed but not controlled
Control: request/negotiate/share risk
Core loop: situation → request → acceptance/modification/refusal → shared consequence → relationship update
Core question: when does autonomy create relationship rather than friction?
```

### Echo Hunt

```text
Fantasy: survive a threat that learns patterns
Control: direct navigation / information / bait
Core loop: act → sense → infer opponent → adapt
Core question: how much adversarial cognition is experientially distinguishable from policy?
```

## Experimental contract

A future treatment should identify:

1. exact Core hypothesis under pressure;
2. conventional game form used as pressure, not presumed product;
3. expected player-value mechanism;
4. cheapest executable or non-executable falsifier;
5. cheaper cognition/control baseline where relevant;
6. what observation would narrow or reject the hypothesis;
7. what the treatment cannot establish.

Do not require every hypothesis to become a browser game. Paper rules, deterministic simulation, agent-vs-policy runs, interactive mockups, borrowed mature engines, or tiny grayboxes may be better experiments.

## Current boundary

The direction space is intentionally open. No treatment is the selected first Ordivon Game product, and no current experiment owns a G0–G8 stage.
