```text

```

# 4. Solitary / self-authored attack

A possible hidden assumption was:

```text

```

F falsifies that assumption.

Solitary player:

```text

"I think that move broke my rule"
→ nonbinding classification
```

The same player can maintain a self-authored challenge where a declared check is treated as current binding certification:

```text

```

inside that PlayPractice.

No other person, tournament or organization is required.

Thus:

```text
ExternalInstitution != necessary condition for binding PlayPractice authority.
```

Authority can be:

```text

role-fused
temporary
withdrawable
scope-bound
```

and remains ordinary F5/F6 semantics.

This closes a major hidden institutional-assumption risk.

# 5. Attack O3 — TypedDeterminationBasisWhenMaterial

Try merging every basis link into one untyped collection.

Two paired counterfactuals defeat this.

## Same evidence, different norm

```text
Evidence E
Norm N1 → VALID
Norm N2 → INVALID
```

## Same norm, different evidence

```text
Norm N
Evidence E1 → VALID
Evidence E2 → INVALID
```

The two changes mean different things for:

```text
review
currentness
provenance
future cases
rule evolution
record explanation
```

Therefore:

```text
case/evidence/canonical-state basis
!=
norm/evaluation/application basis
```

must remain distinguishable **when the distinction is materially counterfactual**.

Result:

```text
O3 SURVIVES conditionally.
```

No universal EvidenceSet or NormApplication object is required.
