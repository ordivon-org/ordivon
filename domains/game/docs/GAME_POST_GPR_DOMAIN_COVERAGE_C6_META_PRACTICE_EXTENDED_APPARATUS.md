# Ordivon Game — Fresh Coverage C6: Meta-practice / Extended Apparatus / Cross-instance Practice Falsification

## 0. Boundary

This is not GDF4 and not GPR8.

C6 attacks the historical residual around:

```text
meta-game
cross-instance practice
campaign
tournament / bracket
season
speedrun category
paratext / guides / wikis
hardware / apparatus
modding / UGC ecosystem
platform mediation
organized play
pervasive/location-based play
persistent worlds
synthetic-only practice
collective theorycraft
```

The old question was:

> When do external knowledge, artifacts, communities and cross-instance practices become constitutive of effective play?

The null model is unusually strong because GDF0 already freezes:

```text
GameStructure
GameArtifact
GameInstance
Gameplay/Enactment
PlayBehavior/Experience
PlayPractice
GameCategory
ExternalConsequenceCoupling
EffectiveRuleTopology
ConstitutiveOverlay
```

and explicitly permits practice/community/institution overlays to become structurally constitutive when they change action, role/object meaning, goal/evaluation, timing/phase, transition interpretation, evidence/history or verification.

C6 must therefore find a target level beyond those frozen distinctions, not merely show that games have communities, tournaments, mods, wikis or physical equipment.

---

# 1. First correction — Game reality really can extend beyond one executable or one instance

This is not disputed.

Current and historical GameForms can depend on:

```text
community-defined categories
organized-play campaign rules
tournament brackets
external timing/video evidence
physical spaces/equipment
land-owner permission
published cache/listing state
persistent characters
mods / UGC
wikis / theorycraft
platform moderation/discovery
cross-instance standings/history
```

So:

```text
Game != executable bytes
Game != one process/session
Game != one GameInstance only
```

But GDF0 already froze that broader ontology.

The C6 question is whether an **additional** `MetaPractice` or `ExtendedApparatus` target is necessary.

# 2. Candidate deletion pass

## MetaGame primitive

`Metagame` is polysemous:

```text
population strategy distribution
out-of-match planning
community norms
counter-picking
between-session progression
tournament strategy
knowledge about other players/builds
```

Delete as universal ontology.

## Campaign primitive

A campaign can mean:

```text
one long enactment spanning sessions
an organized-play rules domain
several linked adventures/instances
marketing/content release grouping
persistent character/history context
```

Delete as universal target.

## Tournament primitive

Tournament is an institutional/practice organization over games, participants, standings and pairing rules.
Delete as Game primitive; retain as owner-local PlayPractice form.

## Season primitive

Season can denote a rules/version interval, competition interval, content cycle or progression-reset period.
Delete as universal ontology.

## Paratext primitive

Guide/wiki/video/forum knowledge can affect behavior without changing GameStructure; if formally adopted as rule/interpretation it enters existing GDF0 authority/currentness.
Delete.

## ExtendedApparatus primitive

Physical equipment, platform services, timers, websites, GPS, score sheets and broadcast systems have heterogeneous causal roles.
Their mere presence does not define one common Game substance.
Delete.

## Community primitive

Community is a Social/Cultural collection/network, not a Game primitive.
Game consumes community norms/recognition/authority when constitutive.

## Platform primitive

Platform can be transport/runtime, marketplace, moderation institution, discovery system or artifact host.
Delete as Game ontology.

## ModEcosystem primitive

Mods are R20 artifacts/content/rule representations; ecosystem adoption/recognition is practice/culture/platform structure.
Delete as a separate Game foundation kind.

## ExternalKnowledge primitive

External theorycraft/guide knowledge is F7/R17 representation/belief evidence unless adopted as constitutive norm/rule.
Delete.

# 3. Falsifier A — speedrun category changes valid play without executable change

## C6-F1 — category overlay

Speedrun.com moderation rules require category rules to specify timing start/end and may specify gameplay restrictions. The same executable run can therefore be valid under one category and invalid under another.

Thus:

```text
SameExecutable
!= SameEffectiveGameStructureForPractice.
```

But GDF0 already explicitly names speedrun categories as possible constitutive overlays.

This is confirmation, not a new target level.
