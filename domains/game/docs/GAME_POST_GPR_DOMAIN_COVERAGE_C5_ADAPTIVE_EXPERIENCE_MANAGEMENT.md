# Ordivon Game — Fresh Coverage C5: Adaptive Experience Management / Runtime Game Modification Falsification

## 0. Boundary

This is not GDF4 and not GPR8.

C5 attacks the historical residual:

```text
AI Director
Dynamic Difficulty Adjustment
Experience Management
Player Modeling
Personalized Quest/Content Selection
Adaptive Tutorialization
Live Event Steering
Runtime Generative Curation
Multiplayer Experience Management
```

The old loop was:

```text
Game observes Player
→ constructs/updates Player model
→ selects steering policy
→ changes challenge/content/rules/dynamics/presentation
→ observes resulting Player
```

The null model is:

```text
C5
= F7 Observation/Representation
+ F8 Evaluation
+ F9 Policy/Control
+ F4 Transition
+ GDF0 EffectiveRuleTopology / rule mutability / currentness / change authority
+ GPR1 ScopedAuthorityEdge / change-rule-policy / change-dynamics operations
+ GDF2 challenge/difficulty scope and transformation discipline
+ R27 hidden-adaptation / playable-adaptation legibility
+ C2 purpose-relative comparison/evaluation
+ C3 ordinary dynamics
+ C1 downstream instance constitution/continuity when affected.
```

Only an obligation that cannot be expressed by those layers may survive as a new Game foundation responsibility.

---

# 1. First correction — Subject learning is not Game adaptation

R27 already established:

```text
Learning != Adaptation
```

but C5 needs a stronger owner separation:

```text
Subject changes because of experience
!=
Game/system changes its current behavior/content/rules because of observations or steering policy.
```

So the old residual was real.

The question is whether it was a missing foundation or merely an un-reconstructed controller/change workflow over existing Game semantics.

---

# 2. Second correction — ordinary dynamics is not authority to modify dynamics

C3 froze this local separation for the fresh search:

```text
OrdinaryEndogenousDynamics
!= AuthorityToModifyDynamics.
```

A resource loop, opponent policy or physics system can evolve under the current GameStructure.

An experience manager can instead change:

```text
parameters
content selection
opponent distribution
challenge target
transition function
rule/policy interpretation
presentation
```

Therefore C5 cannot be dismissed as merely C3 dynamics.

But `different from C3` still does not imply `new foundation`.

# 3. Candidate deletion pass

## ExperienceManager primitive

2018 experience-management research shows that a game/manager pair can be represented as one game with the manager embedded inside.

The same semantic role can also be realized by:

```text
Human GM
live operator
rules-based director
learned Agent
player-authored setting
institutional tournament procedure
```

Delete `ExperienceManager` as an ontology kind.

## PlayerModel primitive

A manager may use:

```text
explicit preference
performance history
current Game state
a learned model
a hand-authored threshold
no persistent player model at all.
```

`PlayerModel` is F7 representation/belief, not necessary for every adaptive Game.

Delete as foundation.

## DDA primitive

Dynamic difficulty is one steering objective/application family over challenge-related variables.
GDF2 already owns ChallengeAssessment scope.

Delete as foundation.

## Personalization primitive

Personalization is target-relative selection/modification using participant-specific facts/models.
It occurs outside games as well.

Delete as Game primitive.

## AdaptiveGame kind

Many GameStructures contain condition-dependent transitions and policies.
Others permit authorized runtime rule changes.
There is no categorical ontology boundary where `AdaptiveGame=true` becomes a new Game kind.

Delete.

## SteeringObjective primitive

Engagement, challenge, fairness, learning, narrative pacing, preference fit and other objectives are F8/evaluation-specific.
Delete universal objective.

## AdaptationAction enum

Parameter tuning, quest selection, content generation, spawn changes, rule changes and presentation changes are heterogeneous owner-local operations.
Delete closed enum.

## AI Director kind

AI/ML realization does not determine semantic authority or role.
Delete Agent-era primitive.

```text

   what can participants/operators infer, audit or explain about the adaptation?
```

This is a trace/view over heterogeneous sources, not a second source of Game truth.

