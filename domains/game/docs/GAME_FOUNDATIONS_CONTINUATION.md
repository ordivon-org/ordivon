## R18 motivational result to preserve

```text
Need    = requirement pressure
Value   = evaluative structure
Desire  = current motivational salience
Preference = contextual comparison
Goal       = selected future / trajectory to pursue
```


## R19 strategic result to preserve

```text
StrategicRelevance(j → i)
=

can change i's preferred response
```

```text
StrategicInterdependence(i, j) =
MutualConsequenceCoupling

+ Belief / Anticipation
```

Core separation:

```text
Conflict     = incompatible preferred futures
Competition  = rivalry over scarce/relative outcomes
Cooperation  = intentional joint strategic benefit
Coordination = compatible action/convention selection
Bargaining   = selection among acceptable joint outcomes under disagreement
Negotiation  = strategic communication around information/proposals/commitments
Strategy     = policy conditioned on anticipated other-policy

```

Preserve:

```text
Many moving Actors != Strategic interaction.
StrategicDepth != SearchDepth.
Statement != Commitment.
Equilibrium != Product Value.
```

## R20 durable result

R20 separates several layers that are often collapsed into “creative content”:

```text
Creation =
deliberate organization/transformation into Form
whose meaningful properties depend on participant choices

Creativity =
meaningful novelty + contextual value/appropriateness
across process/product/context

Expression =
form/choice that makes identity, stance, taste or meaning legible

Authorship =
meaningful causal + normative responsibility for aspects of form/meaning

Customization =
bounded personalization inside a pre-structured option space

Generation =
candidate production mechanism
```

R20's main authorship test is **Authorial Causality**:

```text
If the participant made materially different meaningful decisions,
would important properties of the artifact be systematically different?
```

Raw keystrokes, token count, pixel count or realization labor are poor substitutes for this question.

A non-scalar authorship profile is:

```text
AuthorshipProfile = {
  Framing / Intent,
  Constraint Setting,
  Structural Specification,
  Material Realization,
  Selection / Curation,
  Evaluation / Taste,
  Revision,
  Integration,
  Final Commitment / Publication
}
```

R20 also adds **Creative Contribution Topology**:

```text
Participants / systems as nodes
+
contribution edges into
framing / constraints / generation / composition /
realization / evaluation / selection / revision /
integration / publication
```

This is more informative than a binary `human-created` versus `AI-created` label.

## Creative possibility structure

```text
CreativePossibilitySpace =
Forms reachable from
Materials × Tools × Grammar × Constraints × Skills × Time
```

This is a conceptual decomposition, not a required literal product schema.

Important distinctions:

```text
Combination    = rearrange known primitives
Exploration    = discover interesting regions inside a grammar
Transformation = alter grammar/operators/constraints to open new form families
```

R20 preserves:

```text
Freedom != CreativeAgency
More options != More expression
Creation != Creativity
Customization != Authorship
Generation != Creativity != Player Authorship
Authorship != Ownership
StyleSimilarity != SameAuthor
```

Constraints can be generative because they remove possibilities while creating semantic contrast, trade-offs, mastery and recognizable solution/style structure.

## Creative loop

```text
Impulse / Question / Intent
        ↕
Frame / Imagine
        ↓
Choose Material / Constraint / Tool
        ↓
Make / Compose / Transform
        ↓
Perceive Result
        ↓
Evaluate / Compare / Feel
        ↓
Revise / Branch / Reject / Keep
        ↓
Use / Perform / Share / Place in World
        ↓
New feedback / meaning / possibility
        ↺
```

The two-way beginning is essential:

```text
Intent shapes Artifact
Artifact feedback reshapes Intent
```

Creative intent can therefore emerge through tinkering rather than existing fully before the first action.

## Playable Creation and Expression

R20 adds:

```text
PlayableCreation =
a making process in which player choices causally shape form,
feedback supports a usable mental model,
and resulting differences matter to later use,
interpretation, identity, world state or continued creation.
```

```text
PlayableExpression =
expressive differences the player can intentionally produce
and that remain legible to self, system or audience.
```

Therefore:

```text
TechnicalCreativePower != PlayerCreativeAgency
```

## Human–AI creative modes

Keep these separate:

```text
Assistance
Delegated realization
Co-creation
Autonomous generation
Curation of autonomous generation
```

No one mode is inherently superior.

The automation boundary is experience-relative:

```text
Automate unwanted realization friction.
Do not silently automate the intended creative question.
```

For generative systems, use the smallest hard semantics needed for causality:

```text
authoritative artifact state
adopted constraints / structural commitments
provenance / ownership when relevant
world effects
```

while leaving suggestions, interpretations, stylistic realization and candidate variants soft/generated where appropriate.

## How to continue R21

Start from the **intent-to-action relation**, not from current input devices, combat code or a humanoid-avatar assumption.

The core problem is:

> How does a participant's intention become felt, controlled action through an interface/body, and why do some state changes feel like “I did that” while others feel delegated or system-authored?

Distinguish at least:

```text
Embodiment
Body
Avatar
Presence
Control
Input
Command
Delegation
Motor Skill
Cognitive Skill
Affordance
Capability
Action Possibility
Control Mapping
Action Resolution
Responsiveness
Latency
Feedback
Game Feel
Friction
Automation
```

Questions worth attacking:

1. What counts as embodiment for avatar, cursor, vehicle, camera, army, text persona and abstract-policy games?
2. How do Intent, Input, Control Mapping, Action Resolution and Feedback differ?
3. What makes a state change feel causally owned by the player?
4. What distinguishes direct manipulation, command, delegation and autonomous execution?
5. How does continuous sensorimotor skill differ from symbolic/strategic decision skill?
6. What is Affordance relative to actual capability, perceived possibility and legal action?
7. Which components of “Game Feel” arise from latency, anticipation, animation, audiovisual feedback, inertia, physics and consequence?
8. When does friction create mastery/materiality versus merely interface cost?
9. How can AI assist control/motor tasks without consuming the skill/fantasy that constitutes player value?
10. How do embodiment and control change identity, risk, presence and attachment?
11. What counts as a “body” in text/generative/strategy forms?
12. How do control and feedback interact with R20 Authorial Causality — when does action feel like the player's rather than the tool's?

## Expected R21 output shape

```text
1. separate embodiment/control/input/skill/affordance/game-feel terms;
2. derive the smallest intent→action→feedback structure;
3. test action/sensorimotor games;
4. test strategy/command/delegation forms;
```


## Product-selection stop condition

Do not begin intentional new-product G0 merely because the corpus is large.

Before narrowing, the programme should still:

- finish remaining obvious foundational dimensions;
- synthesize independent vs redundant dimensions;
- identify a smaller set of candidate causal laws;
- compare materially different authored, systemic, social, creative and generative families;
- design high-information falsifiers;
- state what remains unknown.

Only then ask whether evidence is mature enough to select an actual product form.
