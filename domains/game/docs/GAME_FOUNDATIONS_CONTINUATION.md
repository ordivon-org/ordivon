## R18 durable result

R18 separates motivational roles rather than collapsing them into one score:

```text
Need    = requirement pressure
Value   = evaluative structure
Desire  = current motivational salience
Preference = contextual comparison
Goal       = selected future / trajectory to pursue
Intention  = adopted Goal + persistence / reconsideration
Utility    = optional numerical representation / arbitration
Want       = usually a surface-language term rather than a mandatory primitive
```

The updated Subject compression is:

```text
Subject =
SituatedPerspective
+ Belief / InternalState
+ MotiveStructure
+ Commitments
+ Policy
+ ConsequentialAction

MotiveStructure =
RegulatoryPressure
+ EvaluativeStructure
+ CurrentSalience
```

Important R18 laws to carry forward:

```text
Scalarize late.
Goal proposal != Goal adoption.
Commitment creates temporal coherence but must be defeasible.
Motivational complexity is role-relative, not a maturity ladder.
Generative Persona != Autonomous Agent requirement.
Subject Value != Player Value.
Reward != Utility != Value.
```

R18 also adds `PlayableMotivation`: motives, trade-offs and commitments that the player can infer, test, influence, and use for future decisions or expression.

## How to continue R19

Start from strategic interdependence, not from current combat or multi-Agent implementation.

The core problem is:

> What changes when multiple Subjects can intentionally alter one another's reachable futures?

Distinguish at least:

```text
Conflict
Competition
Cooperation
Coordination
Bargaining
Negotiation
Strategy
Commitment
Coalition
Equilibrium
Dominance
Reciprocity
Trust
Reputation
```

Questions worth attacking include the minimum definition of conflict; competition versus direct opposition; cooperation versus coordination; strategic relevance; one-shot versus repeated interaction; reputation and memory; incomplete information; coalition formation; institutional incentive changes; bounded rationality; and minimum strategic cognition for different game forms.

## Expected R19 output shape

3. test one-shot and repeated interactions;

## High-priority warnings

Do not regress into any of these shortcuts:

```text
“LLM is smarter, therefore NPC is better.”
“More memory means deeper character.”
“More agents means richer society.”
“More map means more exploration.”
“More events means more story.”
“More choices means more agency.”
“More simulation means more depth.”
“More generation means more content value.”
“More time spent means more engagement value.”
```

The entire programme exists partly to replace those surface metrics with causal, player-facing structure.

## Product-selection stop condition

Do not begin intentional new-product G0 merely because the research corpus is large.

Before narrowing, the research should at least:

- finish the remaining obvious foundational dimensions;
- synthesize which dimensions are independent vs redundant;
- identify a smaller set of candidate causal laws;
- compare several materially different experience families;
- distinguish requirements of authored, systemic and generative forms;
- design high-information falsifiers rather than simply more prototypes;
- state what remains unknown.

Only then ask whether evidence is mature enough to select an actual product form.
