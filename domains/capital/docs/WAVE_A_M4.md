# Wave A / M4 — Research-to-Portfolio Handoff

## Purpose

Close the first end-to-end investment loop without introducing an alpha claim.

```text
CFA-informed IPS
  -> GLEIF reference identity
  -> SEC fundamental research artifact
  -> portfolio research-admission gate
  -> equal-weight validation target portfolio
```

The portfolio method remains deliberately boring. Research evidence is used only as an admission requirement: every allowed instrument must have one unique validated SEC feature row. Missing or duplicate research evidence fails closed.

This milestone proves the interface between Research E2E and portfolio construction. It does **not** claim that ROA, ROE or equity/assets should determine investment weights.
