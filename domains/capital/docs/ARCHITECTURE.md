# Architecture

## Core rule

Use mature external methods/standards/components. Ordivon-owned code is limited to mandate content, source-specific semantic mapping, strategy/economic logic, and reconciliation rules.

## Wave A

1. IPS: CFA-informed, machine-readable configuration.
2. Reference authority: GLEIF public production API for legal-entity identity.
3. Research boundary: versioned artifacts consumable by Research E2E / MLflow.
4. Portfolio construction: V1 uses deliberately boring equal-weight construction only to validate the system boundary.
5. Output: deterministic target portfolio artifact.

No legacy finance code, no broker, no LEAN, no live financial effect in Wave A.
