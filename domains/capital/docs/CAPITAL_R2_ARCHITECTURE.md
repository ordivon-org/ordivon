# Capital R2 Architecture

R2 is a subtraction migration over the accepted R1 financial semantics.

## Ownership equation

```text
Capital R2
= financial domain semantics
+ financial LEGO registry
+ declarative financial circuit specifications
+ owner-native financial implementations
+ financial reconciliation/accounting evidence
```

Generic composition is not a Capital responsibility.

## Owner split

| Owner | R2 responsibility |
| --- | --- |
| Capital | financial LEGO/effect/authority/evidence vocabulary and domain acceptance |
| Composition | task-local DAG, gates, authority/verification obligations, interface mechanics |
| Runtime | Workspace/Job/Attempt/Artifact physical execution truth |
| Network | transport/proxy/failover authority |
| Gateway | non-authoritative capability routing |
| Host | semantic continuity/collaboration |
| Provider | external market/account/order reality |

## Effect invariant

```text
Authorize → Reserve → Effect → Observe → Reconcile → Account
```

The shared Composition package may validate that declared stages/gates bind mechanically, but it does not infer financial effect coverage. Capital alone declares which financial EffectClass requires Reserve, Reconcile and Account.

## Migration law

R1 local generic composition mechanics are deleted only after frozen R1 outcomes and live R2 differential tests agree for the current Capital contract space. Historical R1 provenance remains evidence; it is not active source.
